2024-05-23

洩露的檔揭露了 OpenAI 對前雇員的侵略性策略​

  • 洩露的文件顯示，由首席執行官山姆·阿爾特曼（Sam Altman）領導的OpenAI使用激進的策略來阻止前員工批評公司，威脅要撤銷他們的既得股權，除非他們簽署限制性退出協定。
  • 儘管阿爾特曼公開道歉並聲稱自己無知，但帶有他和其他高管簽名的內部檔表明，他們知道這些規定，這引發了人們對OpenAI透明度和可信度的擔憂。
  • OpenAI現在正在更新其離職流程，以確保前雇員的既得股權並刪除非貶低條款，儘管仍有更多工作需要解決。

反應​

  • 洩露的文件顯示，OpenAI 使用激進的策略通過威脅前員工的既得股權來執行非貶低協議，導致 OpenAI 的強烈反對和隨後的保證。
  • 這種情況引發了關於合同談判、股權補償和競業禁止條款的討論，凸顯了可執行性的複雜性和地區差異。
  • 批評者認為，OpenAI的行為揭示了更深層次的信任和透明度問題，對行業趨勢、道德問題以及山姆·奧特曼（Sam Altman）等知名人物的影響產生了更廣泛的影響。

記錄證實，OpenAI 沒有為 ChatGPT 克隆 Scarlett Johansson 的聲音​

  • 斯嘉麗·詹森（Scarlett Johansson）聲稱，在她拒絕了首席執行官山姆·奧特曼（Sam Altman）的許可請求后，OpenAI在未經她同意的情況下複製了她的聲音。
  • 根據《華盛頓郵報》審查的消息來源和檔，OpenAI 曾為一個秘密項目尋找具有溫暖、引人入勝的聲音的非工會演員，以使 ChatGPT 人性化，但並沒有明確旨在克隆約翰遜的聲音。

反應​

  • OpenAI 因涉嫌在未經 ChatGPT 同意的情況下使用 Scarlett Johansson 的配音演員而受到審查，這引發了法律和道德問題。
  • 這場辯論凸顯了聲音模仿法的複雜性，並引用了米德勒訴米德勒案等案例。Ford 和 Tom Waits 訴 Frito-Lay，並強調了更新法律框架的必要性。
  • 這場爭議引起了人們對人工智慧、配音演員的更廣泛影響的關注，以及在未經明確同意的情況下使用聽起來相似的聲音的道德考慮。

WinDirStat：適用於 Windows 的開源磁碟使用方式查看器和清理工具​

  • WinDirStat是一個開源工具，用於查看和清理Microsoft Windows上的磁碟使用方式，提供目錄清單，樹狀圖和擴展清單。
  • Linux 的替代品包括 KDirStat 和 QDirStat，而 MacOS X 使用者可以使用 Disk Inventory X 或 GrandPerspective。
  • 該軟體根據 GPLv2 獲得許可，確保其保持免費和開源。

反應​

  • 討論比較了各種磁碟使用方式分析工具，重點關注不同操作系統的功能、性能和可用性。
  • WinDirStat 很受歡迎且開源，但因速度慢而受到批評，而WizTree速度更快，但存在安全問題並且不是開源的。
  • 用戶強調了速度、安全性和可用性之間的權衡，並表示需要更好的檔管理功能和改進的可視化方法，如樹狀圖和旭日圖。

Microsoft 中斷中斷了 Bing、Copilot、ChatGPT 和 DuckDuckGo 服務​

  • 2024 年 5 月 23 日的一次重大Microsoft中斷中斷了多項服務，包括 Bing、Copilot、ChatGPT 互聯網搜索和 DuckDuckGo，主要影響了亞洲和歐洲的使用者。
  • Bing 的主頁和 Copilot 服務遇到了重大問題，而 DuckDuckGo 顯示錯誤消息，但後來恢復了正常操作。
  • OpenAI和Microsoft承認了這些問題，並一直在努力恢復Bing和Copilot的全部功能。

反應​

  • Microsoft中斷影響了多種互聯網服務，例如 Bing、Copilot、DuckDuckGo 和 ChatGPT。
  • 該事件凸顯了在線服務的互聯性及其對Microsoft基礎設施的依賴。
  • 有關更詳細的討論，使用者已被定向到 Hacker News 上的特定線程。

Sierra 的 Space Quest II 軟盤錯誤暴露了 AGI 原始程式碼​

  • 2024年，由於格式不正確，發現 Sierra On-Line 的 Space Quest II 的某些版本在其 720KB 軟盤上殘留了 C 原始程式碼。
  • 這個錯誤暴露了 Sierra 大約 70% 的 AGI 解釋器原始程式碼，包括 75 個 C 源檔和 16 個彙編檔，直到 2016 年才被注意到。
  • 原始碼現在可以在 GitHub 上找到，它提供了對 Sierra 開發過程的寶貴見解，並為 AGILE 基於 Web 的解釋器等專案提供了説明。

反應​

  • 討論強調了軟體分發中的歷史錯誤，例如在最終產品版本中包含敏感或意外數據，例如1989年的DOS遊戲“雙龍II：復仇”。
  • 它研究了軟盤的反盜版措施、消費級磁碟複印機的局限性，以及用於讀取磁性級數據的 Greaseweazle 等現代工具。
  • 參與者分享了對舊遊戲的懷舊體驗，討論了原始程式碼洩露的影響，並強調了部門級映像對存檔的重要性。

無人機飛行大師：FPVSIM互動式初學者教程​

  • FPVSIM 為初學者提供了詳細的無人機飛行教程，涵蓋了懸停、轉彎、傾斜和協調轉彎等關鍵概念。
  • 該教程重點介紹了無人機和汽車導航之間的區別，重點介紹了通過橫滾、偏航和俯仰的 3D 運動，並通過基於 Web 的模擬器提供實踐課程。
  • 用戶可以訪問其他資源，例如手冊、性能提示和高級配置，並繼續在 FPVSIM 的 Web 或桌面模擬器上練習，以增強學習和逼真的圖形。

反應​

  • “無人機飛行 101 – 初學者互動教程”涵蓋了 FPV（第一人稱視角）和非 FPV（電影）無人機的基礎知識，強調了 DJI Mavic 等非 FPV 無人機由於 GPS 穩定而實現的使用者友好性。
  • 本教程強調了選擇合適的發射器的重要性，推薦使用 OpenTX 或 EdgeTX 軟體和 ExpressLRS 協定以獲得更好的性能，流行的發射器包括 Radiomaster 和 TBS Tango 2。
  • 討論探討了無人機在現代戰爭中不斷發展的使用，特別是在烏克蘭，並觸及了自主無人機、飛行員培訓和對策的潛在未來。

Emacs Easy Draw：與組織模式集成的無縫繪圖工具​

  • Emacs Easy Draw 是一個在 Emacs 中運行的繪圖工具，需要 Emacs 27.2、圖像和 SVG 支援、gzip/gunzip 和 libxml。
  • 它與組織模式集成，允許使用者直接在文檔中創建和編輯圖紙，並支援匯出為 HTML 或 LaTeX。
  • 該工具使用 SVG 規範的子集，包括用於 CSS 和 HTML 編輯的顏色選擇器庫，並根據 GPLv3 獲得許可，鼓勵社區貢獻。

反應​

  • Emacs Easydraw 是為 Emacs 開發的繪圖工具，它是在 Windows 而不是典型的 Linux 環境中獨特創建的。
  • 用戶發現它對於小圖紙和與 org-roam 等工作流的潛在集成很有用，儘管它目前缺乏手寫功能和協作功能。
  • 隨著演算法的改進，一些人認為它可以與 Inkscape 競爭，並且它具有方便的顏色選擇器，使其優於許多在線工具。

湯姆·韋茨（Tom Waits）贏得了對Frito-Lay的260萬美元訴訟，理由是聲音盜用​

  • 1988 年，Tom Waits 起訴 Frito-Lay Inc. 在 Doritos 廣告中使用了對他的歌曲“Step Right Up”的類似聲音的模仿，聲稱虛假代言和聲音盜用。
  • 陪審團判給 Waits 260 萬美元，上訴維持原判，為《蘭哈姆法案》和加州法律下的聲音盜用確立了法律先例。
  • Waits批評那些允許他們的音樂出現在廣告中的藝術家，認為這破壞了藝術的完整性，他的案件凸顯了保護藝術聲譽的重要性。

反應​

  • 討論探討了使用聲音相似的配音演員的法律和道德問題，參考了 Tom Waits 對 Frito-Lay 的訴訟和 Scarlett Johansson 與 OpenAI 的爭議。
  • 它研究了聲音模仿的複雜性、“出賣”的概念，以及對藝術家許可其作品的不斷變化的看法，包括未經同意使用類似於約翰遜的聲音的法律影響。
  • 該對話批評了企業的做法，尤其是 OpenAI 的做法，並解決了對人工智慧生成的聲音影響智慧財產權和藝術完整性的廣泛擔憂。

鍵入動畫UI庫：面向設計工程師的免費、可定製元件​

  • 面向設計工程師的 Typing Animation UI 庫提供了 20 多個免費和開源的動畫元件，這些元件使用 React、Typescript、Tailwind CSS 和 Framer Motion 構建。
  • 該庫包括檔保存、全文搜索、多語言支援和日曆過濾等功能，並提供真實的元件演示。
  • 使用者在 Twitter 上稱讚了該庫的設計和功能，Magic UI Pro 提供了更高級的範本供進一步定製。

反應​

  • Magic UI是一個面向設計工程師的UI庫，它得到了不同的評價，一些人稱讚它的美學吸引力，而另一些人則批評它在視覺上分散注意力和衍生性。
  • 主要的批評包括性能低下、資源消耗高、Firefox 的可用性問題，以及被指責抄襲 ShadCN/UI。
  • 討論還強調了 React 在 Web 開發中的主導地位、維護 Figma 元件的效用，以及演示網站上的極端 CPU 使用率和瀏覽器崩潰等性能問題。

NVIDIA 推出 CUDA-Q 平臺以提升全球量子計算中心​

  • NVIDIA 推出了 CUDA-Q 平臺，旨在推動全球量子計算中心的發展。
  • 該公告於 2024 年 5 月 12 日發布，標誌著量子計算技術邁出了重要一步。
  • 此次發佈有望加速量子計算領域的研發。

反應​

  • 英偉達 2025 財年第一季度業績顯示，H100 GPU 銷售強勁，但對潛在的供應鏈風險持謹慎態度，這與思科等歷史案例相提並論。
  • 討論強調了投資策略的重要性，如多元化、風險平衡和瞭解市場動態，突出了英偉達憑藉其卓越的軟體生態系統在人工智慧領域的領先地位。
  • 在人工智慧炒作、Meta和Microsoft/OpenAI等客戶創造自己的晶元的潛在競爭以及台積電和三星的製造限制中，人們對英偉達增長的可持續性提出了擔憂。

參議員警告說，汽車製造商承認在沒有搜查令的情況下與警方共享駕駛員數據​

  • 包括豐田、斯巴魯和寶馬在內的八家汽車製造商向國會承認，他們將在沒有法院命令的情況下向警方提供駕駛員數據，這與他們之前保護消費者隱私的承諾相矛盾。
  • 參議員羅恩·懷登（Ron Wyden）和埃德·馬基（Ed Markey）批評汽車製造商誤導消費者，並對法律系統可能濫用位置數據表示擔憂。
  • 汽車行業在隱私問題上的立場不一致，例如反對維修權法案，同時損害消費者數據，凸顯了對聯網汽車技術保持警惕的必要性。

反應​

  • 參議員們擔心汽車製造商在沒有搜查令的情況下向警方提供車輛位置數據，這引發了現代車輛的隱私和跟蹤問題。
  • 用戶討論了禁用安吉星等跟蹤服務的複雜性、此類操作的合法性以及對車輛功能和保修的影響。
  • 這場辯論強調了公共安全和隱私之間的平衡、保險公司的作用以及健全的消費者權利和數據隱私法規的必要性。

旅行者1號在中斷五個月後恢復科學數據傳輸​

  • 旅行者1號在2023年11月發生計算機問題后，已恢復從其四台儀器中的兩台發送科學數據。
  • 任務小組正在重新校准其餘兩台儀器，等離子體波子系統和磁力計現已投入使用。
  • 該問題可追溯到飛行數據子系統中的記憶體損壞;旅行者1號於1977年發射升空，距離地球超過150億英里，是美國宇航局運行時間最長的航太器之一。

反應​

  • 美國宇航局關於旅行者1號恢復數據傳輸的文章的爭論集中在旅行者號任務是否是人類最偉大的科學成就上。
  • 參與者將旅行者號的長壽和簡單設計與大型強子對撞機和基因組測序等複雜專案進行了比較，強調了重力輔助和獨特的行星排列的重要性。
  • 討論還提到了其他不朽的成就，例如根除天花和印刷機的發展，並強調了由於這些成就的重大影響而對這些成就進行排名的挑戰。

新的圖靈機突破性計算阿克曼級函數​

  • 帕維爾·克羅皮茨（Pavel Kropitz）發現了一個3態、4個符號的圖靈機（TM），它能夠計算阿克曼級函數，在磁帶上精確地停止\（（2 \uparrow^15 5） + 14 \）個非零符號。
  • 這個TM於2024年4月25日被發現，是第一個已知的類比如此複雜功能的TM，其行為需要雙重感應來證明。
  • 這一發現還充當了「歸納證明」驗證器的測試用例，旨在標準化和驗證此類證明。

反應​

  • 本文深入探討了圖靈機的複雜性，重點介紹了忙碌的海狸問題和一個新的圖靈機程式BB（3,4），它在複雜度上超過了阿克曼函數。
  • 它討論了程式的模組化結構、長時間運行的圖靈機的特性以及柯爾莫哥羅夫複雜性的影響，強調了分析這些機器的挑戰。
  • 對話還批評了同行評審制度、數位資訊源的可靠性，並強調了科學研究中正確存檔和引用實踐的重要性。

Computershare 在價格大幅上漲的情況下拋棄 VMware 轉而使用 Nutanix AHV​

  • 全球股票市場股票註冊運營商 Computershare 正在放棄 VMware，原因是 Broadcom 收購 VMware 後價格大幅上漲。
  • VMware 虛擬機管理程式的成本增加了 10 到 15 倍，促使 Computershare 改用 Nutanix AHV，預計一年內將完成 24,000 個虛擬機的遷移。
  • 此舉凸顯了博通的潛在問題，因為其他大客戶也可能因其高收入、高利潤的定價策略而尋求替代方案。

反應​

  • 由於價格大幅上漲，現在由博通（Broadcom）擁有的VMware失去了一個擁有24,000台虛擬機的主要客戶，這反映了專注於高收入、高利潤業務的戰略。
  • 批評者認為，這種方法可能會將客戶推向 Nutanix 或開源解決方案等競爭對手，這凸顯了遷移大型 IT 系統的挑戰以及維護客戶信任的重要性。
  • 該討論還強調了供應商鎖定的風險，並建議採用混合或多雲方法來減少對單個虛擬機管理程式供應商的依賴。
