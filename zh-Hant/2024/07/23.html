2024-07-23

開源 AI 是未來的道路​

  • “開源的 Linux 因其可修改性、經濟實惠性和先進功能，成為雲端運算和行動裝置的業界標準，這與 AI 預期的發展軌跡相似。”
  • Meta 已經發布了 Llama 3.1 405B，這是首個前沿級開源 AI 模型，並且改進了 70B 和 8B 模型，強調更好的成本效益和適合微調的特性。
  • Meta 與 Amazon、Databricks 和 NVIDIA 等公司合作，支持開發者，旨在使開源 AI 成為行業標準，促進透明度、安全性和經濟增長。

評論​

  • Meta 已經推出 Llama 3.1，一個開源的 AI 模型，具有 4050 億參數模型以及增強的 700 億和 80 億參數模型。
  • “此版本被視為一項策略性舉措，旨在通過免費提供先進的 AI 模型來挑戰 OpenAI、Google 和 Microsoft 等競爭對手，但對於用戶數超過 7 億的公司則有限制。”
  • “批評者認為，若無法取得訓練數據和基礎設施，這些模型更像是免費軟體而非真正的開源軟體，這引發了對Meta真實意圖及其更廣泛影響的討論。”

「Kawaii – 鑰匙圈大小的任天堂 Wii」​

評論​

  • 「Thundervolt」專案涉及修改任天堂 Wii，通過修剪其 PCB(印刷電路板)來保留僅有的必要元件，如 DRAM(動態隨機存取記憶體)和處理器，並添加一個外部 DCDC(直流轉直流)板來供電。
  • 該專案旨在製作一個鑰匙圈大小的 Wii，名為「Kawaii」，其尺寸比其他迷你版本如 GC Nano 更小，但仍需要一個底座來實現完整功能，包括電源輸入和控制器連接。
  • 這個專案突顯了對復古遊戲和遊戲機微型化的持續興趣與創新，展示了社群在保存和提升經典遊戲硬體方面的投入與熱情。

Timeshift：Linux 系統還原工具​

  • Timeshift for Linux 是一款類似於 Windows 系統還原和 Mac OS Time Machine 的系統備份工具，專注於系統檔案和設定。
  • 它支援兩種模式：RSYNC(使用 rsync 和硬連結)和 BTRFS(使用 BTRFS 檔案系統功能)，後者需要特定的子卷佈局。
  • 由 Tony George 開發，現已成為 Linux Mint 的 Xapp 專案一部分，Timeshift 提供多種快照層級、跨發行版還原和還原後掛鉤等功能，並提供適用於各種 Linux 發行版的安裝說明。

評論​

  • 「Timeshift 是一款 Linux 的系統還原工具，類似於 macOS 的 Time Machine 和 Windows 的系統還原，允許使用者使用 rsync 和硬連結來創建檔案系統快照。」
  • 用戶討論了各種備份解決方案和配置，包括 restic、rclone、ZFS、BTRFS 和 LVM 快照，強調了原子快照對於資料庫一致性和可靠備份的重要性。
  • 「這段對話強調了需要強大的備份策略，並比較了像 restic、Borg 和 kopia 這些工具，討論了不同檔案系統和快照方法的優缺點。」

2024 年 7 月 Intel Core 第 13/14 代桌上型處理器不穩定報告更新​

  • Intel 已經發現其第 13 代和第 14 代桌上型處理器因微碼演算法導致操作電壓升高而產生不穩定性。
  • 預計在八月中旬會有一個微碼修補程式來解決此問題，英特爾建議受影響的客戶聯繫支援以獲得協助。
  • 用戶表達了對潛在長期 CPU 損壞的擔憂、需要 BIOS 更新的需求，並在尋求管理不穩定性指導的過程中報告了 RMA(退貨授權)問題，直到補丁發布為止。

評論​

  • “英特爾 2024 年 7 月的更新指出，第 13/14 代桌上型 CPU 存在微碼問題，導致電壓請求錯誤，儘管有些用戶懷疑是硬體故障。”
  • “由於英特爾延遲解決問題以及有報導指出無故障的 CPU 在未更新微碼的情況下出貨，這可能導致 CPU 長期退化，引發了擔憂。”
  • 「Intel 計劃發布微碼補丁，但其效能和對性能的影響尚不確定，用戶對 CPU 穩定性的反應不一。」

Google 日曆資料庫設計：一個教程​

  • “Alexey Makhotkin 的教學提供了一個全面的指南，講解如何設計 Google Calendar 克隆的資料庫表格，並遵循即將出版的書籍《使用最小建模的資料庫設計》中的方法。”
  • 它廣泛地涵蓋了邏輯模型，詳細說明如何處理基本的全天事件、基於時間的事件和重複事件，然後過渡到創建實體 SQL 資料表。
  • “本教程針對具有一般資料庫知識的讀者，幫助他們從概念構想到完整的資料庫表格定義，並包含實際步驟來實現設計。”

評論​

  • 「關於 Google Calendar 資料庫設計的討論建議，應優化 iCalendar 解析器以快速掃描事件，而不是創建複雜的架構。」
  • “有人提出了對 SQL 類似範圍搜尋和使用者特定查詢需求的擔憂，這些傳統資料庫處理得很好。”
  • 辯論中包括了時區、日光節約時間和重複事件等挑戰，並達成共識認為 SQL 管理關係和查詢的能力使其適合用於行事曆應用程式。

ASCII 表的優雅​

  • ASCII 表於 1963 年標準化，為 128 個可能的 7 位元二進位碼點中的 100 個賦予了意義，並且至今仍然具有相關性，特別是因為 UTF-8 編碼具有向後相容性。
  • 該表格包含控制碼、可列印字元，並遵循特定的二進位模式，其中空格字元是排序用途的第一個可列印字元。
  • ASCII 的設計既合乎邏輯又美觀，讓人類學習和理解起來都很順暢，這反映了它的歷史意義和精緻的邏輯。

評論​

  • 「這篇文章討論了 ASCII 表的優雅性和實用性，這是一種用於計算機的字符編碼標準。」
  • 它強調了使用者如何透過命令 man ascii 在 Linux 系統上存取 ASCII 表，這對於 shell 逃脫碼和正規表示式(regex)非常有用。
  • 這段對話包含了歷史背景和個人軼事，講述了通過 manpages 學習各種技術的經歷，並強調了 ASCII 表在計算機領域中長期以來的重要性。

「有可能在不進入 FAANG 工作的情況下獲得相同薪水嗎？」​

  • FAANG(Facebook、Amazon、Apple、Netflix、Google)公司與非FAANG公司之間的薪資差距相當大，FAANG工程師獲得的薪酬待遇明顯更高。
  • 在一般新創公司工作的資深工程師可能會獲得25萬美元的基本薪資加上10-20%的獎金，而在FAANG公司工作的資深工程師則可能會獲得類似的基本薪資加上四年內價值100萬美元的股票。
  • 這篇文章質疑是否在 FAANG 和大型銀行/高頻交易(HFT)公司之外的個人能賺取相當的收入，並試圖找出他們是誰以及他們的職位。

評論​

  • “在非 FAANG 公司中獲得 FAANG 水準的薪資是可能的，但很少見，通常涉及利基市場或高壓的職位。”
  • 高薪的替代選項包括對沖基金、高頻交易公司、專業諮詢、利基軟體公司、遺留系統專業知識和創業。
  • 這些職位通常伴隨著高壓、激烈的競爭或重大的風險和努力，使得它們相比於 FAANG 工作來說較為罕見且不那麼簡單明瞭。

Llama 3.1​

  • 「Llama 3.1 是一個開源的 AI 模型，提供三個版本：8B、70B 和 405B，以滿足不同的性能和成本需求。」
  • 它支援進階使用案例，包括程式碼助手、多語言代理和複雜推理，具備即時和批次推論、微調和合成數據生成的能力。
  • 該模型已在超過150個數據集上進行評估，顯示出在一般、程式碼、數學、推理、工具使用和多語言基準測試中的高性能表現。

評論​

  • 「Llama 3.1 是由 Meta 開發的開源 AI 模型，其表現與 GPT-4 等封閉源代碼模型相當。」
  • 405B 型號展示了顯著的基準改進，但在沒有雲端支援的情況下，對於家庭使用來說並不實際，這突顯了在本地運行大型模型的挑戰。
  • Meta 發布強大的開放模型，旨在顛覆競爭格局，激發對硬體需求、量化解決方案以及對人工智慧發展和可及性更廣泛影響的興趣。

「鈕扣小偷」​

  • 「Button Stealer 是一款 Chrome 擴充功能，會自動移除您造訪的每個網站上的按鈕。」
  • 「這個擴充功能設計得很有趣，而且免費使用，但沒有實際用途。」
  • 它透過在使用者的裝置上本地運行來確保使用者資料的隱私。

評論​

  • 「Button Stealer，一款 Chrome 擴充功能，由於其廣泛的權限引發了安全疑慮，這可能使其能夠從任何網頁中擷取資料。」
  • 用戶建議在 GitHub 上審查程式碼並在本地安裝，以避免潛在的惡意更新，而其他人則認為這類有風險的擴充功能不應該出現在 Chrome 商店中。
  • 討論強調了對瀏覽器擴充功能需要更具體的權限以及改進的安全實踐。

回覆：現實生活中的人知道你有部落格嗎？​

  • 作者討論了維持部落格近二十年的個人意義，儘管現實生活中的人們(IRL)對此漠不關心。
  • “部落格作為一種自我表達和自由的形式，與社群媒體和大型科技公司的壓力形成對比。”
  • “讀者的回應突顯了各種觀點，包括部落格寫作對個人思路清晰的好處、對人工智慧剝削的擔憂，以及鼓勵在沒有分析數據的情況下進行寫作。”

評論​

  • 「個人網站提供了靈活性和精緻度，沒有像部落格那樣需要定期更新的壓力，部落格有時會讓人感到懶散和不友好。」
  • “部落格可能對歷史學家和分享想法有用，但個人頁面因其組織性和創意潛力而更受青睞。”
  • 有些人在個人網站上使用假名，以避免專業上的影響，這突顯了這些平台的個人性質。

Wiz 放棄與 Google 的 230 億美元交易​

  • 「Wiz 已決定放棄與 Google 的 230 億美元收購交易，並將改為進行首次公開募股(IPO)，這是由執行長 Assaf Rappaport 宣布的。」
  • 這項決定受到反壟斷和投資者關切的影響，Wiz 的目標是實現每年 10 億美元的經常性收入。
  • 「Wiz 成立於 2020 年，迅速成長，去年達成 3.5 億美元的年度經常性收入，並提供雲端安全產品。」

評論​

  • 「Wiz 已經退出與 Google 簽訂的 230 億美元交易，可能是因為 Google 在內部數據審查後重新評估了這筆交易。」
  • Wiz 聲稱他們退出是因為他們認為自己的估值更高，儘管對於他們的高估值存在懷疑，據報導其估值超過年度經常性收入(ARR)的 60 倍。
  • 儘管Wiz自2020年成立以來迅速成長至年經常性收入(ARR)達到1億美元，這筆交易的破裂仍引發了對其實際價值和未來的質疑。

終止 OCSP 服務的意圖​

  • 「由於隱私風險和資源效率的考量，Let's Encrypt 將停止支援線上憑證狀態協定(OCSP)，轉而使用憑證撤銷列表(CRLs)。」
  • 此變更不會影響網站或訪客，但可能會影響某些非瀏覽器軟體；建議使用者確保其軟體在沒有 OCSP URL 的情況下仍能正常運作。
  • CA/瀏覽器論壇的決定使得OCSP對於公開信任的憑證授權機構(CAs)來說是可選的，唯有微軟是例外；一旦微軟也將其設為可選，關閉OCSP服務的時間表將會公佈。

評論​

  • 「Let's Encrypt 計劃停止其 OCSP(線上憑證狀態協定)服務，原因是憑證撤銷列表(CRLs)存在問題以及 OCSP 系統的複雜性。」
  • 提案包括使用二進位格式的 CRL 以提高效率，以及強制 OCSP 釘選來解決隱私問題，儘管這可能會干擾許多網站。
  • “轉移離開 OCSP 可能會影響非瀏覽器應用程式和嵌入式設備，但使用 Nginx 或 Caddy 等標準網頁伺服器的用戶應該不需要立即進行更改。”

「Linux 音訊堆疊解密(及更多)」​

  • 這篇文章提供了關於 Linux 音訊堆疊的全面概述，解釋了聲音的基本知識、人類的聲音感知以及數位音訊處理。
  • 「Linux 音訊堆疊的主要組成部分包括用於低階硬體控制的 ALSA、用於低延遲即時音訊的 JACK，以及用於高階音訊管理的 PulseAudio，而 PipeWire 正逐漸成為一個統一的解決方案。」
  • PipeWire 被強調為一個多功能的選項，整合了 JACK 和 PulseAudio 的功能，未來可能在 Linux 發行版中取代它們。

評論​

  • 「雖然 Linux 音訊堆疊相當複雜，但它支援多種硬體和功能，包括多工處理和網路功能。」
  • 「Pipewire 旨在統一 Linux 音訊堆疊，支援各種 API 並改進 PulseAudio，提供更高的多功能性和穩定性。」
  • 雖然有些使用者在進階設置上面臨挑戰，但許多人對 Pipewire 為 Linux 音訊帶來的改進和靈活性表示讚賞。

「美國公開核彈頭數量；恢復核透明度」​

  • 「美國科學家聯盟(FAS)讚揚美國解密其核彈頭數量，提升核透明度。」
  • 截至2023年9月，美國擁有3,748枚核彈頭，去年僅拆除69枚，為1994年以來的最低數量。
  • 拜登政府的披露恢復了川普政府暫停的透明度，並且美國科學家聯盟(FAS)鼓勵其他擁有核武的國家採取類似的透明措施，以防止不信任和錯誤資訊的傳播。

評論​

  • 「美國已公開其核彈頭數量，恢復了核透明度並引發了關於生產能力和戰略重要性的討論。」
  • 「主要議題包括潛在生產加速的速度、庫存規模對全球安全和地緣政治的影響，以及維護挑戰如鈽老化和氚替換。」
  • 此項披露旨在通過展示美國強大的核能力來安撫盟友並威懾對手。

Lisp 在 C#​

  • “Sharpl 是一個用 C# 編寫的自訂 Lisp 解釋器，約有 4,000 行程式碼且無外部依賴，使其易於嵌入。”
  • 主要特點包括成對、陣列、映射、方法組合、可變參數、統一的迭代器協議，以及一種定點小數類型等。
  • 「它支援詞彙和動態綁定、尾端呼叫優化以防止堆疊溢位，並提供帶有行號的詳細錯誤報告。」

評論​

  • “名為 codr7 的開發者正在使用 C# 開發一個 Lisp 實作，並尋求社群的優化幫助。”
  • 透過社群建議，例如改變 ArrayStack 的存取方式以及使用 Span 和 ReadOnlySpan 進行資料切片，已經達成顯著的效能提升。
  • “該專案並非以符合標準為目標，而是著重於實際性能和可用性，目前正在討論整合宏和函數表達式(Fexprs)等功能。”
