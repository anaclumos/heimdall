웹 개발자를 위한 바닐라 자바스크립트를 사용한 DOM 조작의 중요성 이해하기​

  • 저자는 웹 개발자가 직접 DOM 관리를 간소화하는 Angular, VueJS, React, Solid, Svelte와 같은 최신 도구를 사용할 수 있음에도 불구하고 일반 JavaScript를 사용하여 DOM(문서 객체 모델) 조작을 마스터해야 할 필요성을 강조합니다.
  • 최신 도구는 직접적인 DOM 상호 작용을 캡슐화하고 추상화하지만, 웹 개발자는 여전히 어느 정도 수준에서 DOM과 상호 작용해야 합니다.
  • 개발자가 DOM 조작을 마스터하는 데 도움이 되도록 저자는 간단한 예제, 라이브 데모, 팁 및 모범 사례와 같은 리소스를 제공합니다.

반응​

  • 저자는 웹 개발자가 앵귤러, VueJS, React, 솔리드, 스벨트와 같은 최신 도구가 등장하는 시대에도 바닐라 자바스크립트를 사용해 문서 객체 모델(DOM) 조작에 능숙해져야 한다고 강조합니다.
  • 이러한 도구는 직접적인 DOM 관리의 상당 부분을 래핑하고 추상화하지만, 웹 개발에서 DOM과의 상호 작용은 여전히 일정 수준 존재한다는 지적이 있습니다.
  • 저자는 간단한 예제, 라이브 데모, 팁, 모범 사례와 같은 리소스를 제공하여 개발자가 DOM 조작 기술을 익히는 데 도움을 줍니다.

프로시모, 러스트에서 개발된 보안 강화 리눅스 유틸리티 Sudo-rs의 안정 버전 출시​

  • 프로시모는 잠재적인 보안 위협을 줄이는 데 도움이 되는 메모리 안전 언어인 러스트(Rust)로 코딩되어 보안이 개선된 Linux의 sudo 유틸리티를 개조한 최초의 안정 버전인 sudo-rs를 출시했습니다.
  • 이 프로젝트는 이미 Wolfi Linux OS에 통합되어 있으며, 보안을 강화하기 위해 축소된 기능 세트와 포괄적인 테스트 스위트의 이점을 누리고 있습니다. 2023년 9월에 외부 보안 감사를 받을 예정입니다.
  • 이 프로젝트는 원래 sudo 유틸리티를 만든 Todd C. Miller의 자문과 함께 Tweede Golf 및 Ferrous Systems와의 협업을 통해 이루어졌습니다. 재정적 지원은 NLnet 재단과 Amazon Web Services에서 제공했습니다.

반응​

  • 프로시모는 메모리 안전 프로그래밍 언어인 Rust로 개발된 널리 사용되는 리눅스 유틸리티 sudo의 보다 안전한 버전인 sudo-rs의 첫 번째 안정적인 릴리스를 발표했습니다.
  • 이미 Wolfi Linux 운영 체제에 통합된 이 프로젝트는 메모리 안전 언어를 사용하여 잠재적인 보안 위협에 대응하고자 하며, 개발자인 Twoede Golf와 Ferrous Systems가 크게 기여했습니다.
  • 외부 보안 감사는 2023년 9월에 예정되어 있으며, 이 프로젝트는 NLnet 재단과 Amazon Web Services를 비롯한 다양한 출처로부터 자금을 지원받았습니다. 원래 sudo 유틸리티를 만든 Todd C. Miller는 sudo-rs의 개발 과정에서 중요한 지침을 제공했습니다.

개발자들이 애플의 피드백 어시스턴트에 항의: 버그 보고 시스템 개선 촉구​

  • Jeff Johnson은 개발자에게 기존 문제에 대한 새로운 피드백을 제출하되 개선이 이루어질 때까지 기존 피드백에 대한 응답을 거부할 것을 촉구하며 Apple의 피드백 어시스턴트에 대한 보이콧을 시작했습니다.
  • 주요 문제점으로 지적된 것은 Apple의 응답 부족, 피드백 임의 종결, 개발자 버그 보고서 무시, 상세한 시스템 진단 보고서 요구, 소규모 버그 진단 방법 무시, 버그 검색 기능 부족, 모든 피드백을 macOS 또는 iOS를 통해 제출하도록 의무화 등이었습니다.
  • 불매 운동은 노동 파업과 비교하여 애플의 소프트웨어와 제품을 테스트하고 개선하는 데 있어 개발자들이 인정받지 못하고 무급으로 기여하고 있다는 점을 강조합니다. 개별 Apple 엔지니어를 비판하는 것이 아니라 회사의 리더십에 도전하는 것입니다.

반응​

  • Jeff Johnson은 Apple의 무응답, 버그 신고 묵살, 버그 검색 불가 등 몇 가지 중요한 문제가 개선될 때까지 Apple 개발자들을 모아 Apple의 피드백 도우미를 보이콧할 것을 촉구하고 있습니다.
  • 이 보이콧은 개발자들이 시스템 문제에 대한 새로운 피드백을 제출하되 기존 피드백에 대한 답변은 자제하도록 장려하며, 개발자들이 애플 제품을 테스트하고 개선하는 데 중요하지만 무보수로 기여하고 있다는 점을 강조합니다.
  • 존슨은 이번 불매운동이 애플의 엔지니어를 겨냥한 것이 아니라 애플 경영진이 버그 보고 시스템을 인정하고 개선하도록 압박하는 데 목적이 있다고 설명했습니다.
