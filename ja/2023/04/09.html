カルチャーアンプでエルムを退社させる理由と方法​

オリジナル。 カルチャーアンプは、同社のエンジニアリングリードによって推進されていたにもかかわらず、4 年後に新しいフロントエンドコードのための優先言語として Elm を引退しました。この動きは、カルチャーアンプのデザインチームが、同社のフレームワークを要求する Web Components で、再利用可能なユーザーインターフェイスコンポーネントの言語にとらわれないライブラリを構築しようとしたことによるものです。カルチャーアンプは、完全に React のコードベースを持つ企業を買収したことと、TypeScript が Elm の状態管理にマッチしていることから、React にこだわることを選択しました。カルチャーアンプの決定は、新規プロジェクトで TypeScript の React を選択する傾向が強まっていることを反映しており、Elm はテックレーダーで「採用」から「封じ込め」のステータスに移行するかもしれません。エンジニアは、Elm がもたらす複雑さを理由に、Elm を封じ込めるという決定を支持しました。

Discussion Service。 カルチャーアンプが特定の言語を好む求職者を不採用とする決定を下したことで、Discussion Service では賛成派と反対派の議論が巻き起こっています。ある技術に熱中しすぎることを戒め、専門性を示す実際の指標に注目することを勧めるユーザーもいます。エルムの課題と衰退が議論され、他の言語への提案もある。Discussion Service コメントでは、企業文化、デザインシステム、技術スタックの選択について議論されています。元 Elm ユーザーは TypeScript に乗り換えた経験を語り、2 つのフレームワークを維持することが困難な企業は Elm を廃止することを決定しました。編集者は政治的、宗教的な発言を避け、技術に詳しい読者の興味を引くような重要なポイントをとらえる必要があります。

強化学習を用いた Google ReCAPTCHA v3 のハッキング(2019 年)​

オリジナル。 研究者らは、Google の reCAPTCHA v3 をバイパスする強化学習手法を開発した。 問題をグリッド世界として定式化する際、エージェントはマウスの動かし方と reCAPTCHA ボタンをクリックして高得点を得る方法を学習できるため、この手法ではどのグリッド解像度に対してもこのキャプチャシステムを破るための分割・征服戦略を行っている。提案手法は、100x100 のグリッドで 97.4%、1000x1000 の画面解像度で 96.7%の成功率を達成した。また、セルサイズを大きくすると、エージェントの性能が低下することも示している。
