2023 年 3 月 27 日​

データ圧縮のパイオニア、ジェイコブ・ジブ氏が逝去。​

  • 可逆データ圧縮アルゴリズム LZ ファミリーの共同発明者であるコンピュータ科学者の Jacob Ziv 氏が亡くなりました。
  • Ziv の研究は、現代のデータ圧縮技術の基礎を築き、信号処理に貢献し、多くの賞を獲得した。
  • Hacker News のコメント欄には、技術の進歩、クリエイターの死、業界の技術導入の関係について考察している人もいます。
  • 指導やサポートは重要だが、特定の科目を子どもに強制することは、学習経験に悪影響を及ぼす可能性があると指摘するコメントもある。
  • 圧縮やコンパイラの記述など、リソースを効率的に利用する能力は、技術が物理的な限界に達するにつれて、ますます重要になるであろう。
  • ムーアの法則の終わりが近づくにつれ、プログラマーは効率、スピード、パフォーマンスを考慮する必要が出てくる。
  • Ziv の研究は、より効率的なデータの保存と転送を可能にし、ZIP、PNG、GIF、Zstandard といった一般的な圧縮方式に使用されました。
  • Discussion Service で議論する または 原文を読む

ストリートビューでウクライナの戦況を捉える​

  • Undeniable Street View プロジェクトは、Google ストリートビューの技術を用いて、ウクライナ戦争による破壊の様子を撮影し、民間人やインフラへの影響を明らかにするものです。
  • プロパガンダは戦争に関する世論に影響を与え、破壊をロシアの侵略ではなくウクライナ軍のせいとする人もいます。誤った情報に対抗し、戦争の複雑さへの理解を促進するためには、批判的思考と正確な情報が必要です。
  • ウクライナ紛争をめぐる議論では、誰が悪いのか、プロパガンダへの懸念、複数の情報源の中で真実を理解することの難しさなどが議論されている。
  • ウクライナ紛争は複雑であり、議論の参加者の間に認知的不協和が生じ、何が真実で何がプロパガンダによるものかを判断することが困難になっている。
  • ブダペスト覚書とミンスク Ⅱ 協定は紛争中に破られ、ロシアは帝国主義に走り、クリミアを併合した。西側諸国の仲間入りをしたことで、周辺諸国は健全な経済を持つ民主主義国家となったが、ロシアの影響下にあり続けることで、自由がなく、腐敗が進むことになった。
  • 現在進行中のウクライナとロシアの紛争は、一定の条件が整うまで続くが、紛争の終結に関する憶測は明確ではない。
  • 最近ウクライナのルハンスクで起きた爆発は、ロケット弾によるものと思われるが、誰が犯人なのか決定的な証拠はない。
  • 紛争に関する議論には、中国の鉄鋼の品質や、紛争がウクライナの都市や地方に与える影響に関する議論も含まれる。
  • Discussion Service で議論するまたは原文を読む

Liberator を使って Apple Notes を Json として抽出する。​

  • Apple Notes Liberator は、Apple Notes からデータを抽出し、JSON として保存することができる新しいツールです。
  • このツールは、Apple Notes を主なメモ書きアプリケーションとして使用している研究者が、構造化されていないメモを取り込むのに役立ちます。
  • ユーザーからは、Apple Notes がシンプルなメモアプリから、共有メモや複数同時編集のための CRDT のようなアルゴリズムを持つ現在のデータベース構造へと進化したことが強調されました。
  • このツールは、ノートを一括してエクスポートしたり、ノートのエコシステム外で使用できる形式に抽出することが困難であるという Apple Notes の問題に対処しています。
  • このプログラムは、抽出された情報を、Apple Notes を表すオブジェクトの配列を含む notes.json ファイルに保存し、将来的には、さらなるデータ型や CSV や HTML などの出力形式をサポートする予定です。
  • Discussion Service で議論するまたは原文を読む

Blendergpt を使った自然言語コマンドで Blender を操作する。​

  • BlenderGPT は、OpenAI の GPT-4 が生成する自然言語コマンドを使って Blender を操作できる AI ツールですが、生成されたコードが必ずしも正しいとは限らないため、反復作業が必要です。
  • このツールは、ノンプログラマーが簡単なデザインやアニメーションを作成するのに便利ですが、Blender の API の知識が必要な、より複雑で精密な作業には十分でない場合があります。
  • AI と自動化の発展により、ソフトウェア開発の自動化が進み、未熟な労働者が機械に取って代わられる可能性があり、仕事の将来やソフトウェア産業で成功するために必要なスキルについて疑問が呈されています。
  • 特定の作業が自動化されることで、より複雑で創造的な作業に時間を割くことができ、業界や経済全体に利益をもたらすという意見もあります。
  • プログラミングのための自然言語インターフェースの可能性についての議論は、必要とされる具体性や精度の欠如を中心に展開されますが、明示的な記号的アプローチや、フレームワークメーカーによって「認可された」大きなビジネスロジックブロックをつなぎ合わせるために LLM を使用することを提案する人もいます。
  • OpenAI の GPT は、ChatGPT の助けを借りて自然言語のクエリから Blender コマンドを生成できるようになり、3D モデリングソフトウェアでデザインするための UI やその他のユースケースに革命を起こす可能性があります。
  • GitHub の BlenderGPT リポジトリには、OpenAI の GPT-4 で Blender を制御するための自然言語コマンドを可能にする拡張機能がホストされていますが、ユーザーはコードを再度実行する必要があり、有効な OpenAI API キーが必要になる場合があります。
  • Discussion Service で議論する または 原文を読む

Nvidia: 暗号通貨は社会に役立たない​

  • Nvidia の最高技術責任者である Michael Kagan は、暗号通貨は社会に何の役にも立たず、チャットボットの方が処理能力を有意義に使えると考えています。
  • Nvidia は、AI 研究者やゲーマーへの供給を優先するため、2021 年にイーサリアム暗号通貨を採掘するためのグラフィックスカードの使用を制限した。
  • ケイガンは、暗号を人類に利益をもたらさない高頻度取引と比較した。
  • Nvidia の製品は、新しい AI システムを訓練するプロセスを大幅にスピードアップする能力により、AI ブームに貢献するようになりました。
  • 同社は AI に特化したプロセッサを Microsoft、Amazon、Oracle に数万個販売しており、8 台の H100 のクラスタで月額 37,000 ドル弱から始まる DGX クラウドサービスを通じてチップへのアクセスを直接レンタルしています。

Ai の生産性向上と産業界への潜在的影響：考察​

  • AI は、コンテンツを素早く簡単に生成するなど、生産性やマーケティングに活用されている。
  • 言語モデル(LLM)は、ビジネスの特定の側面を自動化する可能性を持っていますが、その有用性についての意見はさまざまです。
  • マーケティングや製品レビューにおいて、AI が生成したコンテンツの品質や過剰利用の可能性が懸念されている。
  • AI モデルの学習に著作権で保護された画像を使用することの合法性や訴訟の可能性についての疑問が提起されている。
  • AI 言語モデルがソフトウェア開発業界に与える潜在的な影響について議論がなされている。
  • ChatGPT は、雇用の奪い合いや生産性向上の懸念など、さまざまな業界に影響を与える可能性が議論されている。
  • AI は生産性に大きな影響を与える可能性があるが、適切な管理・配慮が必要である。

チャット＆インタープリター トランスフォームソフトウェア開発​

  • ChatGPT とコードインタプリタは、ソフトウェア開発を変革する可能性を秘めているが、いくつかの制約がある
  • 言語モデルの出力を促すために熟練した人材が必要であり、プログラミングには単なるコード生成だけではありません。
  • 言語モデルは、人間の開発者から AI を搭載したアシスタントに作業の一部を移行させることができるが、人間の開発者を置き換えることはできないので注意が必要である
  • OpenAI の GPT-4 プラグインシステムは、プログラムの実行、アプリケーションの作成、複雑さの異なる質問への回答が可能です
  • コード解釈のための機械学習モデルとしての ChatGPT と、プログラミング言語インタプリタとしての実装について、開発者が語る
  • OpenAI は ChatGPT のプラグインを開発し、コードやサードパーティのプラグインをプラットフォーム上で実行できるようにしており、すでに様々なタスクで素晴らしい可能性を示しています。

ガイド Llama を使った Openai の Chatgpt プラグイン​

  • OpenAI は ChatGPT のプラグインのサポートをリリースし、言語モデルが API を使って外の世界と対話することを可能にしました。
  • このガイドでは、OpenAI の chatgpt-retrieval-plugin と Meta の LLaMA 言語モデルを使用した概念実証を示します。
  • このアプローチの限界は、モデルの違いや他のプラグインへの一般化の難しさなどです。
  • ステップバイステップのガイドには、データストアの設定、ファイルのアップロード、LLaMA の設定、LLaMA を使ったカスタムデータへの問い合わせ、さまざまな設定の実験が含まれています。
  • lastmile ai チームは、基礎モデルとプラグイン/拡張機能の間の相互作用を標準化するための基礎モデルプラグインプロトコル標準の必要性を探っています。

Blake3 による部分的なファイル重複排除のための Sqlite の利用​

  • あるユーザーが SQLite を使って部分的なファイル重複排除を行ったことをきっかけに、別の重複排除方法や、ゲームのファイル更新を処理する際の課題についての議論が始まった。
  • 解決策として、クラスタ複製された SQLite やコンテンツ定義のチャンキングが挙げられ、全ファイルベースのストレージと比較した重複排除の分析も共有された。
  • また、開発者がコンテンツを更新する際のユースケースに関心が寄せられ、ブロックレベルとファイル全体の重複排除、Steamworks 開発者向けのアライメントの考慮など、技術的な詳細が議論された。
  • 筆者は、BLAKE3 ハッシュ関数と複雑なクエリを用いて類似ファイルをマッチングさせるアプローチを採用し、よりシンプルな代替案よりも容量を節約することに成功した。
  • 他のコメントでは、データセットがメモリを超えた場合のファイルの重複排除や、システム管理データの保存など、SQLite の型破りな使用例を紹介しています。
