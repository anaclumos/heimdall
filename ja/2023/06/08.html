2023 年 6 月 8 日​

Windows 11 では、ZIP ファイルをイギリス英語で「postcode file」と呼んでいます​

  • Windows 11 がイギリス英語で zip ファイルを「postcode」ファイルと呼んでいることがツイートで公開され、地域による言語の違いについて議論が交わされるようになる。- ユーザーは、AI ベースの言語モデルと正規表現によるテキスト置換の比較や、WinRAR や 7-Zip などのファイル圧縮ツールの使用について議論します。- また、アメリカ英語とイギリス英語のスペルや言語的な違い、アクセントの違い、測定方法、温度の単位などについても議論されています。

Deepmind Alphadev: Faster sorting algorithms discovered using deep RL​

  • AlphaDev は、DeepMind の研究者が作成した AI プログラムで、深層強化学習を使って効率的なソートアルゴリズムをゼロから発見・生成します。- AlphaDev のアルゴリズムは、ソート時間を最大 70％削減することを実証し、世界中の数百万人の開発者が使用する LLVM 標準 C++ソートライブラリに追加されました。- 新しい研究では、AlphaDev で使用されている異なるアルゴリズムの能力を比較し、アセンブリプログラムの最適化における深層強化学習の利点と限界を探っています。AlphaDev のすべてのアセンブリ実装、疑似コード、ポリシーの実装、ネットワークは Github でアクセスできます。

業界の反応​

  • Deepmind の AlphaDev チームは、深層強化学習を用いた新しいソートアルゴリズムを発見し、LLVM libc++ソートライブラリを短い配列で最大 70%、大きな配列で 1.7%改善しました。- このリリースのインパクトや主張を「大げさだ」と批判する人もいれば、RL によるアルゴリズムの発見は大きな成果だと考える人もいます。- DeepMind の研究は、学術界で認識されている誇大広告やインパクトに関する様々なコメントや議論、また囲碁クラブやオンラインサーバーといった分野への AI の影響に関する議論を呼び起こしました。

uBlock Origin 1.50.0​

  • 様々な修正と変更を加えた uBlock Origin 1.50.0 がリリースされました。- 今回のアップデートでは、属性の削除機能や、MAIN または ISOLATED ワールドでのスクリプトレット注入機能などの新機能が追加されています- Firefox、Chromium、Edge、Opera で利用可能で、一部のプラットフォームではインストールとレビューが保留されています。

業界の反応​

  • uBlock と uBlock Origin の比較- uBlock Origin は本格的でオープンソースであるためおすすめ- アドオンアップデートでアドウェア/マルウェアの拡張機能が転売される可能性がある

Reddit が最近発表した API 変更と、/r/blind の未来​

  • r/blind コミュニティは、視覚障害者のモデレーターやユーザーが使用するようなサードパーティアプリに影響を与える、Reddit の最近の API 価格変更に抗議しています。- 視覚障害者のコミュニティを代表して Reddit の認識を高め、行動を促すために、MOD チームは他の影響を受けるサブレディットと連帯して、6 月 12 日から 14 日までの 48 時間、サブレディットを閉鎖します。- ユーザーとモデレーターは、視覚障害者のためのアクセシビリティとインクルーシビティへの影響を懸念しています。

業界の反応​

  • Reddit は、障害者ユーザーに対するアクセシビリティの欠如に対する批判に直面しており、ボランティアや長年のモデレーターに対する敬意が欠如しているとの懸念が提起されています。- モデレーターが使用する重要なツールの削除は、マネタイズして利益を得ようとする試みとみなされ、不信感や不満につながる。- また、サードパーティ製アプリの制限や、Reddit の変更による潜在的な法的影響についても議論され、テック業界における利益とアクセシビリティの間の緊張関係が浮き彫りになっています。

英国海軍、量子航法テストは成功したと発表](https://thequantuminsider.com/2023/06/06/royal-navy-says-quantum-navigation-test-a-success/)​

業界の反応​

  • 英国海軍は、重力定数 g の変動を利用した量子航法のテストに成功し、航行精度を向上させ、潜水艦が GPS のために浮上する必要性を減らす可能性があるとしている。- ボース・アインシュタイン凝縮体(BEC)重力マップを使用することで、GPS のために浮上することなく超高精度なナビゲーションが可能になり、INS のドリフト誤差を低減して移動を高速化する可能性があります。- 重力場をナビゲーションに利用するには、標高測定の精度や外的要因によるノイズ信号など、潜在的な制限や課題がありますが、英国海軍は原子干渉計や慣性航法を活用した次世代ナビゲーション技術の開発に取り組んでいます。

"I don't care about cookies" extension bought by Avast, users jump ship​

  • Avast が "I don't care about cookies "拡張機能を買収し、ユーザーからプライバシーに関する懸念が表明されています。- ユーザーは Consent-O-Matic や "I still don't care about cookies "などの代替アドオンの使用を推奨しています。- 一部のユーザーは、拡張機能に関する問題や、データ収集に関する Avast の歴史に関する懸念を報告しています。

業界の反応​

  • Avast が「I don't care about cookies」を取得したことで、データプライバシーポリシーや所有者の変更に対する懸念から、ユーザーが代替オプションを求めるようになりました。- 所有者が変わった場合、拡張機能のアップグレードにユーザーの承認を必要とするようなポリシー変更を行うべきであるとか、自動更新を避けるためにオープンソースソフトウェアを使用すべきであるといった意見もあります。- 拡張機能の販売は、インフォームド・ユーザーの同意や、商業当事者とユーザー間のコミュニケーション不足について疑問を投げかけている。

Apple のゲーム移植ツールキットは素晴らしい。サイバーパンク 2077 を M1 MBP でウルトラで](https://twitter.com/isaacmarovitz/status/1666209780031971341)​

業界の反応​

  • Apple のゲーム移植ツールキットは、専業ゲーマーを主なターゲットとしておらず、カジュアルゲーマーを対象としています。- Apple は、Codeweavers、Valve、および広範な Linux コミュニティのオープンソースの取り組みを適応させながら、独自のゲームスタックを構築しました。- M1 Max チップは、ゲームにおいて 5,000 ドルの Mac Studio を凌駕しますが、Nvidia RTX 3090 を搭載した PC を構成すれば、2,000 ドル以下の価格帯でさらに優れた GPU スループットを提供できます。

Apple、最初の iOS 17 と macOS 14 のベータ版で 99 ドルの開発者アカウント要件を撤廃​

  • Apple は、最初の iOS 17 と macOS 14 ベータにアクセスするための 99 ドルの開発者アカウント要件を削除しました。- ベータへのアクセスは Apple ID に紐付けられるようになり、Apple ID で Apple の開発者サイトにサインインすれば、誰でも iOS 17 や macOS Sonoma などの OS の開発者向けベータビルドに無料でアクセスできるようになりました。- ベータ版のインストール方法は昨年から変更されており、初期の開発者向けビルドのインストールは自己責任でお願いします。

業界の反応​

  • Apple は、iOS 17 と macOS 14 のベータテスト用に App Store にアプリケーションを提出するための 99 ドルの開発者アカウント要件を削除しました。- この変更は、発展途上国の開発者や趣味の開発者に利益をもたらす可能性があるが、一部の開発者は、他の料金や要件が非商業的な開発を制限していると主張している。- iOS と macOS の新しい開発者向けベータ版は、開発者アカウントなしでダウンロードできるようになりましたが、開発者以外の人は、潜在的な悪意のあるソフトウェアの警告やアップデートの要求などの障壁に直面するかもしれません。

macOS での DirectX 12 対応​

  • この文章には、最先端の技術ニュースや macOS の DirectX 12 サポートに関する情報などに関する内容は含まれていません。- 本ウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。- 記事を読むには、ウェブサイトを訪問してください。

業界の反応​

  • Apple は macOS で DirectX 12 のサポートを導入し、Vulkan の翻訳に頼らず、Metal API への翻訳を可能にしました。- この動きは開発者やゲーマーから注目を集めており、Apple が独自のグラフィックス技術である Metal をサポートしていることから、この動きに疑問を呈する声もある。- また、Apple は、Mac プラットフォームでのゲーム開発を推進する一環として、開発者が Windows ベースの DirectX 11 および 12 のゲームを macOS に変換するための Game Porting Toolkit を発表しています。

SEC、Binance.US の資産を凍結・送還する緊急拘束命令を付与​

  • 米国証券取引委員会(SEC)は、バイナンスに対して 13 件の告訴を行った翌日、Binance.US の資産を凍結する緊急拘束命令を提出しました。- この命令は、SEC が同社に対する訴訟を解決するまで、Binance.US の顧客の資産を保護し、米国内に留まることを保証することを目的としています。- 裁判所は SEC の要求を認め、バイナンスの事業体である BAM Management と BAM Trading の資産を事実上凍結し、Binance.US の顧客のために米国外に保有する資産を本国送還することを要求しています。

業界の反応​

  • SEC、Binance.US の資産凍結と本国送還のための緊急拘束命令を付与- 暗号コミュニティが投機や犯罪を超えた暗号通貨の用途を開拓できていないことに対する批判。- 暗号通貨に対する懐疑的な意見、その金融的な可能性を活用することへの関心、規制の欠如に対する批判など、さまざまな意見がある。
