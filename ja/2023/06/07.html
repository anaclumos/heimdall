2023 年 6 月 7 日​

Reddit のサードパーティ製アプリを殺す計画は、広範な抗議を呼び起こす​

  • サードパーティアプリに API 料金を課すという Reddit の計画は、ユーザーからの抗議と反発を呼び、数百の subreddit が 6 月 12 日に 48 時間暗転する予定です。- サードパーティアプリは、多くの開発者が他のサイトの料金をはるかに上回る高額な API 価格に直面し、閉鎖に追い込まれる可能性があると述べています。- Reddit の公式アプリは一般的にサードパーティのオプションより劣ると考えられており、API 条件もサードパーティアプリの広告をブロックすることや、サイトの大きな魅力であるアダルトコンテンツを除外することを求めています。

業界の反応​

  • Reddit は、ローカライズされたバージョンのサブレディットのエンゲージメントを人為的に高めていると非難されていますが、これは、ユーザーを公式アプリに誘導し、上場前に知覚価値を高めるという戦略に沿ったものだと批判されています。- ユーザーは、Discord や Twitch に似た資金調達モデルを導入し、ユーザーがサブレディットのアップグレードにお金を払うことを可能にし、その一部をモデレーションの資金として使用することを提案しています。- 投稿では、Reddit のモバイルアプリとウェブサイトについて議論しており、ユーザーは問題の修正に優先順位が与えられていないことに不満を表明し、同社の優先順位に対する批判を述べています。

GGML - AI at the Edge​

  • GGML は、通常のハードウェアで大規模なモデルと高いパフォーマンスを実現する機械学習用のテンソルライブラリで、Apple Silicon アーキテクチャに最適化されています。- 16 ビット浮動小数点と整数の量子化をサポートし、最適化アルゴリズムを内蔵し、WebAssembly と WASM SIMD による Web サポートを提供します。- 音声合成用の whisper.cpp と言語モデリング推論用の llama.cpp の 2 つのプロジェクトが含まれており、どちらも Apple Silicon ハードウェア上で効率的な性能を発揮しています。

業界の反応​

  • CPU 上で機械学習モデルを実行するためのライブラリである GGML は、VC から大きな資金援助を受けており、コモディティハードウェア上で効率的な計算を行うことができます。- オープンコアのビジネスモデルや、企業とコミュニティの利害が一致しない可能性についての懸念が提起されている。- Willow と Home Assistant は、ローカルコマンドの検出と音声認識のための GGML に代わる選択肢であり、異なる選択肢を比較するためのベンチマークが必要である。

米 SEC が Coinbase を提訴、Binance 提訴の 1 日後に​

  • 米国証券取引委員会(SEC)は、暗号通貨プラットフォーム Coinbase を提訴し、暗号取引に関する中間業者として運営し、投資家を保護するための開示要件を回避していると非難しました。- この訴訟は、世界最大の暗号通貨取引所である Binance に対する同様の訴訟に続くもので、Binance とその CEO が "欺瞞の網 "を運用していたとして非難しています。- SEC がいずれかの訴訟で勝訴すれば、大部分が規制外で運営されてきた暗号業界に対する管轄権を主張し、市場を一変させる可能性があります。

業界の反応​

  • SEC は Coinbase に対して、未登録の証券を取引し、法的基準を満たしていないとして訴訟を起こした。- この問題は、特定の暗号通貨が証券や金融商品の定義に合致するかどうかを中心に展開されている。- SEC は、何が証券で、何が証券でないかについてのガイダンスを提供していないため、企業は法令遵守への明確な道筋がないままになっています。

到来するコンピューターショッパー津波に備える​

  • コンピュータ史の専門家であるジェイソン・スコット氏は、1980 年代から 1990 年代にかけて、ハードウェアとソフトウェアの「バイブル」として人気を博した雑誌「コンピュータ・ショッパー」の 200 冊近い号を入手した。- Scott 氏は、少なくとも 10 万ページ以上になるであろうこの号をスキャンし、Gaming Alexandria 社に送り、より読みやすいバージョンにするための後処理を依頼する予定である。- 研究者たちは、保存された雑誌からコンピューティングの歴史を分析し、興味深い情報や傾向を見つけることを目指しており、読者には、欠けている号の寄付を広めることに協力してもらうよう呼びかけています。

業界の反応​

  • Internet Archive の Computer Shopper コレクションは、人気テクノロジー雑誌の遺産を保存しているとして賞賛されています。- コメント欄には、コンピュータのパーツを選んだり、地域の掲示板システムを探したりするために雑誌をめくっていた昔を懐かしむ声が寄せられています。- 読者は、歴史的なコンピュータ雑誌、特にコンピュータショッパーをデジタル化することで、歴史的な PC の価格やハードウェアの入手方法に関する貴重な情報を得ることができると述べています。

朝日 Linux で OpenGL3.1​

  • Asahi Linux は、グラフィックドライバを OpenGL 2.1 から OpenGL 3.1 にアップグレードし、OpenGL ES 2.0 のサポートを OpenGL ES 3.0 に増加しました。これにより、より高品質なレンダリングと、より高機能なアプリケーションを実現します。- ただし、ドライバは実験的なもので、OpenGL や OpenGL ES の仕様にまだ準拠していないため、ユーザーはバグに遭遇する可能性があります。- 今回のアップグレードのハイライトは、複数のレンダーターゲット、マルチサンプリング、トランスフォームフィードバック、テクスチャバッファオブジェクトです。具体的には、マルチサンプリングは、不十分な解像度でレンダリングすることにより、斜めのエッジがギザギザになることで生じるエイリアシングを効率的に低減する方法である。各ピクセルに対して複数のサンプルを作成し、それらを平均化することで正規の画像を作成します。しかし、Apple の AGX GPU はサンプルシェーディングに独自のアプローチを必要とし、ブレンドとマルチサンプリングが有効でサンプルシェーディングが無効の場合、ブレンドがパフォーマンスを後退させることがあります。

業界の反応​

  • アサヒリナックス社が、M2 Pro/Max/Ultra SoC のベースサポートや、ファームウェアベースの新しいバッテリー充電制御方法など、様々な機能を搭載したアップデートを公開しています。- Apple のハードウェアのユーザーは、その上で Linux を自由に動かせることに感謝していますが、Asahi の持続可能性や、それを動かすためだけに Mac を購入する価値があるかどうかについては、議論があります。- Asahi Linux は大きな進歩を遂げましたが、パフォーマンスに影響を与える GPU ドライバーの制限や非互換性はまだ残っています。

タコ、カニ、ロブスターが英国の法律で感覚を持つ存在として認められる(2021 年)​

  • タコ、カニ、ロブスターが英国の法律で感覚を持つ存在として認識されました。- これは、これらの動物が痛みや苦しみを感じることができ、それに応じて扱われなければならないことを政府が認めたことを意味します。- また、新法では、ロブスター、カニ、ザリガニなど、人間が食べるための生きた甲殻類の販売・流通が禁止されました。

業界の反応​

  • 英国は、特に無脊椎動物に対する動物福祉の向上を目的とした新しい環境対策のもと、タコ、カニ、ロブスターを感覚を持つ存在として認めています。- この新法は、衝撃を与えない生茹で、訓練を受けていない取扱者への十脚甲殻類の生売り、脱爪などの特定の行為を禁止しています。- 新しい分類は、最終的にすべての動物の苦しみを減らすことにつながる可能性がありますが、生きた甲殻類の食用禁止や食肉産業の慣行の改善には懐疑的な意見もあります。

Reddit、レミーの移住を提唱するユーザーのアカウントを永久に禁止​

  • Reddit は、レミーを支持し、その投稿を検閲しているユーザーのアカウントを永久追放しました。- このユーザーは複数のサブをモデレートしており、Reddit の繁栄を支えるコミュニティの改善に数え切れないほどの時間を費やしていましたが、その苦労が突然 Reddit によって奪われたのです。- この事件は、Reddit のような中央集権的なプラットフォームに依存することのデメリットと、Lemmy のような分散型の代替手段を使うことのメリットを浮き彫りにしています。Lemmy では、個人が自分のインスタンスをホストしたり、検閲された場合は別のインスタンスに参加することができます。

業界の反応​

  • Reddit では、プライバシーを重視したソーシャルメディアプラットフォーム Lemmy への移行を提唱したユーザーを追放し、Reddit のような既存のサイトと競合する、連合型かつサーバー管理型のソーシャルメディアプラットフォームの利点と欠点に関する議論を呼び起こしました。- マストドンを Reddit の代替として提案するユーザーもいますが、使いにくさやモデレーションの欠如を批判しています。- Reddit の代替となるフェデレーション型オープンソースとしての Lemmy の限界とスケーラビリティの問題について、トラフィックの急増に対応する能力についての懸念がユーザーによって議論されています。

アップルビジョン​

  • Apple は、新しい複合現実ヘッドセット「Apple Vision」を発表し、2024 年初頭に 3,499 ドルで発売する予定であることを明らかにした。- このデバイスは体験的には VR デバイスであるが、12 個のカメラを使って AR を実現し、時間遅れの少ない高品質の没入体験を提供する。- Apple Vision Pro は、生産性や仕事に対する可能性を持っていますが、コンテンツの制作や社会とのつながりの欠如という課題に直面する可能性があります。

業界の反応​

  • Apple は、12 台のカメラ、手持ちのジェスチャー認識コントロールを搭載し、ライブ体験、ゲーム、生産性に焦点を当てた新しい VR/AR ヘッドセット「Apple Vision」を発表しました。- このヘッドセットは、教育、ストリーミング、装飾、リラクゼーションなどの使用例が考えられるが、孤独感や 3,500 ドルという高額な費用を心配する批評家もいる。- このデバイスに対する意見は、エンターテインメントやヘルスケアの可能性に対する興奮、プライバシーに対する懸念、技術革新を推進するポルノの歴史、人間工学に基づいたデザインや乗り物酔いなどの実用的な問題など、さまざまな意見があります。

米国、無傷の宇宙人の乗り物があると主張した後、UFO の証拠を明らかにするよう促される​

  • 米国の元情報機関職員である David Grusch 氏は、米国政府が「無傷および部分的に無傷の」宇宙人の乗り物を所有しているが、それに関する情報を議会から違法に隠していると主張した。- グラッシュ氏は、これらの乗り物に関する機密情報を議会に提供した後、政府の報復に遭ったと主張し、4 月に退職することになりました。- 現在の米国情報当局者であるジョナサン・グレイは、「異質な物質」の存在を確認したが、これらの車両や物質の場所については明言していない。

業界の反応​

  • 元政府高官、米国が墜落した宇宙人の宇宙船を回収し、その技術を秘密裏に研究していると主張- 地球外生命の可能性については、懐疑的な見方、陰謀論、伝聞がまかり通っている- 軍による最近の情報公開は、地球外生命体の存在や訪問を示す具体的な証拠を示していない

Nvidia、480GB の CPU RAM、96GB の GPU RAM を搭載した新しい AI チップをリリース​

  • Nvidia は、大規模 AI および HPC(High-Performance Computing)アプリケーション向けに設計された新しい AI チップ「Grace Hopper Superchip」をリリースしました。- このチップは 480GB の CPU RAM と 96GB の GPU RAM を誇り、AI と HPC タスクのための市場で最速のチップの 1 つとなっています。- このチップは、初期のコンピュータとプログラミング言語の開発に貢献した米国のコンピュータ科学者グレース・ホッパーにちなんで命名されました。

業界の反応​

  • Nvidia は 480GB の CPU RAM と 96GB の GPU RAM を搭載した新しい AI チップをリリースし、スーパーコンピューターとして賞賛されています。- ML ワークロードのために GPU から ASIC に移行する可能性が議論されているが、ASIC の限界から GPU の方が無難である。- Nvidia の新しい Grace Hopper スーパーチップは、CPU と GPU を組み合わせ、72 個の Neoverse V2 Armv9 コアを搭載し、AI、HPC、ゲームアプリケーション向けに設計されています。
