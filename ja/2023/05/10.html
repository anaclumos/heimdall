10

2023 年 5 月 10 日​

アップル、Final Cut Pro と Logic Pro を iPad に対応​

  • Final Cut Pro と Logic Pro for iPad は、ビデオや音楽のクリエイターのために設計されたパワフルなツールで、究極のモバイルスタジオ体験を提供します。
  • これらのアプリケーションは、iPad の即時性と直感的なマルチタッチジェスチャーでワークフローを向上させることができるタッチファーストインターフェイスを導入しています。
  • Final Cut Pro for iPad は、ビデオクリエイターのための新しいツールを導入し、ビデオの撮影、編集、仕上げ、共有を可能にします。Logic Pro for iPad は、作曲、ビートメイキング、録音、編集、ミキシングのための洗練されたツールの完全コレクションを提供します。

業界の反応​

  • Logic Pro X for iPad のリリースは、タブレットでの音楽制作にとって画期的なことですが、最終的なオーディオのミキシングと制作に関しては、ユーザーはデバイスの制限に注意する必要があります。
  • Apple は、同社のアプリ、特に Final Cut Pro と Logic Pro を、それぞれ月額 4.99 ドルまたは年額 49 ドルのサブスクリプションモデルに移行しています。

言語モデルでニューロンを説明できる​

  • 研究者は、GPT-4 を使用して、言語モデルにおけるニューロンの動作の自然言語説明を生成し、スコア化する自動化プロセスを提案する。
  • 彼らはこのプロセスを使って、研究用のオープンソースデータセットとして公開されている GPT-2 のすべてのニューロンに対する説明とスコアを提供します。
  • その目的は、言語モデルの内部構造に関する追加情報を明らかにすることで、アライメントや安全性の向上に役立てることです。

業界の反応​

  • 専門家は、ブラックボックス化した AI モデルには透明性がないため、空港での嘘発見や薬物検出といった重大な用途には適さないと警告しています。
  • 投稿では、人間の知覚や意識のもろさを論じ、AI が人間に近い意識と推論能力を持つ可能性について議論しています。

10 年後に学ぶ DNS​

  • RubyConf Mini のスピーカーは「10 年で DNS を学ぶ」と題して、難しい概念を学ぶための構造化されたアプローチについて語りました。
  • DNS とは Domain Name System の略で、ドメイン名を IP アドレスに変換するものです。
  • 講演者は DNS を学ぶために、DNS とは何かを議論すること、dig や Wireshark などのツールでスパイすること、混乱して質問すること、仕様を読むこと、実験をすることを勧めています。

業界の反応​

  • ユーザーはこのリソースを賞賛し、DNS に関連するトラブルシューティングの経験を共有しています。
  • また、DNS の設定を無視するアプリケーションの不満や、DoH と DoT の違いについて議論しているユーザーもいます。

アップルは iOS の仮想マシンを禁止しようとした訴訟で敗訴した​

  • 米裁判所、Corellium 社に有利な判決、セキュリティ研究目的のサードパーティ製仮想 iOS デバイスを認める
  • Corellium 社の CORSEC シミュレータは、著作権法のフェアユース・ドクトリンにより保護されています。
  • 開発者が Corellium の VM を使用して、適切なハードウェアを取得せずにアプリケーションを試すことが懸念される。

業界の反応​

  • この判決は、Apple のデバイスの独占と、App Store の販売手数料 30％や支払い方法の制限などのポリシーに疑問を投げかけるものである。
  • アップルは JIT コンパイルや代替ブラウザエンジンを禁止しており、不必要で偽善的と見るユーザーからの批判に直面している。

国連人権総長、英国に「深く悩ましい」公序良俗法案の撤回を要請​

  • このウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。
  • 記事を読むには、ウェブサイトをご覧ください。

業界の反応​

  • 警察は、先日の戴冠式で新法を乱用して平和的な抗議者を逮捕したと批判されています。
  • 新しい警察権限法案は、警察が、座り込みや「絶滅の反乱」のような運動に参加している人々を含む、平和的な抗議をしていない人々を逮捕することを可能にすると批判された。

ジェームズ・ウェッブ宇宙望遠鏡、フォマルハウトの円盤を詳細に解明​

  • このウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。
  • 記事を読むには、ウェブサイトをご覧ください。

業界の反応​

  • JWST は、太陽光がセンサーを圧倒しないように極低温で運用され、最適な観測条件のために太陽と地球のラグランジュ点(L2)を回るハロー軌道に配置されています。
  • JWT の感度は向上し、赤方偏移 11 を超える銀河の観測が可能となり、開口合成や宇宙電波干渉計の能力により、さらに高い解像度が得られ、科学研究の大きな進歩が期待されます。

CheerpJ 3.0: HTML5 と WASM で JVM を置き換え、モダンブラウザ上で Java を実行する​

  • CheerpJ は、開発者が HTML5 と WebAssembly(WASM)を通じて、モダンブラウザ上で Java アプリケーションを実行できるようにする技術です。
  • 最新バージョンである CheerpJ 3.0 では、パフォーマンスが向上し、さらに多くの Java ライブラリや機能をサポートしています。
  • CheerpJ は、企業向けソフトウェアやビデオゲームなど、さまざまなアプリケーションに使用でき、主要なブラウザと互換性があります。

業界の反応​

  • 新しいバージョンは、より良いエンタープライズアピールのためにインタプリタを使用し、カスタムタグをサポートし、JRE は 2.5MB になる。
  • Hacker News でのコメントは賛否両論で、ウェブ開発への悪影響を予測する人もいれば、新しい開発の利点を強調する人もいた。

ビタミン D の日常摂取でがん死亡率が減少​

  • ビタミン D を毎日摂取することで、集団におけるがん死亡率を 12％低減できることが、ドイツがん研究センターが約 10 万 5000 人を対象に実施した 14 の研究の評価で明らかになりました。
  • ビタミン D 欠乏症は世界中で広く見られ、がん患者さんでは頻繁に診断される。
  • ビタミン D3 を毎日投与することでより優れた効果が得られるのは、腫瘍の成長を抑制する活性物質である 1,25-ジヒドロキシビタミン D というホルモンのバイオアベイラビリティがより定期的に得られるためであると説明されている。本研究は、がん死亡予防におけるビタミン D3 投与の可能性を明らかにし、効果的な治療法に関する今後の研究につながる可能性があります。

業界の反応​

  • 最適なビタミン D 濃度は 60 ～ 70ng/ml 程度ですが、欧米では多くの人が欠乏していると言われています。
  • ビタミン D を補給すると、特にビタミン D 欠乏症の人のがん死亡率が低下するが、高用量では効果がない。

Syncthing: A continuous file synchronization program​

  • Syncthing は、2 台以上のコンピュータ間でファイルをリアルタイムに同期させ、不正なアクセスから保護するプログラムです。
  • データは各自のコンピュータにのみ保存されるため、危険にさらされる可能性のある中央サーバーは存在しません。
  • Syncthing は様々なプラットフォームで利用できるオープンソースのプログラムで、使いやすく、デバイス間でデータを同期するための強力なツールとなっています。

業界の反応​

  • ユーザーは Syncthing の信頼性を高く評価していますが、Apple の機能制限のために優れた iOS アプリがないことに不満を表明しています。
  • ユーザーは、iCloud と同様の API を統合するなどの解決策を提案し、Nextcloud、Seedvault、ワーキングコピーなど他のバックアップオプションについても議論しています。

"Tinder for Canceling Meetings"​

  • "会議をキャンセルするための Tinder "として、Cala という新しいアプリが紹介されています。
  • このアプリは、参加者全員が匿名で左にスワイプして会議をキャンセルすることができ、全員が左にスワイプした場合のみ投票内容が明らかになる。
  • Cala は、ユーザーが不必要な会議を避け、集中力を高めることを目的として設計されています。

業界の反応​

  • 会議の直前キャンセルに関する議論では、組織内で生産的な会議を行うための良好なコミュニケーションとガイドラインの必要性が強調されています。
  • Cala の iOS アプリでは、参加者が「スワイプ」して会議をキャンセルすることができますが、一部のユーザーは、アプリをやみくもに使用すると、参加者から有益な最新情報や重要な決定を奪うことになると指摘し、直接フィードバックを提供したり、会議のコストプラグインを作成したりする代替案を提案しています。
