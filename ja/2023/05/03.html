03

2023 年 5 月 3 日​

アイキャンディ​

  • レンズワイプ、POV、ローアングル、ドリーズーム、スクリブルアニメーション、安定した拡散、マッチカット、ティルトなど、アニメーションで使用されるさまざまなクリエイティブテクニックをまとめた記事です。
  • Nike や Ashahi といった有名ブランドの作品や、NBA のショートフィルムなど、キネティックタイポグラフィー、クラッシュズーム、グリッチエフェクト、モーフィング、固定オブジェクト、オブジェクトポータルといった様々なテクニックを適用した作品が紹介されています。
  • また、著名なエドガー・ライト監督にスポットを当て、『ベイビー・ドライバー』『ショーン・オブ・ザ・デッド』『ホット・ファズ』『ラストナイト・イン・ソーホー』といった人気ジャンル映画で見られる、緻密なサウンドデザインとユニークな編集スタイルも紹介しています。

業界の反応​

  • このウェブサイトでは、ベストテクニックをタイプ別に分類してまとめており、ユーザーは新しいテクニックを提案することができます。
  • ユーザーは動画をクリックすることで、業界で使用されている映画撮影のテクニックや選択肢の例を見ることができます。"第 4 の壁"、"ドリー・ズーム"、"オブジェクト・ポータル "などが例として挙げられます。

映画スタジオ、海賊版に関するコメントを書いた Reddit ユーザーのマスクを剥がす入札に敗れる​

  • カリフォルニア州北部地区連邦地方裁判所の判事は、海賊版関連のスレッドにコメントを書き込んだ 8 人の匿名ユーザーを特定する必要はないとし、Reddit に有利な判決を下しました。
  • 映画スタジオは、海賊行為についてコメントした Reddit ユーザーの身元を明らかにすることを求めていましたが、裁判官は、コメントは映画スタジオの訴訟とは無関係であり、他の情報源から関連情報を得ることができるとし、召喚状を破棄したため、敗訴しました。
  • Reddit は、修正第 1 条はユーザーがオンラインで匿名で発言する権利を保護するものであり、この記録は、修正第 1 条が証拠開示を禁止することを示していると主張しました。

業界の反応​

  • Reddit は、原告へのコメント者 1 名を dox したのみで、全員を dox したわけではない
  • Reddit の匿名スピーチ擁護が問題視されています。

Mojo - AI 開発者のための新しいプログラミング言語​

  • Mojo は、人工知能(AI)開発者向けに特別に設計された新しいプログラミング言語で、AI 開発プロセスを合理化し、コードの読み書きを容易にする機能を備えています。
  • ワシントン大学の研究者が開発した Mojo は、AI の研究開発によく使われるグラフィック・プロセッシング・ユニット(GPU)やその他の専用ハードウェア上で動作するように最適化されています。
  • Mojo の開発者は、AI 開発の民主化に貢献し、あらゆるレベルのプログラマーが高度な AI アプリケーションをより身近で容易に作成できるようになることを期待しています。

業界の反応​

  • Mojo は、所有権やガベージコレクションなしなどの技術的な進歩により、現行の Python エコシステムをサポートしつつ、競合他社よりも優位に立つことができます。
  • Mojo は Triton、TVM、OpenXLA、ONNX Runtime との競争に直面しているが、機械学習や AI 開発者に新しい選択肢を提供する。

Fakespot Is Acquired by Mozilla​

  • このウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。
  • 記事を読むには、ウェブサイトをご覧ください。

業界の反応​

  • Firefox は、Chrome や Safari と比較して、機能、性能、シェアの面で遅れているものの、プライバシーに配慮したブラウザと考えられています。
  • ブラウザプロジェクトにエンジニアを増やすのではなく、低品質の AI 生成コンテンツに対抗する技術に投資するという Mozilla の決断は賢明です。

Linux カーネルモジュール プログラミングガイド​

  • Linux Kernel Module Programming Guide は、システムを再起動することなくカーネルの機能を拡張するカーネルモジュールの書き方を解説した無料の書籍です。
  • 本書は、ヘッダー、デバイスドライバ、ファイルシステム、システムコール、割り込みハンドラ、スケジューリングタスクなど、さまざまなトピックをカバーしています。
  • 著者は、すべてのサンプルをコンソールから抽出し、コンパイルし、ロードすることを推奨しています。本書では、マクロ module_init と module_exit の使用を含む、カーネルモジュール設定を扱う新しい方法を紹介し、カーネルモジュールのライセンスオプションについて説明しています。さらに、モジュールはグローバル変数と module_param()マクロを使用して、コマンドライン引数を取ることができます。

業界の反応​

  • eBPF は、いくつかのカーネルモジュールのタスクに対して、より新しく、少し簡単で安全な代替案です。
  • このガイドは、カーネルモジュールについて学ぶための良い出発点ですが、より複雑なドライバを書くことになると、不足するかもしれません。

マイクロソフトが Edge を普及させるために Chrome の機能を壊した​

  • Microsoft が発行した Windows アップデートで Chrome の機能が壊れ、デフォルトのブラウザを変更することが難しくなり、ポップアップで Chrome ユーザーを困らせていることが Gizmodo の取材でわかりました。
  • このアップデートは、Chrome のワンクリック「デフォルトにする」ボタンに影響を与え、企業ユーザーにとっては、Chrome を開くたびに Windows のデフォルト設定ページがポップアップするようになりました。
  • この動きは、Windows 以外のウェブブラウザとそれを使う人々に対して戦争を仕掛けている Microsoft の行動パターンの一部である。

業界の反応​

  • Google はプライバシーサンドボックスを開発しているが、多様な人々への対応とユーザーアイデンティティの保護とのトレードオフのため、この提案は却下された。
  • エンタープライズ版の Windows ユーザーは、API の問題で Chrome を開くたびにデフォルトのシステム設定が開くという経験をし、ユーザーのプライバシーや潜在的な反トラスト行為に対する懸念につながった。

PornHub がユタ州のユーザーをブロック、同州の年齢確認法を理由に​

  • PornHub は、ユタ州の新しい年齢確認法に基づき、同社サイトへのアクセスを希望するユタ州のユーザーに対してブロックを実施しました。
  • この法律は、ポルノサイトにユタ州のユーザーが 18 歳以上であることを確認することを義務付けるもので、これに従わないサイトは、未成年者がアクセスしたことによる損害賠償の責任を問われる可能性があります。
  • PornHub は、ID を要求することはユーザー保護に有効ではなく、かえって子供やプライバシーを危険にさらすと主張し、デバイスによるユーザーの識別がより良い解決策であることを示唆しています。

業界の反応​

  • 年齢認証の取り組みは、ポルノ提供者に大きな負担を求め、プライバシー侵害や記録の作成などの懸念があることから、誠意ある取り組みかどうか、その有効性について議論がなされています。
  • コメントでは、多様性と文化、政府による年齢制限、ペアレンタルコントロール、アダルト素材の表示と分類に関する法律などのトピックを取り上げて議論しています。

GitHub が唯一の選択肢にならないようにしよう​

  • ソフトウェア開発における GitHub の支配的な地位は、1 つの企業に過度のコントロールを与え、代替ツールの使用を制限するため、業界にとってリスクを生む。
  • デフォルトのコラボレーションツールとして Pull Requests(PR)に依存しているため、信頼性の低い文化が生まれ、コラボレーションスタイルが制限される。
  • 単一のプラットフォームで均質化することはリスクであり、開発者は選択肢の多様性とソフトウェア産業の回復力を確保するために、代替ツールを探求し投資する必要があります。

業界の反応​

  • GitLab、Sourcehut、Codeberg など、Git や GitHub に代わる様々な代替プラットフォームが議論されています。
  • 代替プラットフォームの成功は、GitHub の包括的な検索、信頼できるトラッカー、課題トラッカーの統合、基本的なドキュメントの期待に対抗できるかどうかにかかっています。

faulTPM: Exposing AMD fTPM's Deepest Secrets​

  • フラウンホーファー研究所の研究者は、AMD の fTPM(ファームウェアベースの TPM)に faulTPM と名付けられた脆弱性を発見しました。
  • この脆弱性を悪用すると、攻撃者は TPM から暗号化キーやパスワードなどの機密情報を読み取ることができます。
  • AMD は、この問題を軽減するためのファームウェア・アップデートをすでにリリースしており、ユーザーはできるだけ早くシステムをアップデートすることが推奨されます。

業界の反応​

  • コメント欄では、技術の限界、Windows 11 の任意ハードウェアサポート切れ、Windows から Linux ディストロへの乗り換えの実現性など、様々な技術的トピックについて議論しています。
  • 研究者は、AMD の fTPM 実装の脆弱性を公開し、$3 チップ攻撃で悪用されてデータを流出させる可能性があることを明らかにし、自分の脅威モデルを評価し、fTPM や TPM のみのプロテクターに依存する以外の追加のセキュリティ対策を実施する重要性を強調しています。

Jsonformer: LLM から構造化出力を生成する​

  • Jsonformer は、言語モデルから構造化 JSON を生成する新しいアプローチで、生成される JSON が常に構文的に正しく、指定されたスキーマに準拠することを保証します。
  • Jsonformer は、生成過程で固定トークンを埋め、コンテンツトークンの生成のみを言語モデルに委ねることで、既存のアプローチよりも効率的で弾丸のような生成方法を実現しています。
  • Jsonformer は HuggingFace トランスフォーマーライブラリーの上に構築されており、柔軟で拡張可能でありながら JSON スキーマのサブセットをサポートします。

業界の反応​

  • Clownfish や Guardrails といった他の類似の JSON スキーマジェネレーターは、複雑なスキーマに対してより複雑なアプローチを必要とします。
  • Zod は、期待される型を定義し、応答を検証するために使用することができ、「transmogrify」後の Typescript のように推論された静的な型にマッチします。
