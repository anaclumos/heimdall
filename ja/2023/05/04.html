2023 年 5 月 4 日​

MSFT が Outlook と Teams に Edge でリンクを開かせることを強制し、IT 管理者が怒っている​

  • Microsoft は、Teams と Outlook の特定のリンクに Edge ブラウザを使用するよう強制する変更を行い、IT 管理者を怒らせている。
  • この変更は、ユーザーがデフォルトのブラウザではなく、Edge ブラウザで自動的にリンクを開くことを意味します。
  • IT 管理者は、この変更をユーザーに通知し、それに応じてポリシーを変更する必要があります。

業界の反応​

  • マイクロソフトは、Edge を推進する上で、反競争的な行動や「闇のパターン」の歴史があるとして批判されています。
  • しかし、C#や.NET エコシステムといったマイクロソフトのオープンソースツールや VS Code のようなツールを賞賛するコメントもある一方で、ブラウザエンジンの限界やテック企業によるプラットフォームコントロールについても論じています。

It's A(door)able​

  • このウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。
  • 記事を読むには、ウェブサイトをご覧ください。

業界の反応​

  • プレイヤーからの提案として、一方通行のドアや崩れやすい床を追加することで、前に進む動機付けを与えることができる。
  • コメント欄には、比喩的なプログラミングをめぐるユーモラスな議論や、手作り体験のための類似したウェブサイトの共有があります。

銀行破綻の可視化​

  • 記事では、1947 年から 2023 年の間に発生した銀行の破綻を視覚化したものを取り上げています。
  • この視覚化では、破綻した銀行の規模とそれぞれの破綻日の関係が示されています。
  • データは、銀行の規模の大きさをよりよく理解するために、インフレ率で調整されています。

業界の反応​

  • observablehq.com の銀行破綻のグラフの正確さと視覚的表現に疑問、FDIC 以外の銀行破綻を除外することに懸念も
  • FTX は、暗号通貨を中心に構成された 10 億ドル以上の資産をブロックチェーン技術で回収したが、73 億ドルとされる評価額には懸念が残る
  • 意見者の間では、米国における銀行破綻の頻度、銀行の規模やビジネスモデルに焦点を当て、小規模な地方銀行を支持する意見と、より大規模で分散されたポートフォリオを支持する意見がある
  • 記事では、マイク・ボストックの印象的なデータビジュアライゼーション作品に注目しつつ、データの表現として円を使用することの欠点を強調しています。
  • このテーマについてデータや洞察を提供するコメンターもおり、会話は金融の透明性や銀行・暗号通貨業界における不正行為など、さまざまなテーマに触れています。

Replit の新しい Code LLM：オープンソース、Codex より 77%小さく、1 週間でトレーニング​

  • Replit は、OpenAI の Codex よりも効率的で、わずか 1 週間でトレーニングされた新しいコード LLM をオープンソース化しました。
  • Replit の AI 責任者である Reza Shabani は、データプラットフォームである Ghostwriter と、新規採用やスケーリング法などのチームの今後の計画について話しています。
  • 会話の中心は、AI ベースのコード補完ツールである Ghostwriter と、コードを補完するだけではない独自の能力、そして自動化がもたらす社会的影響と、AI が人を置き換えるのではなく、人を助けるようにすることの重要性についてです。

業界の反応​

  • Replit-Code モデルは、OpenAI の Codex や GitHub の Copilot と似ていますが、オープンソースであり、ユーザーの特定のコードベースでトレーニングできるため、特定のタスクのための AI モデルを改善するアプローチとしてより一般的になっています。
  • OpenAI の Copilot では不完全なコードや関係のないコードが生成されることがありますが、オープンソース対応のため特定のライブラリに微調整する機能が提案されています。

WebGPU の話をしたい​

  • WebGPU は、Web ブラウザやその他のソフトウェアで 2D および 3D グラフィックスを作成するための新しい低レベルグラフィックス API としてリリースされました。
  • Vulkan や OpenGL に代わって、あらゆる種類のソフトウェアやプログラミング言語での描画の標準となる可能性を持っています。
  • 初期化やパイプラインの構築においていくつかの制限や複雑さがありますが、WebGPU はより簡単なクロスプラットフォームの GPU プログラミングに期待されています。

業界の反応​

  • また、WebGPU は物理シミュレーションや科学的ワークロードにおける潜在的なユースケースを持ち、宣言型プログラミングモデルもサポートしています。
  • Web 開発者は、グラフィックス・プロセッシング・ユニットへのアクセス向上など、WebGPU を使用することで得られる潜在的なメリットについて議論する一方で、悪意のある活動への可能性について懸念も示しています。

パスキー：パスワードの終わりの始まり​

  • Google は、パスワードよりも使いやすく安全な、アプリやウェブサイトへの新しいサインイン方法である passkeys の展開を開始しました。
  • パスキーは、ユーザーがデバイスのロックを解除するのと同じ方法でサインインすることができ、指紋、顔スキャン、スクリーンロック PIN などのオプションがあります。
  • パスワードとは異なり、パスキーはフィッシングなどのオンライン攻撃にも強いため、より安全です。

業界の反応​

  • パスキーは生体認証を利用して携帯電話のロックを解除し、ユーザーの端末に保存され、同じ Google アカウントにサインインしたすべての端末で同期されます。
  • パスキーを使用するためのオープンソースやサードパーティーのオプションがありますが、プライベートキーをクラウドベースのサービスに保存することは、プライバシーに関する懸念があり、すべてのデバイスへのアクセスを失うことは、データへのアクセスを失うことにつながります。

OpenLLaMA: LLaMA のオープンな再生産​

  • OpenLLaMA は、Meta AI の言語モデル LLaMA を再現した、Berkeley AI Research が公開した新しいオープンソースの言語モデルです。
  • 7B の OpenLLaMA モデルのパブリックプレビューは、2000 億トークンで学習され、Huggingface Hub で PyTorch と Jax の重みで利用できるようになりました。
  • OpenLLaMA は様々なタスクで評価され、オリジナルの LLaMA や GPT-J モデルと同等の性能を示しています。

業界の反応​

  • 一部のユーザーは、llama.cpp と 8GB RAM で使用した場合、Intel ベースの MacOS システムでエラーが発生しました。
  • モデルとデータセットは Apache License 2.0 の下で完全に複製可能であり、研究の透明性を提供し、大規模な技術企業による独占を防止しています。

フレームワーク・ラップトップ 13​

  • Framework Laptop 13 は、AMD Ryzen™ 7040 シリーズプロセッサーを搭載し、信じられないほど素晴らしい CPU と GPU 性能を特徴とする新しいノートパソコンです。
  • Ryzen 5 7640U と Ryzen 7 7840U プロセッサーは、それぞれ 6 コアと 8 コアを搭載しており、非常にパワフルです。
  • このノートパソコンは、最新のゲームを直接扱うことができ、そのグラフィックは市場で最も優れたものの一つです。

業界の反応​

  • 異なるプロセッサー・アーキテクチャに関する議論、キーボードレイアウトやタッチスクリーンのサポートがないことへの失望、消費電力や可用性に関する懸念など。
  • タッチスクリーンやキーボードレイアウトに対するユーザーの嗜好についての洞察で、特に新しい情報や刺激的な情報は投稿されていません。

プログラマのための数学入門​

  • この投稿は、"A Programmer's Introduction to Mathematics "という書籍の情報を提供するものです。
  • この本は、Amazon で物理的なフォーマットで、また有料の PDF 電子書籍として入手できます。
  • 読者は GitHub で各章のコードにアクセスでき、他の読者と演習に関する議論に参加することができます。

業界の反応​

  • プログラミングにおける形式言語と数学的表記法の使用をめぐる議論、数学的言語に対する賛否両論。
  • 研究論文を効果的に利用し理解するための数学的言語の学習の重要性が強調され、非数学者のための数学に関する書籍の勧めも紹介された。

脱ドル化は「圧倒的」なスピードで進行中​

  • このウェブサイトは、直接ウェブサイトを訪問していただくのが一番体験しやすいと思います。
  • 記事を読むには、ウェブサイトをご覧ください。

業界の反応​

  • 脱ドルの動きは、米国経済とその外交政策に打撃を与える可能性があるが、他国にとっての金融リスクと外国の経済政治的影響力を最小化する可能性もある。
  • 多極化する世界における脱ドルの課題と潜在的な影響について、異なる世界の大国の役割、現代の通貨理論、デフレとインフレのメカニズムなどの議論がある。
