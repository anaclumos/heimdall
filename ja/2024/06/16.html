2024-06-16

世界最小で最安のネットワークスイッチを作りました​

  • MUREX Roboticsは、ニューハンプシャー州エクセターの高校チームで、JLCPCBから6.9ドルで入手可能なオープンソース技術を公開しました。
  • 彼らは25台未満の限定版を10ドルプラス送料で販売しており、基板ファイルはGitHubでアクセス可能です。
  • お問い合わせは、byran@mrx.ee の Byran または max@mrx.ee の Max までご連絡ください。

反応​

  • MUREX Roboticsは、ニューハンプシャー州エクセターの高校チームで、世界最小かつ最安のネットワークスイッチを開発しました。価格は6.9ドルです。
  • このスイッチはオープンソースで設計されており、コスト効率が高く、アクセスしやすいことを目的としています。サイズとコストが重要なアプリケーションを対象としています。
  • チームは、オープンソースの電子機器を通じて技術を民主化するという使命を強調しながら、これらのボードの小ロットを近日中に販売する予定です。

SSHハニーポットを30日間稼働させた結果​

反応​

  • あるユーザーが30日間SSHハニーポットを運用したところ、主にIPv4空間をスキャンする「インターネットセキュリティ会社」からの大量の不正トラフィックが確認されました。
  • これらのネットワークをブロックすることで不要なトラフィックが50%以上減少しましたが、この議論はCGNAT(キャリアグレードネットワークアドレス変換)によるIPブロッキングの限界を浮き彫りにしています。
  • 強調されているのは、サーバーを保護するためにfail2ban、VPN、および公開鍵認証のようなセキュリティツールを使用することであり、ユーザーはセルフホスティングの経験や絶え間ない攻撃の課題を共有しています。

部屋で一番賢くなろうとするのではなく、一番親切になろうとしなさい​

反応​

  • 知性よりも親切を強調することで、傾聴、尊重、共感、問題解決を通じてチームのダイナミクスと生産性を向上させることができます。
  • 親切は持続的な影響を生み出し、前向きな職場環境を育むため、長期的な成功にとって重要です。
  • 知性は重要ですが、職場における親切の利点を過小評価すべきではありません。

NLRB判事が競業避止条項を不当労働行為と宣言​

  • NLRB判事のサラ・カルピネンは、競業避止条項および同僚勧誘禁止条項が不当労働行為であると判断し、画期的な決定を下しました。
  • この事件はJ.O. Mory, Inc.に関するもので、労働組合の組織者が「サルティング」(同僚の組織化)を理由に解雇され、裁判官がその組織者の復職と未払い賃金の支払いを命じました。
  • これは、行政法判事(ALJ)がこれらの条項を不当労働行為と判断した初めてのケースであり、非監督労働者に対するこれらの条項に反対するNLRBの立場を強調しています。

反応​

  • NLRBの判事は、競業避止条項が不当労働行為であると判断し、他の制限的な雇用慣行についての議論を引き起こしました。
  • この判決は、求人勧誘禁止条項や、マネージャーが推薦状を提供することを制限する会社の方針についての議論を引き起こしました。これらは一部の人々によって、職業の流動性を妨げると主張されています。
  • この決定は、雇用主と従業員の間の権力のバランスを取るための大きな議論の一部であり、公正な待遇と労働市場の流動性を確保するための労働者保護の強化を求める声が上がっています。

フランスの裁判所がGoogle、Cloudflare、Ciscoに対し、海賊行為を阻止するためにDNSを無効化するよう命じる​

  • フランスの裁判所は、Google、Cloudflare、およびCiscoに対し、DNSリゾルバを通じて約117の海賊スポーツストリーミングドメインへのアクセスをブロックするよう命じ、放送局Canal+のための反海賊行為の取り組みを強化しました。
  • Canal+はまた、フランスの既存のサイトブロッキング法を活用して、これらのサイトを検索結果から削除する許可を得ています。
  • 海賊行為の率に対する影響が最小限であるという議論にもかかわらず、裁判所はCanal+の権利を支持し、Googleはこの命令に従うことを確認しました。これにより、将来の反海賊行為戦略に関する疑問が提起されています。

反応​

  • フランスの裁判所は、Google、Cloudflare、およびCiscoに対し、約117の海賊スポーツストリーミングドメインへのアクセスをブロックするためにDNSリゾルバを変更するよう命じました。
  • この判決は、同様の米国の法律に対するテクノロジー企業の以前の抵抗と対照的であり、彼らの立場が変化し、コントロールを維持し法的問題を回避するための動きを強調しています。
  • 批評家たちは、これらのブロックを回避するために個人用DNSリゾルバを使用することを提案しており、反海賊行為対策とインターネットの自由のバランスについての議論が続いている。

Raspberry Pi 5はTini-Mini-Micro PCには敵わない​

  • 2023年秋に発売されたRaspberry Pi 5は、性能が向上していますが、SDカードストレージの制約や前モデルに比べてコストが高いという点で依然として制限があります。
  • デル、レノボ、HPなどのブランドの中古1LミニPCは、処理能力、RAM容量、およびストレージオプション(SATAおよびNVME SSD)においてPi 5を上回ります。
  • Raspberry Pi 5は省エネですが、中古のミニPCは性能が優れており、内蔵SSD/NVMEサポートがあるため、ホームサーバー用途にはより適しています。

反応​

  • Raspberry Pi 5は、Broadcomとの特別な取引の終了により手頃な価格を失い、現在の市場で競争力が低下しています。
  • ユーザーは、中古のミニPCにより良い価値を見出しており、同じ価格でより多くのパワーと機能を提供しています。
  • Pi 5は教育やGPIO(汎用入出力)アプリケーションにおいて依然として強力ですが、中古のIntel NUCや新しいN100ミニPCのような代替品は、一般的なコンピューティングタスクにおいてより魅力的です。

WebAssemblyとOpenGLを使用してウェブブラウザでSimCity​

  • WebAssemblyのMicropolisは、MaxisによるオリジナルのSimCity Classicの移植版で、Will Wrightがデザインし、Don Hopkinsが移植しました。
  • プロジェクトは進化しており、Patreonでの支援とGitHubでの公開が続いています。
  • ユーザーは、マウスやキーボードショートカットなどのさまざまなコントロールを使用してゲームと対話することができ、将来のアップデートではさらに多くの機能やイースターエッグが追加される予定です。

反応​

  • SimCityはWebAssemblyとOpenGLを使用してウェブブラウザに移植され、ソフトウェアをインストールすることなくアクセスできるようになりました。
  • このプロジェクトは、オリジナルのSimCity Classicコードに基づいており、パフォーマンスとアクセシビリティを向上させて現代のプラットフォームにゲームをもたらすことを目的としています。
  • このポートはまだ進行中であり、ユーザーインターフェースの強化、モバイルサポートの追加、パフォーマンスの最適化に向けた取り組みが続いています。

一人の技術系スタートアップの背後にあるアーキテクチャ (2021)​

  • この投稿では、AWS上でKubernetesを使用して一人で運営するSaaS(サービスとしてのソフトウェア)のインフラ設定について説明しており、その低ストレスで自己資金による運営の特徴を強調しています。
  • 主要なコンポーネントには、CloudflareとAWSによるトラフィック管理、GitHub ActionsとFluxを介したデプロイメントの自動化、そしてKubernetesのオートスケーリングとライブネスプローブによる信頼性が含まれます。
  • 追加機能には、Redisを使用したキャッシュ、Django Ratelimitを使用したレート制限、Celeryを使用したスケジュールタスク、New RelicとSentryを使用したモニタリングが含まれており、ソロテックスタートアップの管理に関する包括的な概要を提供します。

反応​

  • スタートアップにとって最適な技術スタックは、チームがすでに慣れ親しんでいるものであり、新しい技術を学ぶことは不必要な複雑さを加える可能性があるからです。
  • 迅速な展開を優先し、リファクタリングは後で考慮してください。ユーザーは基盤技術よりも機能する製品を重視します。
  • いくつかの新しい技術、例えばKubernetesのようなものは過剰かもしれませんが、Docker Swarmやマネージドサービスのようなよりシンプルなソリューションは、シンプルさとスケーラビリティのバランスを取るためにより適している場合があります。

ソフトウェアのための単純な妨害(2023年)​

  • 第二次世界大戦中のCIAの「シンプルサボタージュ」本は、生産性を妨害するための時代を超えたアドバイスを提供しており、現代のテクノロジー環境にユーモラスに適応されています。
  • CTOに対するサボタージュの提案には、長時間を要するリライトを要求すること、多様な言語を奨励すること、そしてシステムを分割して複雑さを増すことが含まれます。
  • 他の方法には、有用な指標を無視すること、報酬を役職やチームの規模に結びつけること、そして主観的な採用プロセスを作成することが含まれ、すべてもっともらしい行動を通じて生産性を微妙に低下させることを目的としています。

反応​

  • 2023年のエリック・バーンハードソンの記事を引用しながら、ソフトウェアにおける単純な妨害行為についての議論が、元CIAの妨害戦術の効果について疑問を投げかけています。
  • コメント投稿者たちは、これらの戦略の実用性と影響について議論しており、悪い管理と誤った利益最適化が自然に組織を麻痺させる可能性があると指摘しています。
  • この会話には歴史的な背景、無能の役割、そして複雑なセルフサービスシステムや義務的なオフィス復帰ポリシーなどの現代の慣行が含まれており、これらが意図せずに妨害の原則と一致する可能性があります。

ヨーロッパの代替案​

  • この投稿では、さまざまなデジタルサービスや製品に対するヨーロッパの代替案を強調し、地元企業の支援とGDPR(一般データ保護規則)への準拠を強調しています。
  • それは、ウェブ解析、クラウドコンピューティング、メールプロバイダーなど、利用可能な代替案の数とともにサービスのカテゴリを一覧表示します。
  • この投稿は、ヨーロッパのプロバイダーを選ぶ利点を強調しています。これには、VATの還付、一般的なヨーロッパの支払い方法、統一された法律によるEU内での権利の行使の容易さが含まれます。

反応​

  • European Alternativesは、EU、EEA、EFTA、またはDCFTA加盟国に拠点を置く企業の製品およびサービスをリストアップしており、非EU/EFTAのサブホスティングプロバイダーは除外しています。
  • このサイトは、アイデンティティとアクセス管理、VPSプロバイダー、検索エンジンなどのカテゴリをカバーしており、ポストブレグジット後の英国の排除やEU規制の遵守に関する議論も行っています。
  • ユーザーはまた、HetznerやTutaのようなサービスの品質、そしてデータプライバシーや競争における地政学的な影響についても議論しています。

シムシティを作る: 世界を機械に入れる方法​

  • 『シムシティを作る』は、チャイム・ギンゴールドによる著作で、ウィル・ライトが制作した影響力のあるシミュレーションゲーム『シムシティ』の歴史と開発について探求しています。
  • この本は、コンピュータシミュレーションにおけるSimCityの影響と、そのゲームを開発した会社であるMaxisの歴史を、図や写真などの視覚資料とともに取り上げています。
  • MITプレスから出版され、2024年6月からペーパーバック版と電子書籍版の両方で入手可能になります。

反応​

  • スポアの著者兼デザイナーであるチャイム・ギングルドが、7月19日午後2時(東部標準時)にTwitchでROMchipが主催するQ&Aセッションに参加します。インタビューはウィル・ライトが行います。
  • スチュワート・ブランドは、ギンゴールドの本をコンピューティングにおける最高の起源物語と革新の記録の一つとして称賛しました。
  • ギンゴールドは、シムシティの現代的な後継作として、シティーズ：スカイライン、マインクラフト、タイニーグレードを推奨し、ゲーム開発における生成AIの影響を強調しています。

SQLiteは他のすべてのデータベースエンジンを合わせたよりも多く使用されている可能性があります​

  • SQLiteは最も広く展開され、使用されているデータベースエンジンであり、Android、iOS、Mac、Windows 10、主要なウェブブラウザ、およびさまざまな人気のあるアプリケーションを含む数十億のデバイスやアプリケーションに存在しています。
  • 40億台以上のスマートフォンにはそれぞれ数百のSQLiteデータベースが含まれており、世界中で1兆以上のアクティブなSQLiteデータベースが存在する可能性があります。
  • SQLiteは、最も広く展開されているソフトウェアモジュールのトップ5の一つであり、zlibに次いで2番目に広く展開されているソフトウェアライブラリである可能性があり、デバイスごとに複数のインスタンスが存在するため、最も広く展開されているソフトウェアコンポーネントである可能性もあります。

反応​

  • SQLiteは、その使いやすさ、信頼性、オフライン機能により、他のすべてのデータベースエンジンを合わせたものよりも広く使用されています。
  • ユーザーはバックアップや共有のためにデータをダウンロードする際、より良いスキーマの強制を求めてjson+zipからgzipped SQLiteに移行しています。
  • その人気にもかかわらず、SQLiteは貢献を受け付けていませんが、そのファイル形式はよく文書化されており安定しているため、iOSやAndroidを含む多くのアプリケーションに理想的です。

専門家 vs. 模倣者​

反応​

  • 議論は専門家と模倣者を対比し、真の専門知識には深い理解と効果的なコミュニケーションが伴うことを強調しています。
  • 専門家は、複雑なトピックを簡単な言葉で説明する能力が重要であり、技術的な知識とともに優れたコミュニケーションスキルの重要性を強調しています。
  • 会話は、専門家が一般の人々に複雑な概念を伝える際に直面する課題に触れており、これらの困難を説明するためにプログラミング言語のRustやPythonの例を使用しています。

初めての組み込みLinuxシステムの作成​

  • その投稿は、著者がPCB(プリント回路基板)の経験が全くない状態から始めて、ゼロからLinuxシステムを構築する過程を詳述しています。
  • 重要なステップには、Atmel ATtinyのようなマイクロコントローラーのプログラミング、カスタムPCBの設計、F1C100s SoC(System on Chip)を使用した組み込みLinuxボードの作成が含まれます。
  • このプロジェクトには、プログラミング用のavrdudeのようなツールの使用、複雑な配線のための4層PCBの使用、およびカスタムボード用にLichee Piソフトウェアイメージを適応させることが含まれていました。

反応​

  • あるユーザーが初めて組み込みLinuxシステムを作成した経験を共有し、技術的な詳細や改善点についての議論が始まりました。
  • 主なポイントには、16Mbitフラッシュの使用、差動配線、およびSDカードコネクタを追加することの潜在的な利点が含まれます。
  • このプロジェクトでは、533MHzのシングルコアARMv7と32MBのオンボードDRAMを搭載したAllwinner F1C100Sが使用され、他の類似プロセッサとの比較が促されました。

あらゆるトピックに関する2,299のブログのコレクション​

反応​

  • さまざまなトピックに関する2,299のブログの新しいコレクションがooh.directoryで開始されました。これは、Yahooのカテゴリ別リンクディレクトリのような初期のウェブディレクトリを思い起こさせます。
  • ユーザーは、広告で埋め尽くされた検索エンジンと比べて、発見しやすさが向上するキュレーションされたディレクトリの性質を評価しています。
  • ディレクトリは、新しいブログやインタビュー対象者を見つけるための貴重なリソースと見なされており、特にAI生成コンテンツが普及している時代において重要です。
