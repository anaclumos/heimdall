Flipper Zero: Multi-Alat Serbaguna untuk Peretas dan Geeks​

  • Flipper Zero adalah perangkat multi-alat portabel yang dirancang untuk para pentester dan geek, menawarkan kemampuan kustomisasi dan sumber terbuka untuk meretas sistem digital seperti protokol radio, sistem kontrol akses, dan perangkat keras.
  • Dilengkapi dengan layar LCD monokrom 1,4 inci, directional pad 5 tombol, dan berbagai pilihan konektivitas seperti Bluetooth, NFC, dan inframerah.
  • Perangkat ini dapat membaca dan meniru kartu RFID, memiliki slot kartu microSD untuk penyimpanan, dan dapat dikontrol secara mandiri atau dihubungkan ke komputer atau smartphone untuk fitur-fitur canggih, membuat eksplorasi dan pengembangan perangkat keras menjadi lebih menyenangkan dan nyaman.

Reaksi​

  • Flipper Zero adalah perangkat serba guna yang serbaguna dengan berbagai fungsi, termasuk bertindak sebagai remote IR.
  • Ini telah memicu diskusi tentang keterjangkauannya dibandingkan dengan alternatif lain dan merek Cina dengan blaster IR pada ponsel mereka.
  • Perangkat ini telah menghadapi kontroversi dan keterbatasan, termasuk iPhone yang rusak, dilarang oleh Amazon, dan kekhawatiran tentang kemampuan pertukaran data dan implikasi privasi.

NASA Terhubung Kembali dengan Helikopter Mini Mars di Tengah Pemadaman Komunikasi​

  • NASA telah berhasil mendapatkan kembali kontak dengan helikopter mininya di Mars setelah mengalami gangguan komunikasi.
  • Kode CSS yang disediakan digunakan untuk menata berbagai elemen di situs web, seperti fitur, remah roti, pesan pengecekan fakta, dan menu geser.
  • Kode ini memastikan tampilan visual halaman web yang konsisten dan menyertakan kueri media untuk desain responsif.

Reaksi​

  • NASA telah berhasil membangun kembali komunikasi dengan helikopter mini bertenaga Linux, Ingenuity, di Mars.
  • Diskusi berkisar pada pengembangan perangkat lunak untuk misi tersebut, termasuk penggunaan skrip Python dan potensi pengurangan biaya dalam industri kedirgantaraan.
  • Strategi SpaceX untuk pemotongan biaya dan produksi komponen internal disorot, bersama dengan pentingnya pengerasan rad pada aplikasi penting. Potensi penggunaan helikopter di Mars dan tantangan dalam merancang sistem pesawat untuk eksplorasi Mars juga dieksplorasi.

Kerentanan GPT-3.5. Kerentanan: Frasa yang Salah Eja Menyebabkan Pesan Kesalahan dan Menimbulkan Kekhawatiran Keracunan Data​

  • Menambahkan frasa tertentu di bagian atas respons pada ChatGPT 3.5 secara konsisten memicu pesan kesalahan.
  • Kesalahan ini tidak terjadi pada GPT-4 atau ketika menggunakan API GPT-3.5.
  • Kesalahan ini kemungkinan disebabkan oleh proses tokenisasi yang digunakan dalam model GPT OpenAI.
  • Frasa spesifik adalah nama opsi yang salah eja yang ditemukan dalam file konfigurasi XML untuk perangkat lunak Katalon Studio.
  • Kumpulan data yang digunakan untuk melatih GPT-3.5 mungkin telah mengecualikan file XML, sehingga model tidak menyadari adanya token yang salah eja dan menghasilkan respons yang tidak valid.
  • Penemuan ini menimbulkan kekhawatiran tentang potensi keracunan data dan merusak kemampuan ringkasan GPT-3.5.

Reaksi​

  • Diskusi ini berfokus pada model bahasa AI, terutama gangguan pada token tertentu, pembuatan token, dan dampaknya pada konversi teks.
  • Percakapan ini mencakup topik-topik seperti training set, tokenizer, dan tampilan serta fungsionalitas model GPT-3.5 dan GPT-4.
  • Para pengguna memiliki pendapat yang beragam mengenai masalah visual, kecepatan, dan kegunaan GPT-4 dengan API, serta skeptisisme terhadap pendekatan OpenAI dan kemampuan untuk membuktikan pemikiran.

Bell Labs yang Legendaris Bersiap Meninggalkan N.J., Memicu Kenangan Nostalgia​

  • Nokia Bell Labs, yang dikenal dengan penemuannya yang inovatif, memindahkan kantor pusatnya dari Murray Hill ke pusat teknologi baru di New Brunswick, yang memicu nostalgia di kalangan karyawan dan mantan karyawan.
  • Perpindahan ke pusat inovasi HELIX di New Brunswick, yang akan dimulai pada tahun 2025, bertujuan untuk menciptakan fasilitas penelitian dan pengembangan canggih yang memenuhi kebutuhan para peneliti Bell Labs.
  • Meskipun ada langkah tersebut, Bell Labs tidak mengantisipasi pengurangan staf dan tetap berkomitmen untuk berinovasi dan menciptakan teknologi transformatif.

Reaksi​

  • Nokia Bell Labs pindah dari New Jersey ke New Brunswick, sehingga mendorong diskusi tentang pentingnya sejarah kampus Murray Hill dan pusat inovasi HELIX yang baru.
  • Percakapan ini membahas berbagai topik seperti bangunan-bangunan terkenal, pengalaman pribadi, dan rekomendasi buku.
  • Ada kekaguman terhadap perusahaan yang berfokus pada penelitian seperti Bell Labs dan seruan untuk pusat penelitian dan pengembangan yang lebih terkonsentrasi.

Ilmuwan Kembangkan Senyawa Peptida untuk Menargetkan Protein Pemicu Kanker​

  • Para peneliti di University of California - Riverside telah menciptakan senyawa peptida yang menargetkan protein MYC, yang umumnya ditemukan dalam sel kanker.
  • Dengan memodifikasi struktur peptida, para peneliti meningkatkan kemampuannya untuk berinteraksi dengan MYC, sehingga memungkinkannya untuk berikatan kuat dengan protein.
  • Perkembangan ini menunjukkan harapan dalam pengembangan pengobatan kanker baru, dan para peneliti berfokus pada peningkatan kemampuan peptida untuk memasuki sel.

Reaksi​

  • Para ilmuwan telah mengidentifikasi molekul yang dapat memblokir aktivitas protein MYC, yang bertanggung jawab untuk memicu 75% kanker.
  • Penemuan ini menawarkan pilihan pengobatan yang potensial untuk kanker, tetapi efektivitasnya, metode pemberian, dan potensi efek sampingnya masih belum diketahui.
  • Meskipun ini adalah perkembangan yang menjanjikan, penting untuk dicatat bahwa ini masih dalam tahap awal dan belum diuji pada manusia. Penelitian kanker adalah bidang yang kompleks, dan keberhasilannya tidak terjamin, tetapi memainkan peran penting dalam memajukan perawatan kanker.

Google mengakui melacak pengguna dalam mode Penyamaran, terlepas dari klaim privasi​

  • Google telah memperbarui penafiannya untuk mode Penyamaran untuk memperjelas bahwa data pengguna masih dikumpulkan, meskipun ada klaim privasi.
  • Penafian yang telah diperbarui menyatakan bahwa meskipun orang lain yang menggunakan perangkat yang sama tidak akan melihat aktivitas pengguna, data masih akan dikumpulkan oleh situs web yang dikunjungi dan layanan yang digunakan, termasuk Google sendiri.
  • Hal ini menegaskan kecurigaan bahwa Google melacak aktivitas pengguna bahkan ketika mereka berada dalam mode Penyamaran, sehingga pengguna disarankan untuk berhati-hati saat menggunakannya.

Reaksi​

  • Ada perdebatan yang sedang berlangsung tentang praktik pelacakan Google dalam mode penyamaran dan potensi dampaknya terhadap privasi pengguna.
  • Beberapa pengguna mengklaim bahwa Google masih melacak aktivitas mereka bahkan dalam mode penyamaran, sementara yang lain mempertanyakan sejauh mana pelacakan dan hubungannya dengan sesi non-inkarnasi.
  • Saran untuk menjaga privasi termasuk menggunakan peramban alternatif atau alat yang berorientasi pada privasi, dan ada seruan untuk komunikasi yang lebih jelas dari Google mengenai keterbatasan mode penyamaran.

Ikan Buffalofish Menentang Penuaan: Ada yang Hidup Melewati Usia 100 Tahun dan Tetap Sehat​

  • Sebuah penelitian terbaru yang dilakukan di Danau Apache di Arizona telah menemukan bahwa buffalofish, sejenis ikan air tawar, dapat hidup lebih dari 100 tahun dan memiliki sistem kekebalan tubuh yang kuat serta respons stres seiring bertambahnya usia.
  • Sebelumnya, diyakini bahwa ikan buffalofish hanya hidup hingga usia pertengahan 20-an.
  • Temuan ini menunjukkan bahwa penelitian lebih lanjut mengenai umur panjang ikan buffalofish dapat memberikan wawasan untuk memperpanjang umur vertebrata, termasuk manusia. Selain itu, penelitian ini menyoroti perlunya upaya konservasi karena populasi buffalofish menurun dan saat ini tidak ada peraturan tentang pemanenan mereka.

Reaksi​

  • Thread diskusi mencakup berbagai topik, seperti umur spesies ikan, dampak keabadian pada masyarakat, kemajuan teknologi perpanjangan umur, dan masalah kelebihan populasi.
  • Hal ini menekankan pentingnya kemampuan beradaptasi, keadilan sosial, dan potensi kebutuhan akan intervensi pemerintah.
  • Percakapan tersebut mencakup komentar lucu dan sarkastik di samping diskusi serius.

Mengakses Data Layanan Taman Nasional dengan API Data NPS​

  • API Data National Park Service (NPS) tersedia bagi para pengembang untuk menggunakan data NPS dalam proyek mereka seperti aplikasi, peta, dan situs web.
  • API menawarkan berbagai informasi mengenai peringatan, artikel, bumi perkemahan, acara, rencana pelajaran, rilis berita, taman, dan pusat pengunjung.
  • Pengembang dapat mengakses sumber daya API dan mendaftar untuk mendapatkan kunci API di situs web API Data NPS, sementara peta jalan API NPS menguraikan pembaruan dan peningkatan API di masa mendatang.

Reaksi​

  • API Layanan Taman Nasional AS menghadapi masalah karena kekurangan staf dan kekurangan dana, sehingga menimbulkan kekhawatiran di antara para pengguna.
  • Pengguna telah menemukan metode alternatif untuk mengakses data, tetapi muncul perdebatan mengenai biaya dan ketergantungan pada vendor pihak ketiga.
  • Diskusi mencakup topik-topik seperti membayar untuk data publik, pembatasan akses, dan penggunaan kunci API untuk otentikasi dan perlindungan DDoS, bersama dengan keefektifan dan perlunya pembatasan kecepatan dan metode otentikasi alternatif. Masalah keamanan yang terkait dengan kunci API juga disebutkan.
