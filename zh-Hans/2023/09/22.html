每月 10 美元，可无限次搜索 Kagi​

  • Kagi 是一个搜索引擎，该公司更新了其产品，推出了每月 10 美元的专业计划（包括无限搜索）和每月 5 美元的入门计划（300 次搜索）。
  • 终极计划将引入新工具，并邀请用户参与封闭测试。此外，还推出了提供无限搜索的 Family 和 Duo 计划。
  • Kagi 强调以用户为中心的方法和对隐私的保护，并表示对合作和投资机会持开放态度。

反应​

  • 文中围绕各种话题进行了讨论，包括 Kagi 和 Google 等搜索引擎、广告拦截器以及 Reddit 上日益恶化的产品评论质量。
  • 讨论的另一部分集中于广告的影响、操作系统的可用性（尤其是 Windows 和 Linux 之间）以及彩票的概念。
  • 这些主题表明，用户正在分享和讨论各种不同的意见和观点。

思科收购 Splunk​

  • Splunk 与思科公司建立了合作伙伴关系，旨在应对人工智能和数字化转型带来的挑战，提高数字复原力。
  • 通过整合各自领先的解决方案，这两家公司旨在提供安全、可观测性和网络运营方面的全面可视性，快速推动创新并创建变革性数据解决方案。
  • 利用思科的全球网络和市场能力，Splunk 旨在增加其资源，以更好地服务于客户并增强其数字复原力。

反应​

  • 思科在收购 Datadog 失败后收购了数据分析软件公司 Splunk，有传言称此次收购与内幕交易有关。
  • 讨论集中在 Splunk 的高定价、成本增加、客户不满以及思科收购后服务可能发生的变化。尽管如此，一些客户仍然发现了 Splunk 的价值，尽管成本很高。
  • 讨论中提到了其他日志分析工具和平台，以及作为 Splunk 潜在替代品的 IP 地址搜索工具的开发。

吉卜力工作室将成为日本电视台的子公司​

  • 日本电视台将收购著名的动画工作室吉卜力工作室，并将其定位为子公司。

矩阵 2.0矩阵的未来​

  • Matrix 是一个开放式标准通信平台，通常用于安全的分散式通信：Matrix 2.0。此次更新提高了可用性和性能。
  • Matrix 2.0 引入了滑动同步和本地群组 VoIP 等功能，旨在提供比一般信息服务更快、更高效的通信。该版本是 Matrix 的重大发展。
  • Matrix 客户端 Element X 采用滑动同步功能，强调快速的用户界面，同时 Matrix 2.0 还加入了 Matrix Group 本地 VoIP 通话功能。Matrix 团队正在进行更多改进，并为持续开发筹集资金。

反应​

  • 讨论围绕 Matrix 消息平台及其与 Element X 客户端的集成展开，涉及复杂性、通知延迟、加密、应用程序重命名、商业方面以及自托管困难等问题。
  • 开发人员承认存在漏洞，并发誓要通过代码重写来提高用户体验和性能，尽管有些用户对频繁更改表示担忧。
  • 对话还围绕实施点对点功能的挑战和预期解决方案、矩阵开发的资金以及平台与执法和政府机构的合作展开，强调了信任和透明度的重要性。

航空公司从里程计划中赚的钱比开飞机还多​

  • 达美航空公司（Delta Air Lines）修改了其 "天空万里通"（SkyMiles）计划，增加了客户获得身份和福利的难度，这反映了美国航空旅游业存在的更广泛的问题。
  • 1978 年放松对航空公司的管制后，航空公司与银行和信用卡公司合作，推出了忠诚度计划，并出售航空公司积分，这成为一个重要的收入来源。这种将重点转向消费而非里程的转变，可能会对没有积分卡的消费者不利。
  • 文章认为，放松对航空公司管制所带来的好处并没有兑现，重新审视管制有助于改善航空公司的金融化和消费者的航空旅行体验。

反应​

  • 讨论涉及航空业的各种话题，从法规对降低成本和定价的影响到新增编码线对计划的影响。
  • 对话探讨了竞争与创新之间的联系、航空公司的定价技巧、盈利能力及其对消费者的影响，以及向航空公司提供补贴的问题。
  • 讨论的其他主题包括指令经济、优化商业实践、财富分配和创新在经济中的作用，说明了这些主题的复杂性和细微差别。

铅中毒导致的死亡和智商下降比想象的要多：研究​

  • 一项新的研究表明，铅中毒对全球健康的影响比以前认为的更为严重，每年可能造成 500 多万人死亡，并导致儿童智商显著下降。
  • 根据这项研究，2019 年有 550 万人死于铅暴露导致的心脏病，比以前的估计高出六倍。此外，铅还导致2019年全球5岁以下儿童的智商累计下降7.65亿分。
  • 这项研究首次评估了铅暴露对发达国家和欠发达国家儿童心脏病死亡率和智商下降的影响，但还存在不确定性，需要进一步验证。

反应​

  • 本论述探讨了铅中毒的各种影响，包括铅中毒与学龄前儿童犯罪率的相关性，以及铅在汽车污染和各种产品中的存在。
  • 重点包括管道配件中铅的危险和含铅燃气的使用，同时还强调了石棉、水壶中的矿物质沉积以及电热水器的挑战等问题。
  • 讨论强调了监管和认识对于解决这些与铅中毒相关的环境和健康问题的重要性。

美国国家航空航天局的韦伯号探测器在木星卫星欧罗巴表面发现碳源​

  • 美国国家航空航天局（NASA）的詹姆斯-韦伯太空望远镜在木星卫星木卫二的表面发现了碳元素，这表明木卫二表面下的海洋中可能存在宜居环境。
  • 在这次发现之前，生命的关键元素碳的存在尚未得到证实；据推测，碳来自冰壳下的欧罗巴海洋。
  • 尽管韦伯望远镜没有在欧罗巴表面观测到水蒸气羽流的证据，但美国宇航局计划在2024年发射 "欧罗巴快船 "航天器进行进一步探测。

反应​

  • 美国宇航局的詹姆斯-韦伯太空望远镜在木星的卫星欧罗巴表面发现了碳源的迹象。这意义重大，因为据推测，木卫二拥有一个液态水的地下海洋。
  • 讨论深入探讨了进入地球的 "新水 "和地球上的多种水源，强调了全球水文视角。
  • 此外，还探讨了木卫二上存在生命的可能性、即将进行的木星卫星研究任务，以及在木卫二冰层下进行研究的意义和激励措施，暗示了对天体生物学的日益关注。

WebP 0day​

  • 谷歌为 Chrome 浏览器发布了一个安全更新，以修补 WebP 图像库中的堆缓冲区溢出漏洞。
  • 该漏洞与名为 "BLASTPASS "的 iMessage 零点击漏洞有关，该漏洞被用于运行 NSO Group 的 Pegasus 间谍软件。
  • 尽管该漏洞已被修补，但要将修补程序传播到所有系统可能还需要一些时间。这提醒我们，源代码审查和更严格的图像解码及复杂解析器代码沙箱的重要性。

反应​

  • 在 WebP 图像格式中发现了一个安全漏洞，在包括主要浏览器和操作系统在内的多个平台上都存在潜在风险。
  • 这一漏洞引发了关于利用形式验证、内存安全语言、沙箱和类型系统的有效性来提高软件安全性的讨论。
  • 一些 Linux 发行版已经发布了安全补丁来解决这个问题，但人们仍然担心其他易受攻击的发行版和应用程序。尽管存在相关的挑战和限制，但关于使用虚拟机来提高浏览器安全性的讨论也越来越广泛。

加快 JavaScript 生态系统的运行速度--流氓式的 Polyfills​

  • 目前的问题是，npm 软件包中不必要地包含了 polyfills，导致 node_modules 文件夹的大小超出了要求。
  • 包括 "eslint-plugin-react "在内的许多软件包都在导入并直接调用 polyfill 函数，这种做法效率很低，因为 JavaScript 已经广泛支持这些工作。
  • 文章认为，JavaScript 生态系统需要重新评估依赖关系的使用，以提高效率并减少磁盘空间的浪费。通过消除不必要的 polyfills，项目中的依赖关系数量可以显著减少。

反应​

  • 文章深入探讨了 JavaScript 中的自动多填充问题，以及在 swc 和 Babel 等工具的催化下，不必要的多填充是如何导致库规模增大的。
  • 它讨论了与 IE6 等旧版浏览器保持向后兼容性的困难，提出了分叉库的可能性，以消除非必要的向后兼容性。
  • 文章强调了 JavaScript 生态系统中存在的挑战，如高度依赖性、缺乏经验的开发人员和过时的浏览器支持。文章提出了一些解决方法，如减少依赖性、采用依赖性较低的库，以及可能利用 WebAssembly (WASM) 来解决依赖性问题。

用较少的训练数据和较小的模型就能超越较大的语言模型​

  • 谷歌的云计算人工智能团队推出了一种名为 "逐步提炼 "的技术，有助于使用较少的数据训练紧凑的特定任务模型。
  • 这项技术的工作原理是从大型语言模型（LLM）中提取被称为 "理由 "的信息部分，以监督小型模型的训练。
  • 研究表明，这种方法在使用更小的模型和更少的训练数据时，性能比 LLM 更好，为应对大型模型带来的部署挑战提供了更节省资源的解决方案。

反应​

  • 辩论的焦点集中在谷歌的人工智能能力上，提请人们注意研究的成功未必能保证产品的主导地位。
  • 我们强调了特定领域模型、多模态训练和精通处理器密集型大型语言模型（LLM）（如 OpenAI 的 GPT-3+）的管理器模型的重要性，以及对批处理框架的需求。
  • 未来的可能性包括苹果和英特尔进入 LLM 市场，以及增加硬件的内存容量以更好地适应 LLM。

呼吁关闭布里斯托尔学校使用应用程序 "监控 "学生和家庭的做法​

  • 布里斯托尔 100 多所学校使用 "思考家庭教育"（TFE）应用程序来监控学生及其家庭背景，这引起了人们的关注。
  • 批评者认为，该应用程序提供了与警方和福利服务机构的家庭联系渠道，有可能加剧对少数民族或工人阶级背景学生的歧视。
  • 虽然布里斯托尔市议会和埃文与萨默塞特警方坚称，该应用程序是为了保护儿童，而不是为了定罪，但批评者反驳说，它可能会无意中将少数族裔儿童描述为参与犯罪活动。

反应​

  • 主要话题围绕布里斯托尔学校使用的一款应用程序，该应用程序收集并共享学生和家庭数据，引发了人们对隐私、潜在貌相和不公平待遇的担忧。
  • 它进一步扩展到对学校监控的作用、数字设备、安全官员以及数据共享系统的负面影响的更广泛讨论。
  • 此外，还提出了关于贫困社区治安状况差、系统性贫困、当前系统在保护弱势个人方面的局限性、潜在的种族定性、透明度问题以及企业和政府部门在管理个人数据方面的责任等问题。

反应​

美国证券交易委员会打击绿色营销​

  • 美国证券交易委员会（SEC）启动了一项针对 "绿色清洗 "的规则，确保基金投资组合的 80% 与基金名称中指定的资产相对应。该规则旨在防止对环境、社会和治理（ESG）投资的误导性描述。
  • 为了反对绿色营销，欧盟（EU）还禁止在 2026 年之前宣称 "气候中立 "或任何广泛的环保主张。
  • 除 "洗绿 "外，地缘政治紧张局势也在升级，如印度和加拿大之间的签证暂停、美国和沙特阿拉伯可能签署的防务条约因人权问题而引起关注，以及乌克兰和波兰之间的谷物进口争端。

反应​

  • 美国证券交易委员会（SEC）正在对碳市场中的 "洗绿 "行为实施更严格的监管，因为非营利组织涉嫌在环境可持续性方面进行虚假宣传。
  • 关于碳信用额度的可信度和有效性以及进一步规范碳抵消市场的必要性的争论日益激烈。人们对毁林信用额度和骗局的担忧也在增加。
  • 文章和评论讨论了潜在的解决方案，如碳税，但也承认相关的挑战，包括可靠地量化碳排放、黑市出现的风险以及核国家带来的复杂性。
