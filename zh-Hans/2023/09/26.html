2023-09-26

我们开始在 ChatGPT 中推出新的语音和图像功能​

  • OpenAI 正在为其 ChatGPT 人工智能系统添加语音和图像功能，使其成为一个交互性更强的界面，用户可以讨论图像并进行语音对话。
  • 这些功能应用广泛，包括讨论旅行照片、识别食品和帮助解决数学问题。
  • 这些更新将在未来两周内提供给 Plus 和企业用户，在 iOS 和安卓系统上都可以使用语音功能，并且图像兼容所有平台。OpenAI 回应了与这些新功能相关的冒名顶替和隐私问题，声称他们已采取措施降低这些风险。

反应​

  • OpenAI 的目标是根据用户对低延迟语音订购的反馈以及对更快语音响应和系统可中断性的要求，改进 ChatGPT 的语音和图像功能。
  • 尽管对速度、准确性和生态影响存在担忧，但 ChatGPT 在机器人规划和任务中的潜在用途仍被视为大有可为。关于人工智能生成信息的可信度和价值，人们一直在争论不休。
  • OpenAI 计划推出一个新的图像生成模型 DALLE-3，与此同时，人们还在讨论人工智能的商业模式、对互联网搜索的影响以及人工智能平台撤销网页浏览功能等问题。

团结最古老的社区宣布解散​

  • 波士顿 Unity 小组（BUG）是全球首个官方 Unity 用户小组，该小组宣布将于 9 月 27 日举行最后一次活动，理由是对公司最近的发展方向和缺乏对开发者社区的支持感到失望。
  • 组织者认为，他们的贡献应更好地用于在更广泛的地方发展社区内创造机会。
  • 欢迎 BUG 成员加入波士顿游戏开发者聚会小组，继续与其他行业专业人士进行交流。最后一次 BUG 会议将是在 Zoom 上举行的社交活动。

反应​

  • 由于 Unity 最近的价格变动，Unity 的长期社区波士顿 Unity 小组（BUG）已经解散，这表明人们对该公司失去了信任。
  • 人们普遍讨论，由于审查制度、注重短期利润和产品可靠性下降等负面商业行为，人们对 Unity 和 Craftsman 等知名品牌的信任度下降。
  • 开源游戏开发中的问题，如 Godot 等游戏引擎的局限性、人事变动、沟通失败以及 Unity 对独立开发者的支持存在问题等，也得到了强调。

伊恩的鞋带网站​

  • Ian's Shoelace Site 提供有关鞋带的详细信息和资源，包括系鞋带、打结和了解鞋带结构的教程。
  • 该网站以 "伊恩结 "而闻名，这是一种快速安全的鞋带结，网站还展示了各种系鞋带的照片。
  • 它提供搜索功能，便于导航，并根据访问者的反馈定期更新内容，使其成为所有鞋带相关查询的全面资源。

反应​

  • Ian's Shoelace 网站因介绍不同的鞋带系法和绳结而受到用户的赞赏，他们认为这对他们很有教育意义，也很有帮助。
  • 伊恩结被宣传为最快的鞋带结，获得了好评，用户也分享了自己喜欢的系法。
  • 用户建议在网站内容的基础上制作 YouTube 视频，这暗示着伊恩鞋带网站有可能扩展到一个新的平台。

Fantilator 网页​

  • Fantilator "是一个将多个风扇连接在一起的项目，目的是开发一个更大的设备；其设计经过不断改进，减少了厚度并改善了供电。
  • 后来，Fantilator 的设计进行了阶段性升级，加强了线缆管理，并配备了风扇底座。在这一阶段，它使用了 64 个风扇，并引入了使用 Arduino 的 PWM（脉宽调制）控制单个风扇。
  • 最终，Fantilator 项目取得了成功，所有风扇都由运行特定操作系统 FantilatorOS 的 Arduino 控制。

反应​

  • 欧洲核子研究中心网站幽默地创建了一个名为 "Fantilator Page "的子域，在网站评论区引发了争论和幽默。
  • 针对这个笑话子域，用户分享了相关网站的链接，并制作了有关风扇和通风系统的双关语。
  • 对这个笑话的反应不一，一些用户欣赏这种幽默，而另一些用户则质疑其相关性或适当性。

节奏 0​

  • "节奏 0 "是艺术家玛丽娜-阿布拉莫维奇（Marina Abramović）在 1974 年进行的一场长达 6 小时的表演，她允许观众使用提供的物品与她互动，测试公众行为的程度。
  • 随着演出的进行，观众的行为从温和的互动升级到极端暴力，包括割破她的衣服、割破她的喉咙、用上膛的枪威胁她。
  • 最后，阿布拉莫维奇站起身来，观众纷纷逃离，这部作品被誉为行为艺术史上的开山之作。

反应​

  • 中心主题围绕对玛丽娜-阿布拉莫维奇的行为艺术 "节奏 0 "的解读，辩论了观众行为的概括性以及艺术描绘科学所不能描绘的人类视角的能力。
  • 讨论还探讨了营销和背景对观众行为的影响，并思考了表演可能涉及的法律问题，对艺术作品背后的道德和议程提出了质疑。
  • 辩论还涉及基督教伦理、艺术与法律相互交织的作用，以及艺术作品在引发思考和催生暴力行为方面的真实性和有效性。

威廉与维基已从 Fandom 分支​

  • Minecraft 维基已从 Fandom 过渡到新网站 minecraft.wiki，新网站引入了更强大的功能，如全新的设计、更快的页面加载速度、更少的广告、更好的搜索功能和匿名编辑。
  • 我们呼吁用户分享这一消息，使用 minecraft.wiki 链接而不是 Fandom 链接，并为改进新维基做出贡献。他们还可以将自己的 Gamepedia/Fandom 账户转移到新网站。
  • 新的威廉与维基由 Weird Gloop 托管，目前只有英文版已转移。非英语版本将来可能会转移。

反应​

  • Minecraft Wiki 以前是 Fandom 的一部分，现在已成为一个独立实体。
  • 这一分离发生在 20 小时前，并在黑客新闻论坛等平台上引发了讨论。
  • 它标志着该资源的管理发生了转变，可能会影响其结构和内容。

大疆迷你 4 Pro​

  • DJI Mini 4 Pro 是一款轻便、先进的无人机，具有高质量成像能力和超长电池续航时间。
  • 该无人机拥有航点飞行和先进的返航功能等智能功能，并提供多种拍摄模式，可带来多样化的摄影和视频体验。
  • 用户可使用简单的编辑功能，并可进入社区获取灵感和技巧。与无人机相关的其他配件可单独购买。

反应​

  • 讨论还涉及中国和西方无人机企业之间的竞争、大疆无人机的性能、替代无人机选择以及围绕大疆软件与中国政策联系的争议。
  • 此外，还讨论了无线传输距离、噪音水平、合法性、隐私和大疆无人机的价值等问题。

Apache Open Office 是一个未维护的项目吗？​

  • 作者概述了 Apache 软件基金会推出的办公自动化软件 Apache Open Office，并强调该软件自 2014 年以来缺乏重大更新。
  • 他们对项目的活跃状态提出质疑，并列举了软件仓库中大量仅涉及空白改动的提交。
  • 作者敦促用户向阿帕奇软件基金会表达他们的担忧，并建议链接到另一个维护更好的办公软件。

反应​

  • 讨论的主要议题包括人们对 Apache OpenOffice 项目维护不足的看法、Apache 软件基金会的作用和有效性，以及 OpenOffice 和 LibreOffice 之间的比较。
  • 重点介绍了开源软件面临的挑战，如如何在开源承诺与盈利之间取得平衡，以及如何解决 OpenOffice 的构建过程和复杂性问题。
  • 马克-扎克伯格（Mark Zuckerberg）在发言中提到，他更喜欢年轻员工，这也是科技行业年龄歧视的一个暗流。

SR-71 "黑鸟 "天文导航系统的工作原理是跟踪恒星​

  • 冷战时期的战略侦察机 SR-71 Blackbird 采用了天文导航系统（简称 "R2-D2"），利用星象提供导航。
  • 天文导航系统类似于 20 世纪 60 年代的全球定位系统，使 "黑鸟 "能够更新其惯性导航系统并提供航向建议。
  • 黑鸟 "的飞行员和侦察系统官（RSO）负责管理该系统以及机载的其他监视和防御技术。

反应​

  • 全文围绕与导航系统有关的几个方面展开，包括 SR-71 Blackbird 的 Astro-Nav 系统的效率和天体导航细节。
  • 它强调了测绘软件、雷达和导航参考系统的局限性，以及二战期间航空航天技术合作的重要性。
  • 此外，它还提到了恒星跟踪器的使用，并简要介绍了廉价 CPU 以及初创企业加速器计划 Y Combinator (YC) Winter 2024 的应用可能性。

根据新州法律，纽约雇主必须在招聘广告中注明薪资标准​

  • 纽约最近的一项法律规定，雇主有义务在招聘广告中公布薪酬标准，旨在鼓励薪酬透明，解决与年龄、性别和种族有关的薪酬差距问题。
  • 该法律适用于至少有四名员工的企业，其中包括向纽约管理人员汇报工作的远程员工。
  • 批评者认为，小雇主可能难以遵守，而且该法律给企业带来了额外的行政负担。加利福尼亚州和科罗拉多州也制定了类似的薪酬透明法。

反应​

  • 纽约新出台的一项法律规定，雇主必须在所有招聘广告中注明薪资标准。
  • 讨论显示了不同的观点，一些人质疑该法律的效力，另一些人则认为它可以帮助求职者避免薪酬过低的工作，同时促进薪酬对等。
  • 话题延伸到决定薪酬等级，考虑的因素包括软件工程师的价值和绩效、薪酬中性别歧视和种族主义的影响，以及公布薪酬细节的优势或挑战。

KSP2 正在向 Windows 注册表发送垃圾邮件，直至游戏停止运行​

  • Kerbal Space Program 2》的用户遇到了一个错误，导致游戏在 Windows 注册表中填充冗余数据，引发游戏故障。
  • 开发人员已经意识到这个问题，目前正在测试一个解决方案，以便发布热修复程序。
  • 用户建议的临时解决方案是删除注册表项，但由于存在潜在风险，建议谨慎行事。有人对开发团队的能力和对个人电脑的安全影响提出了批评。

反应​

  • 讨论围绕与 Kerbal Space Program 2 (KSP2) 有关的一系列话题展开，包括 Windows 注册表导致游戏问题的技术问题，以及对注册表作为配置管理系统的批评。
  • 其他话题包括对 KSP2 开发和性能的争论、对 Take-Two Interactive 收购的担忧、Windows 注册表和 Unix 文件系统的比较，以及对游戏功能和开发团队的失望。
  • 总之，关于 KSP2 及其正在进行的开发过程，存在着各种各样的观点和批评。

PostScript 在索诺玛猝死​

  • 苹果公司以安全问题为由撤销了 macOS Sonoma 操作系统对 PostScript 和 EPS 文件的支持。
  • 用户对此反应不一；有些人理解加强安全性的必要性，有些人则怀旧并强调 PostScript 的重要作用。
  • 由于这一变化，用户将需要其他软件来转换这些文件，或者仍然可以通过虚拟机使用 PostScript。

反应​

  • PostScript 是一种出版格式，由于存在相关的安全风险，正在被 WebKit/Safari 和 Microsoft Office 逐步淘汰；EPS 文件也出现了类似的趋势，Ghostscript 可能会成为其替代品。
  • 苹果公司正在远离 Perl 等不同的脚本环境，在代码库中转向 Swift，这引起了用户对这一变化的不满。
  • 苹果公司决定在 macOS 中取消对 PostScript 和 EPS 的支持，这在用户中引起了极大的不满，并引发了有关潜在替代方案和对用户体验影响的讨论。

反应​

  • 讨论聚焦于微软裁员、阶级斗争、推特上的仇恨言论、工程师的沟通能力、谷歌的雇佣协议、投资者的角色以及科技领域的外包等众多话题。
  • 与劳工权利和保护、收入差距和裁员影响有关的主要关切问题得到了强调。
  • 这场对话凸显了人们对财富再分配、不平等以及科技行业员工待遇的担忧。

反应​

  • 文章仔细分析了移动赌场游戏的不良影响和不道德行为，尤其是对年轻用户的影响，强调了制定更严格的法规和开设适龄网店的必要性。
  • 报告强调了货币化、战利品箱（随机奖励的虚拟物品）、应用内购买和企业责任等常见问题，同时还讨论了概率操纵以及广泛宣传和严格监管的迫切需要。
  • 讨论范围扩大到批评移动游戏的质量和货币化障碍、苹果商场的有限选择，以及相关的担忧，如 NFT（不可兑换代币）和给年轻人带来的金融风险。

圣赫勒拿岛通信​

  • 摘要讨论了圣赫勒拿的通信问题，涉及邮政、货运、电话、互联网和电子邮件服务以及通信公司，包括其局限性和高成本。
  • 重点介绍了政府为改善互联网而采取的措施，如利用卫星服务（Starlink、OneWeb）和即将开通的 Equiano Cable，这些措施将有可能加强岛屿的网络服务。
  • 报告简要介绍了圣赫勒拿广播电台在无线电通信方面的作用、Sure 有限的电视服务以及 Maestro Technologies 公司在新的数据和语音网络方面的参与。报告还追溯了圣赫勒拿在电报发展方面的历史及其与埃奇亚诺海底电缆的联系。

反应​
