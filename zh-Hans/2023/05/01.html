2023 年 5 月 1 日​

举报人是社会的良知，却遭受严重的伤害​

  • 举报人对社会很重要，因为他们让富人和有权有势的人对他们的行为负责，但他们往往因为他们的努力而遭受巨大的痛苦。
  • 立法机构必须为举报人提供保护，以鼓励更多的人站出来，对错误行为发表意见。
  • 作者 Ashley Gjøvik 是一名律师、活动家、作家和前举报人，专门研究人权和共同利益。

行业反应​

  • 权力结构不太可能容忍与他们作对的举报人，从而导致责罚和缺乏来自组织内部的支持。
  • 关于举报的辩论包括道德、情报机构的作用，以及像 PRISM 这样的项目的合法性和道德性。

微软悄悄地支持立法，使其更容易修复设备​

  • 微软悄悄地支持华盛顿州的公平维修法案，打破了典型的科技公司对寻求使设备维修更方便的维修权法案的反对。
  • 维修倡导者说，微软对该法案的支持首次将其他主要科技制造商带到了谈判桌上。
  • 由于立法者的反对，《公平维修法案》在华盛顿州参议院停滞不前，但微软在维修设备方面的参与标志着该行业对维修权立场的改变。

行业反应​

  • 微软已承诺使其硬件更容易维修，Surface Laptop 4 具有可更换的固态硬盘，这是包括苹果和谷歌在内的科技公司为响应维修权运动而做出类似承诺的更广泛趋势的一部分。
  • Windows 11 因其大量的广告和不如 Windows 10 友好的用户界面、其硬件要求和大量的预装垃圾软件而面临批评，但也有一些后端改进，如支持可变刷新率和英特尔线程主管。

评价房东：与像你一样的租户匿名分享信息​

  • 本网站的最佳体验是直接访问网站。
  • 请访问该网站阅读该文章。

行业反应​

  • 评论者讨论了房东-房客关系的剥削性，并提出了合作住房等替代方案。
  • 强调了解法律权利和遵守法规的重要性。

Just Simply - Stop saying how simple things are in our docs​

  • 在技术文档中使用 "简单 "这个词，对于那些正在挣扎的读者来说，可能是一种居高临下的态度和不屑。
  • 当有人阅读技术文档时，这通常意味着他们正在努力学习一个新的概念，所以通过暗示它应该很简单而让他们感觉更糟是没有帮助的。
  • 在文档中分享对代码的兴奋和热情是很重要的，但可以不使用可能被解释为居高临下的语言来这样做。

行业反应​

  • 清晰简洁的文档很重要，但友好的语气也可以是有效的
  • 使用 "简单 "和 "容易 "这样的夸张术语会抑制清晰度，并产生误导。

工程师们开发出能去除 "永远的化学品 "的水过滤装置​

  • 不列颠哥伦比亚大学的工程师们已经开发出一种有效的水处理方法，可以去除饮用水中的 PFAS，也被称为 "永远的化学品"，使用一种独特的吸附材料，可以捕捉和破坏存在于供水中的所有 PFAS 颗粒。
  • 由 Madjid Mohseni 博士和他的团队创造的技术可以捕获高达 99%的 PFAS 颗粒，并且可以再生和潜在地重复使用，消除了有毒废物的环境挑战。
  • 这种新的水过滤技术对于那些缺乏资源来实施昂贵的解决方案以消除 PFAS 的小社区的人们来说特别有利，而且在分散的和家庭的水处理中会特别有用。

行业反应​

  • 永远的化学品具有很强的抗分解能力，可以在环境中积累，并与人类和动物的健康问题有关
  • 新系统使用等离子体技术实时处理大流量的水，可用于处理饮用水、废水和农业径流。

Minetest: An open source voxel game engine​

  • Minetest 是一个开源的体素游戏引擎，允许用户玩预先制作的游戏，修改现有的游戏，创建自己的游戏，或加入多人服务器。
  • 该游戏引擎可用于各种平台，包括 Windows、macOS、GNU/Linux、FreeBSD、OpenBSD、DragonFly BSD 和 Android。
  • Minetest 的最新版本是 5.7.0，于 2023 年 4 月 8 日发布。

行业反应​

  • 围绕微软对 Minecraft 的管理以及用户对分裂社区和执行聊天节制的抱怨，引起了讨论。
  • Minetest 与 Minecraft 相似，但由于其开源性质，允许更多的定制选项；然而，它可能不被一些玩家所喜欢，而不是 Minecraft。

纯 Sh 圣经​

  • "Pure sh Bible "是一本关于外部进程的 POSIX sh 替代品的集合，旨在从脚本中去除不需要的依赖性，并使其更快。
  • 该书涵盖了关于字符串、文件、文件路径、循环、变量、条件表达式、算术运算符的主题，并提供了常见的 Unix 命令的替代品的例子。
  • 本书提倡在文本格式和颜色方面使用原始转义序列而不是 tput。

行业反应​

  • 一些用户建议使用 Python 或 Perl 来编写更复杂的脚本，而其他用户则认为 shell 脚本是一种可行的选择。
  • 提到了避免潜在的危险做法的重要性，如使用 eval 或依赖 shell 特定的转义序列。

Koyaanisqatsi 的 40 年​

  • Koyaanisqatsi "是 20 世纪 80 年代的实验电影，今年将庆祝其 40 周年。
  • 该片由戈弗雷-雷吉奥(Godfrey Reggio)执导，只包括视觉和音乐，没有任何对话或情节，探讨了自然、技术和人类之间的关系。
  • 影片的标题来自霍皮语，意思是 "失去平衡的生命"，这部电影已经成为经典和前卫电影的主力。

行业反应​

  • 这部电影在 20 世纪 80 年代上映时和之后都激发了许多人的灵感和共鸣。
  • 这部电影被比作音乐录影带，并对其产生了影响，同时也影响了同类型的其他电影。

FAA 否决了工程师的意见，让波音麦克斯继续飞行​

  • FAA 推翻了个别工程师的建议，在 2019 年第二次致命的坠机事件后停飞波音 737 Max 飞机。
  • FAA 官员倾向于等待更详细的数据和信息，然后决定停飞飞机。
  • 交通部监察长办公室的一项调查建议 FAA 记录如何做出关键和紧急的安全决定，以防止未来发生类似事故。

行业反应​

  • 关于航空业监管官员的资格和利益冲突问题存在争议
  • 谈话强调了航空业对问责制和独立监督的需求

开发过程中我最喜欢的 C 编译器标志​

  • 本文介绍了 GCC、Clang 和 MSVC 中对开发者来说重要的 C 编译器标志，重点是警告、静态和动态运行时检查，以及调试信息。
  • 启用-Wall -Wextra 和-Wdouble-promotion 等标志可以帮助静态地检测错误。
  • 使用像 Address Sanitizer 和 Undefined Behavior Sanitizer 这样的净化器可以帮助检测动态运行时错误和数据竞赛，而用-g3 正确配置调试信息对于有效调试至关重要。

行业反应​

  • 一些标志旨在提高性能，重新输出符号，并解开 C 编译器的束缚
  • 开发人员建议在开发过程中尽早和经常使用净化器，以发现 C 和 C++程序中的内存错误，具体的标志和设置被强调了
