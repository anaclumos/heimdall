我因鳞癌而奄奄一息，而潜在的治疗方法却遥不可及​

  • 作者罹患鳞状细胞癌，已无治疗方法。
  • mRNA 肿瘤疫苗是一种可能的治疗方法，它在治疗头颈部鳞状细胞癌方面显示出巨大的前景。
  • 美国食品和药物管理局(FDA)对新药的审批程序缓慢，阻碍了及时获得可能挽救生命的治疗方法，作者呼吁为临终病人提供更有力的 "尝试权 "推定。

业界反应​

  • 身患鳞状细胞癌的作者强调了他们在获得潜在治疗方法方面所面临的挑战。
  • 美国食品和药物管理局(FDA)在批准鳞状细胞癌等疾病的治疗方法时采取了谨慎的态度，这种态度被批评为阻碍了疾病的进展，延误了获得可能挽救生命的治疗方法。
  • 人们对允许临终病人尝试实验性治疗的伦理和安全性展开了争论，呼吁在确保病人安全的同时，采用更灵活、更快捷的审批程序。

加州理工学院诺贝尔奖获得者庆祝百岁生日，然后继续工作​

  • 加州理工学院化学教授鲁迪-马库斯(Rudy Marcus)以座谈会的形式庆祝了自己的百岁生日，展示了他漫长的职业生涯和对科学的贡献。
  • 马库斯是诺贝尔化学奖得主，以研究电子转移反应和简化复杂问题的能力而闻名。
  • 尽管年事已高，马库斯仍在继续工作并发表研究论文，这表明了他对科学探索的持久好奇心和奉献精神。

工业反应​

  • 加州理工学院的一位诺贝尔奖获得者庆祝了自己的百岁生日，并继续工作。
  • 对每个人来说，退休并不是一个自动的里程碑，有些人即使年事已高，也能在工作中找到激情和目标。
  • 年龄不应成为从事有意义工作的限制因素，这位诺贝尔奖获得者的成就就证明了这一点。

Plane - Jira 的开源替代方案​

  • Plane 是一款开源软件开发工具，有助于以简单、可定制的方式管理问题、冲刺和产品路线图。
  • 它提供了简单直观的用户体验，通过列表、看板和日历等各种视图来可视化任务和工作流程。
  • Plane 允许与 Slack 和 GitHub 等其他工具轻松集成，并提供附件、评论和强大的通知等功能。

业界反响​

  • Plane 是流行的问题跟踪和项目管理工具 Jira 的开源替代产品。
  • 用户称赞 Plane 简洁、完整，整体第一印象良好。
  • 一些用户对需要改进的地方提出了反馈意见，如用于编写任务的屏幕空间，以及需要更清晰的说明如何使用标记符。

Shopify员工违反保密协议透露公司用人工智能取代下岗工人​

  • 一名 Shopify 员工违反保密协议，透露公司正在用人工智能和廉价合同工取代下岗工人。
  • 这名员工在推特(Twitter)上强调了Shopify如何积极拥抱人工智能技术，即将为商家推出名为 "Sidekick "的人工智能助手。
  • 这种削减成本的策略对客户满意度产生了负面影响，导致客户支持严重延迟，平台上的诈骗业务也可能增加。

业界反应​

  • 据一名违反保密协议的员工透露，Shopify 正在用人工智能取代被解雇的员工。
  • 客户服务转向人工智能的驱动力是成本效益和提高数量，而不是为客户提供更好的服务。
  • 关于在客户服务中使用人工智能的益处和弊端，包括失去人与人之间的互动以及可能降低服务质量等问题，一直存在争论。

联邦调查局对美国参议员不当使用 702 监视权​

  • 美国联邦调查局被发现不当使用《外国情报监视法》第 702 条规定的监视权，搜索一名美国参议员、一名州议员和一名州法官的信息。
  • 第 702 条允许对位于国外的外国人进行无证监视，但该条款因可能侵犯与被监视者进行通信的美国人的隐私而受到批评。
  • 这一消息对情报部门推动重新授权第 702 条的工作提出了挑战，并凸显了改革以保护公民权利和隐私的必要性。

业界反应​

  • 联邦调查局对一名美国参议员不当使用监控权，引发对政府滥用权力的担忧。
  • 关于财富分配和税收的辩论，支持和反对向富人征税的观点不一而足。
  • 讨论提出了安全与隐私之间的平衡、监督的必要性以及政府机构内部腐败的可能性等问题。

Putting the "You" in CPU​

  • 这篇文章解释了在计算机上运行程序时会发生什么，包括多进程、系统调用、内存管理和可执行文件加载。
  • 作者在知识空白的情况下做了大量研究，以了解计算机从启动到程序执行的工作原理。
  • 文章的写作方式通俗易懂，对刚接触该主题的读者大有裨益。

业界反响​

  • 把 "你 "放进 CPU》是一个开源项目，旨在为学习操作系统和硬件提供更好的资源
  • 该项目由一名 17 岁的自学成才的程序员创建，他发现有关该主题的在线资源在质量和准确性方面存在不足
  • 该项目涵盖一系列主题，包括 CPU 架构、系统调用和内存管理，并包含图表和插图，使内容更易于理解。

Egregoria: 3D City Builder without a grid​

  • Egregoria 是一款独立的城市建设游戏，其灵感来源于《城市：天际线》(Cities:Skylines)，侧重于城市的社会经济方面，并加入了物流元素。
  • 该游戏仍处于早期开发阶段，但已开放源代码，允许玩家贡献和提供反馈。
  • 开发者在博客上介绍了 Egregoria 的开发情况，并提供了如何在不同平台上构建和玩这款游戏的说明。

业界反应​

  • Egregoria 是一款三维城市建设游戏，其开发者没有想到这款游戏会在 Hacker News 上受到如此广泛的关注。
  • 这款游戏仍处于早期开发阶段，许多功能和 3D 模型尚未创建。
  • 开发者在兼顾全职工作的同时，还将该项目作为一个副业来做，这使得开发进度有时很具有挑战性。

重要的编码习惯​

  • 必须养成良好的编码习惯，以避免因长时间坐着和姿势不正确而引起椎间盘滑脱等身体并发症。
  • 每天做伸展运动并在打码时定时休息，有助于改善整体身体健康，减轻背部负担。
  • 通过使用站立桌等符合人体工程学的设备来改善打码环境，有助于获得更健康、更舒适的打码体验。

业界反应​

  • 由于长时间坐着和姿势不良，许多开发人员和程序员都会感到背部和身体疼痛。
  • 文章提出了各种改善姿势和预防背部受伤的策略和锻炼方法。
  • 注意姿势、将锻炼和运动纳入日常工作以及使用符合人体工程学的设备有助于预防和减轻开发人员的背痛。

微软密钥遭破解：影响比我们想象的要大​

  • 微软和 CISA 披露了一起安全事件，一名来自中国的威胁行为者获取了一个私人加密密钥(MSA 密钥)，并用它伪造了访问令牌，影响了 Exchange Online 和 Outlook.com 的多个客户。
  • 被泄露的 MSA 密钥比最初想象的更强大，威胁者可以利用它伪造各种 Azure Active Directory 应用程序的访问令牌。
  • 虽然微软已采取措施降低风险，但由于令牌验证过程中缺乏日志记录，客户可能会发现很难检测到针对其应用程序使用伪造令牌的情况。应用程序所有者必须更新其 Azure SDK 并刷新其应用程序缓存，以防止出现密钥泄露漏洞。

业界反应​

  • 身份提供商的签名密钥价值高、功能强大，类似于证书颁发机构(CA)的密钥。
  • 微软密钥的泄露对云服务的信任和安全产生了重大影响，特别是在身份层方面。
  • 该事件凸显了改进安全措施的必要性，如使用硬件安全模块(HSM)和更严格的密钥管理实践。
