发现黑白棋的计算解决方案：科学家泷泽浩树说：完美下棋总能导致和棋​

  • 泷泽浩树（Hiroki Takizawa）发表了一篇论文，宣布复杂的黑白棋游戏已被计算解决。
  • 黑白棋在计算机科学中具有重要的挑战地位，因为它有大约十万亿个潜在的游戏记录和十万亿个潜在的游戏位置。
  • 这一成就意味着，现在已经通过计算证明，在黑白棋中，双方的完美下法可以导致平局。

反应​

  • 泷泽浩树（Hiroki Takizawa）最近发表的一篇论文揭示，黑白棋游戏因其无数可能的对局记录和局面而被认为是世界上最复杂的游戏之一，但它已被计算解决。
  • 黑白棋是计算机科学的一项重大挑战，因为据粗略估计，黑白棋可能有十万亿个游戏记录和十万亿个游戏位置。
  • 这一突破意味着，参赛双方的完美发挥可以通过计算证明会导致平局。

遗传学研究揭示：海星大部分是头，没有躯干或尾巴：对理解进化和生物多样性的意义​

  • 新的基因研究表明，海星主要具有头状结构，在进化过程中失去了独特的躯干或尾巴。
  • 这项发表在《自然》杂志上的研究开启了关于棘皮动物（包括海星、海胆和海参）与人类之间共同血统的潜在讨论。
  • 研究认为，棘皮动物的身体进化过程可能比以前所了解的要复杂得多。研究这些海洋生物可以帮助人们了解地球的生命进化和不同物种的健康状况。

反应​

  • 新的基因研究表明，海星或海星主要是没有躯干或尾巴的头，在长期进化过程中失去了这些特征。
  • 这项研究可以揭示棘皮动物（包括海星、海胆和海参）与人类之间的共同祖先，表明棘皮动物身体的进化方式比以前所理解的更为复杂。
  • 发表在《自然》杂志上的这项研究成果表明，研究棘皮动物可能会进一步了解地球上的生命进化，并有助于理解各种物种的健康状况。

微软架构师倡导使用 TypeScript 更简单、更安全的 C++ 方法​

  • 微软公司的赫伯-萨特（Herb Sutter）提议，通过类似于 TypeScript 的计划，让 C++ 编程语言变得简单 10 倍、安全 50 倍。
  • 这种方法代表了与当前 C++ 代码、库和工具的无缝兼容性，以及与 ISO C++ 的全面标准演进支持。
  • 萨特的实验性语法 Cpp2 是 100% 纯 C++ 的尝试，它集成了更强的通用性、改进的默认设置、更少的仪式和更少的漏洞，偏离了之前遵循的 "Dart 计划"。

反应​

  • 微软公司的软件架构师 Herb Sutter 建议精简著名的 C++ 编程语言，将简洁性提高十倍，安全性提高五十倍。
  • Sutter 建议为 C++ 制定一个 "TypeScript 计划"，强调与现有 C++ 代码、库和工具的不间断互操作兼容性，并提供 ISO C++ 标准支持。
  • 他介绍了一种实验性语法 Cpp2，意在成为纯粹的 C++，提供增强的通用性、改进的默认设置、降低的复杂性和更少的漏洞。这种方法与之前与 "Dart 计划 "一致的项目有很大不同。

SARS-CoV-2 改变线粒体功能，导致能量耗竭和器官衰竭联合国大学研究人员​

  • 包括 Jonathan C. Schisler 在内的一组研究人员发现了 SARS-CoV-2 对人体能量储存的影响，有可能导致器官衰竭。
  • 研究显示，病毒从基因层面改变了线粒体，抑制了利用氧气产生细胞能量的特定基因，造成了他们所说的 "能量中断"，从而导致细胞死亡和炎症。
  • 这些发现为了解人体对病毒的反应以及减轻与 COVID-19 相关的慢性症状铺平了道路。未来的研究将深入探讨线粒体功能障碍的持续时间和可能的恢复情况，特别是在长期COVID病例中。

反应​

  • 联合国大学医学院的 Jonathan C. Schisler 博士在一项研究中阐明了 SARS-CoV-2 感染是如何影响人体能量储存并导致器官衰竭的。
  • 研究发现，SARS-CoV-2 会改变线粒体的基因，通过阻断利用氧气产生细胞能量的特定基因，造成重要器官的 "能量中断"，从而阻止人体能量储备的补充。
  • 这一发现至关重要，因为它有助于了解影响心脏、免疫系统和大脑神经元的慢性 COVID 症状。目前的研究重点包括长期 COVID 病例中线粒体功能障碍的寿命以及潜在的恢复方法。

微软 Exchange 发现四个零日漏洞，允许 RCE 和数据窃取​

  • 在 Microsoft Exchange 中发现了四个零日漏洞，可被远程利用来执行任意代码或披露敏感数据。
  • 趋势科技的 "零日计划"（ZDI）向微软通报了这些漏洞，但微软认为这些漏洞还没有严重到必须立即采取行动的地步。
  • ZDI 建议限制与 Exchange 应用程序的交互，实施多因素身份验证，并提到某些漏洞需要事先访问电子邮件凭证。微软表示已采取保护措施，并将在未来的更新和产品中解决这些问题。

反应​

  • Microsoft Exchange 中发现了四个零日漏洞，包括远程代码执行 (RCE) 漏洞和数据验证问题，这些漏洞可能导致未经授权的代码执行或敏感数据暴露。
  • 尽管趋势科技的 "零日计划"（ZDI）已经通知微软，但微软并不认为这些问题严重到需要立即采取行动的地步。所有发现的漏洞都需要验证才能利用。
  • ZDI 建议限制与 Exchange 应用程序的交互，并实施多因素身份验证作为缓解策略。与此同时，微软声称已采取保护措施，并计划在未来的更新和产品中解决这些漏洞。有些问题已经得到解决，或者需要事先访问电子邮件。
