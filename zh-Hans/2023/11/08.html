通过技术提高银行运营效率：对当前挑战和潜在改进措施的分析​

  • Patrick McKenzie 批评银行因结构混乱、子系统之间沟通不畅而导致运营效率低下，进而引发账户关闭和信用卡欺诈等问题。
  • 他指出，旨在节省银行时间和资源的分级客户服务系统往往会加剧客户的挫败感和效率低下。此外，他还指出某些法律义务，如不披露可疑活动报告，可能会导致账户突然关闭，给客户带来更多困惑。
  • 麦肯齐建议，技术改进可以加强银行业务和客户服务，但他也承认在全系统范围内采用技术需要时间。他还要求重新评估一些对客户造成不必要伤害的法规。

反应​

  • Patrick McKenzie 仔细检查银行因子系统内沟通和组织不力而导致的运营效率低下，从而引发账户关闭和信用卡欺诈等问题。
  • 他指出，银行的分级客户服务结构和某些令人困惑的法律义务（如不披露可疑活动报告）是问题的一部分。
  • 麦肯齐认为，改进后的技术可以提高银行的运营能力和客户体验，但他也承认，在整个金融系统的实施可能需要循序渐进。他还强调，有必要重新考虑对客户造成不必要伤害和混乱的具体法规。

强化 Northlight 技术，提升《艾伦-威克 2》的游戏体验​

  • 艾伦-觉醒 2》的 Northlight 开发团队引入了多项技术改进，例如新的面向数据的游戏对象模型可提高内存效率和性能，基于体素的角色控制可改进导航。
  • 开发人员采用了由 Roblox 的 Lua 衍生而来的语言 Luau，从而消除了约 8 万行多余的代码。他们还引入了新的风力系统，以获得真实的物理效果，并为大规模环境设计引入了散射工具。
  • 续集采用了新的 GPU 驱动渲染管道，支持 HDR，并增强了透明度渲染和视觉特效工具，从而提高了艺术灵活性。此外，它还支持光线追踪直接照明。

反应​

  • 艾伦-威克 2》的 Northlight 开发团队在技术上进行了多项改进，例如采用了内存效率高的面向数据的游戏对象模型和基于体素的角色控制，以获得更流畅的导航体验。
  • 引入了可产生逼真物理效果的新风系统，以及用于大规模环境设计的散射工具。此外，专有的脚本语言被 Luau（源自 Roblox 的 Lua）取代，减少了约 8 万行不必要的代码。
  • 续作采用全新的 GPU 驱动渲染管道，可呈现更丰富的游戏世界细节，并改进了透明度渲染和视觉特效工具。它还支持 HDR 和光线追踪直接照明，为美工人员提供了更大的创作灵活性。

欧空局欧几里得太空任务首次公布宇宙详细彩色图像，为绘制宇宙最大 3D 地图做准备​

  • 欧空局的欧几里得（Euclid）飞行任务公布了其首批全彩色宇宙学图像，在大片天空中展示了无与伦比的清晰度。
  • 欧几里得望远镜将生成最全面的三维宇宙地图，并仔细研究占宇宙 95% 的暗物质和暗能量。
  • Euclid 的初始图像展示了其独特的能力，能够一次性在广阔的天空区域生成清晰的可见光和红外图像。这项任务是欧洲卓越成就和全球合作的缩影。

反应​

  • 欧洲航天局（ESA）的欧几里得（Euclid）太空任务首次披露了宇宙的全彩色图像，大部分天空都非常清晰。
  • 欧几里得望远镜旨在生成最全面的宇宙三维地图，它将深入研究占宇宙 95% 的暗物质和暗能量。
  • 在接下来的六年里，Euclid 将仔细观察长达 100 亿光年的数十亿个星系，展示其在一次会议中提供大片天空中清晰的可见光和红外图像的独特能力。

优化容器中的 Go 应用程序：Linux 调度器和 CPU 限制的作用​

  • 博文强调，在运行应用程序时，有必要在容器编排器中设置 CPU 限制，以避免使用主机的所有 CPU 能力。
  • 深入介绍了 Go 垃圾收集器进程、Linux 调度器的作用，以及通过 GOMAXPROCS 环境变量控制 CPU 线程的重要性。
  • Uber 引入了 "automaxprocs "库，它能自动从容器的 cgroups 中计算 GOMAXPROCS 值，从而简化了在容器化应用程序中运行 Go 时的设置。

反应​

  • Go 开发人员在博客中强调了在容器编排器中设置 CPU 限制的重要性，以避免主机的 CPU 消耗过高，因为 Go 运行时往往会使用所有可用的 CPU 能力，从而可能导致高延迟。
  • 作者建议使用 GOMAXPROCS 环境变量控制 Go 运行时可创建的 CPU 线程数，该变量与 CPU 配额一致。
  • Uber 创建了 "automaxprocs "库，它可以自动从容器的 cgroups 中计算出该环境变量值，从而满足了在容器化应用程序中运行 Go 时合理分配 GOMAXPROCS 的需要。

介绍 Gleam：基于 Erlang 运行时的并发、用户友好编程语言​

  • Gleam 是基于 Erlang 运行时的强大程序，具有现代语法和强大的类型系统，其并发系统和快速不可变数据结构可处理任何规模的工作负载。
  • 该程序支持多核操作，使用并发垃圾回收器，并提供自己的编译器、构建工具、格式器、编辑器集成和软件包管理器。它可与 Erlang 和 Elixir 等其他 BEAM 语言的软件包互操作。
  • 除核心功能外，Gleam 还能编译为 JavaScript，生成用于高效外部交互的 TypeScript 定义，并优先考虑用户友好型错误信息，旨在实现多元文化的包容性。

反应​

  • Gleam 是一个基于 Erlang 运行时的强大程序，具有现代化的语法和强大的类型系统，其并发系统和快速不变的数据结构可处理任何规模的工作负载。
  • 它自带编译器、构建工具、格式化器、编辑器集成和包管理器，并能与 Erlang 和 Elixir 等其他 BEAM 语言的包进行交互。它还能编译为 JavaScript 并生成 TypeScript 定义，以实现高效的外部交互。
  • 用户友好的错误信息和多元文化的包容性是 Gleam 的重中之重，因为它的目标是让不同的用户群体都能方便高效地使用。

缅因州 2023 年选举选票将包括完整印制原始州宪法的提案​

  • 缅因州提议通过 2023 年选举选票中的一项立法提案修改宪法，确保宪法的所有条款都出现在州务卿制作的正式印刷文本中。
  • 如果投 "赞成 "票，则将恢复该文件中因 1876 年修正案而遗漏的原有部分，如缅因州对瓦巴纳基人的条约义务。
  • 该提案并不打算改变对瓦巴纳基民族的现有承诺，而是让公民能够全面查阅宪法原文。

反应​

  • 缅因州将在 2023 年的选举选票上提出一项立法提案（第 6 号问题），以修改州宪法，确保所有条款都包含在州务卿准备的正式印刷文本中。
  • 投 "赞成 "票将恢复因 1876 年修正案而在印刷本中遗漏的原始章节，包括缅因州对瓦巴纳基人的条约义务。尽管这些条款在印刷本中没有出现，但它们仍然有效。
  • 该提案力求在不改变缅因州对瓦巴纳基部落现有 "责任和义务 "的前提下，使公民更容易获得完整的宪法原文。

eIDAS 2.0 的第 45 条：欧盟网络安全标准的潜在挫折​

  • 欧盟（EU）正在讨论 eIDAS 2.0，这是一项可能允许政府与证书颁发机构合作监控加密流量的新法规。
  • 该法规可能会在未经欧盟成员国政府批准的情况下影响某些证书颁发机构的现代安全要求，从而引发潜在的隐私问题。
  • 特别是该法规的第 45 条引起了特别关注，因为它可能会降低欧洲互联网用户的网络浏览器安全标准。正式文本预计将于 11 月 8 日定稿。

反应​

  • 欧盟正计划批准一项名为 eIDAS 2.0 的新法规，允许各国政府与证书颁发机构合作，对加密流量进行潜在监控。
  • 该条例可能会在未经欧盟成员国政府同意的情况下破坏证书颁发机构的当代安全前提条件。
  • 该法规中的第 45 条引起了主要是欧洲互联网用户对隐私的担忧，因为它可能导致网络浏览器安全标准的降低。该法规的最终文本将于 11 月 8 日确定。

介绍 SectorC：x86 机器引导扇区中世界上最小的 C 编译器​

  • SectorC 是用 x86-16 汇编语言编写的 C 语言编译器，由于它可以放在 x86 机器的引导扇区中，因此有可能成为最小的 C 语言编译器。
  • SectorC 支持大量的 C 语言子集，尽管体积小巧，却能编制复杂的程序，例如涉及移动正弦波动画的程序。
  • 虽然 SectorC 被认为是一个小众的使用场景，但对于那些热衷于了解 x86-16 bios 功能和机器模型而不需要大量 x86 汇编知识的人来说，SectorC 不失为一个有用的工具。

反应​

  • SectorC 是一个 C 语言编译器，据说是有史以来开发的最小的编译器之一，采用 x86-16 汇编语言编写。该编译器的独特之处在于，它可以装在 x86 机器的引导扇区中。
  • 尽管体积小巧，但 SectorC 支持 C 语言的显著子集，包括函数、if 语句、while 语句和其他功能。这样就可以创建复杂的程序，如移动的正弦波动画。
  • 它的开发重点似乎是那些希望了解 x86-16 bios 功能和机器模型的人，为他们提供了一座探索的桥梁，而无需学习大量的 x86 汇编程序。
