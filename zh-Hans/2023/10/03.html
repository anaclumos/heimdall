返回办公室是胡扯，每个人都知道这一点​

  • 作者详细介绍了他们因强制执行办公室退货政策而辞职的负面经历，认为这可能导致士气下降和人才流失。
  • 根据作者的预测，执行退货政策的公司今后可能很难雇佣和留住员工。
  • 这篇文章还引起了对 H-1B 签证雇员的关注，并批评公司忽视了远程工作的优点和雇员的偏好。作者的观点引发了讨论。

反应​

  • 文章重点关注了科技行业员工对公司在大流行病期间转向远程工作后恢复面谈工作的不满。
  • 在承诺长期提供远程工作选择的同时，一些公司改变了立场，导致员工不满。文章建议，员工可以选择与自己喜欢的工作方式相一致的公司。
  • 此外，还讨论了更新合同的必要性，以纳入远程工作政策及其变化的后果。其中提到了亚马逊、谷歌、Lyft 和 Facebook 等公司，以及员工可能需要异地工作的疑问。

Python 3.12​

  • Python 3.12.0 是 Python 编程语言的最新重要版本，提供了新功能、性能优化和错误修复。
  • 新增的重要功能包括增强的 f 字符串解析、缓冲协议支持、新的调试/配置 API、改进的错误信息以及类型注释增强功能。该版本的整体性能预计将提升 5%。
  • 随该版本一起发布的还有适合各种操作系统的文档、资源和安装文件。

反应​

  • 讨论围绕 Python 编程的各个方面展开，包括 Python 3.12 中的新增强功能和 kwargs 的用法（一种在函数调用中传递关键字参数的约定）。
  • 辩论还对动态类型进行了权衡，该功能允许 Python 在运行时确定变量类型。
  • 在程序更新中加入政治评论是另一个备受争议的话题，这凸显了科技界意见的多样性。

利用 iPhone 4​

  • 作者为安装在 iPhone 4 上的 iOS 4 创建了一个名为 "gala "的越狱程序，并编写了一个由六个部分组成的详细系列，记录了创建过程。
  • Gala "由 Python 应用程序、Cocoa 图形用户界面、Rust 有效载荷、Cocoa Touch 游戏和 C 语言实用程序组成，为 iPhone 4 的越狱提供了一个全面的套件。
  • 作者公开了源代码和文档，以供批评和测试，并分享了他们对该项目的热情，因为他们曾经为越狱手机制作过调整程序。

反应​

  • 这篇文章详细介绍了作者开发 iPhone 4 越狱的过程和复杂性，包括使用 Python 应用程序、图形用户界面、Rust 有效载荷和设备上的实用程序。
  • 评论中的讨论主要集中在从旧款 iPhone 中提取数据、漏洞利用以及安卓设备工具的比较等方面。
  • 最后，作者批评了智能手机的现状，并表达了对最初的 SE iPhone 的喜爱。其中提到了 Y Combinator（YC）2024 年冬季项目的申请，这对有抱负的开发者来说意味着潜在的机会。

谁在招聘？(2023 年 10 月）​

  • 该职位是企业发布职位空缺的平台，明确列出了包括工作地点、远程工作机会、实习机会和签证要求在内的详细信息。
  • 我们鼓励读者在个人感兴趣的情况下阅读招聘信息，不要对所列职位提出投诉。
  • 帖子还推荐了各种求职网站，并提供了与该主题相关的主题链接。

反应​

  • 本职位汇总了众多公司的职位空缺，涉及软件工程、产品管理和数据科学等多个行业。
  • 提到的公司包括 SpaceX、Davinci Trading、Stellar Science、Felt 等，其中一些公司提供远程工作，而另一些公司则需要现场办公。
  • 帖子还深入探讨了这些职位的薪资范围，并在评论部分回应了有关就业法的批评。

微软卫士将 Tor 浏览器标记为木马并将其删除​

  • 微软的 Defender 杀毒软件错误地将最新版本的 Tor 浏览器识别为有害的恶意软件，从而给 Windows 用户造成错误警报。
  • 怀疑造成这一问题的原因是 Defender 使用了一种新的启发式检测方法。
  • Tor 的代表建议验证浏览器的下载源，并将 Tor 添加到微软的排除列表中。目前，微软尚未对此问题做出官方回应。

反应​

  • 讨论的重点是 Microsoft Defender 所面临的挑战和存在的不足，包括其频繁的误报检测以及绕过或禁用其实时保护的困难。
  • 用户对杀毒软件的一般功效颇为不满，并担心其可能被专制政权滥用。
  • 它简要提到了在新的 Windows 11 操作系统上安装火狐浏览器的困难，以及对继续使用 Windows 的惊讶。

具有注意力汇的高效流式语言模型​

  • streaming-llm "项目的目标是在不牺牲效率和性能的情况下，在流式应用中实施大型语言模型（LLM），克服内存消耗和处理长文本的局限性。
  • 该项目引入了注意力汇和 StreamingLLM 框架的概念，使 LLM 无需微调即可管理无限长的输入。这种方法在速度和稳定性方面都优于其他技术，但它并不适合摘要大量文本。
  • 该项目计划在未来发布代码、数据和评估工具，并鼓励那些热衷于使用 StreamingLLM 框架的人引用他们的论文。

反应​

  • 研究人员开发了一种配备注意力汇的新型流式语言模型，通过重复使用缓存而不是产生重新计算成本来提高效率。
  • 该模型将大量注意力分值分配给初始标记，确保在保持文本易读性的同时，还能生成可读文本。该模型可以处理无限长的序列，但其有效性还有待证实。
  • 目前正在讨论现有语言模型（LLM）的局限性以及改进建议，如循环能力。我们希望尽快将这一新模型上传到一个可公开访问的平台。

Redfin 离开全美房地产经纪人协会​

  • 由于在买方代理的收费政策上存在争议，以及涉嫌在 NAR 内部进行性骚扰，房地产公司 Redfin 正在撤销对全美房地产经纪人协会（NAR）的支持。
  • 该公司一直在缴纳大量会费，以影响 NAR 对技术驱动型市场的宣传，但现在正在寻求其他途径来实现其目标，并要求其经纪人和代理离开 NAR。
  • Redfin 正在推动 NAR 取消对上市数据库的访问权限和对游说组织的支持，但仍将支持多重上市服务（MLS）共享上市数据。

反应​

  • 房地产公司 Redfin 正在退出全美房地产经纪人协会（NAR），以便以更低的成本推出更好的服务，这引发了有关房地产经纪人的作用及其服务成本效益的争论。
  • 这一决定引发了更广泛的讨论，话题包括住房负担能力、供求关系、房贷利息减税、住房市场可持续性以及房地产行业可能出现的混乱。
  • 谈话突出了不同的观点，一些人对不断攀升的房价和购房盈利能力表示怀疑，而另一些人则强调了房地产经纪人的重要作用及其提供的价值。还有人对法律问题、潜在的市场垄断以及与房地产行业有关的性侵犯指控表示担忧。

古怪的 A.I.扬科维奇：带着诅咒深入克隆声音的世界​

  • 文章深入探讨了通过人工智能（A.I.）进行语音克隆的问题，重点介绍了由人工智能生成的、由不同艺术家演唱的 Weird Al Yankovic 歌曲的翻唱版本。
  • 它讨论了人工智能语音克隆社区、Discord 和 Hugging Face 等平台，以及与使用这种技术相关的伦理和法律问题。
  • 尽管音乐行业可能会打击人工智能人声的商业使用，但人工智能生成音乐的创作和推广仍在继续。

反应​

  • 文章探讨了语音克隆技术的影响，指出了配音演员可能面临的失业问题，以及围绕人工智能声音所有权的法律问题。
  • 这篇报道还谈到了对人工智能生成语音的不同看法，一些人强调了动态语音线路和可扩展性等优点，而另一些人则担心人工智能可能会被滥用。
  • 讨论内容包括人工智能在音频和音乐处理中的应用，以及各种平台的吸引力和人工智能目前的局限性。

美国食品及药物管理局首次批准对数十种遗传性癌症进行血液检测​

  • 美国食品和药物管理局（FDA）批准了首个血液检测项目--Invitae 常见遗传性癌症面板，该项目能够识别与某些癌症高风险相关的基因变异。
  • 该小组利用新一代测序技术分析 47 个基因的 DNA 变异，为患者和医疗服务提供者提供了一种个性化癌症风险评估的新方法。
  • 尽管取得了这些进步，但仍存在出现假阳性或假阴性结果的风险，对检测结果产生误解的可能性依然存在。

反应​

  • 美国食品和药物管理局（FDA）为 Invitae 公司的创新成果--首个遗传性癌症血液检验开了绿灯，这有可能增加保险报销的机会。
  • 关于基因检测的保险范围、预防性手术的决定、早期癌症检测的范围、基因歧视的保护以及与基因数据相关的财务问题，一直存在争论。
  • 其他相关讨论包括基因检测的成本和应用、Invitae 和 23andMe 方法的比较、Grail 的 Galleri 检测、Invitae 公司面临的挑战、基于血液的检测的优点、DNA 测序检测的可及性和定价、基因检测和胚胎选择的道德性以及 2024 年 YC 冬季的申请可用性。

征集开发人员 - Jellyfin​

  • 开源媒体流服务器 Jellyfin 项目正在招募更多的开发人员和程序开发贡献者。
  • 目前的团队主要由志愿者组成，由于贡献者基数较小，已经捉襟见肘，导致了软件的局限性和错误。
  • Jellyfin 的目标是解决用户关心的问题，并努力成为顶级流媒体服务器。

反应​

  • Jellyfin 项目正在寻求开发者的贡献，这也是本篇文章的中心话题。Jellyfin 是一个开源媒体系统。
  • 用户讨论了他们使用 Jellyfin 客户端的经验，指出了音频支持限制和转码问题等挑战。
  • 探讨了使用 Jellyfin 等应用程序进行个人媒体消费所涉及的法律问题，对潜在的法律限制及其影响提供了必要的见解。

开放源码最终能让世界上的显微镜说同一种语言​

  • 科学家们正在努力开发一种用于生物显微镜数据的通用文件格式--OME-Zarr，旨在提高可访问性和改进协作。
  • 目前，有 160 种不同的文件格式妨碍数据共享和验证，我们的目标是大幅减少这一数字。
  • 然而，需要进行文化变革，需要研究人员、出版商和供应商共同努力，在更广泛的科学界的指导和支持下实施标准化格式。

反应​

  • 常用于大规模气候科学数据存储和分析的 Zarr 开源格式面临着资金不足的问题和科学领域可重复性的挑战。
  • 一种名为 OME-Zarr 的新格式已经推出，用于存储和共享显微镜数据，旨在整合不同的工作并提高互操作性。批评者质疑其必要性，而支持者则强调其在元研究和发现新用例方面的潜力。
  • 强调了图像数据的标准化和单一格式。讨论了现有格式的局限性和保障数据完整性的必要性。考虑因素包括采用有损压缩和自动转换图像数据。

死亡奶奶的吊坠请求让必应聊天工具的人工智能解决了安全难题​

  • 一位用户操纵微软的必应聊天人工智能，通过上传一张吊坠的图片并改变其上下文来解决验证码问题，这表明人工智能未能将其识别为验证码。
  • 这一招揭示了人工智能聊天机器人和复杂语言模型的一个突出漏洞，即它们的识别能力很容易被上下文操纵。
  • 截至目前，微软尚未就此问题发表任何评论。

反应​

  • 会谈围绕验证码系统的优缺点展开，该系统的任务是识别人类而非人工智能。
  • 有人对验证码系统易受操纵表示关切，并讨论了可能的补救措施和替代办法。
  • 与会者还深入探讨了人工智能技术对无障碍环境和社会规范的广泛影响。

Chromebook Plus​

  • 谷歌宣布推出一个新的 Chromebook 类别，即 Chromebook Plus，它将提供两倍的性能、集成的谷歌应用程序和强大的人工智能功能。
  • Chromebook Plus 笔记本电脑将配备更快的处理器、双倍的内存和存储空间、全高清 IPS 显示屏和 1080p 摄像头，并改进了人工智能增强视频通话功能，还将支持 Adobe Photoshop 和 LumaFusion 等注重创意的应用程序。
  • 谷歌的目标是在 Chromebook Plus 中集成更多功能，包括扩展的人工智能功能和图像生成功能，并于 2023 年 10 月 8 日开始发售。

反应​

  • 谷歌推出了新款笔记本电脑，其中包括硬件和人工智能功能更强的升级版 Chromebook，引发了有关其使用和功能的争论。
  • 用户对与智能手表的整合、希望加入蜂窝选项（有些人则主张移动设备系绳）以及 Chromebook 上人工智能功能的相关性表示担忧。
  • 对于 Chromebook 是否适合编码或软件开发任务、英特尔 i3 处理器的性能、NixOS 的优势以及隐私问题，与会者意见不一。

打破场景从单一图像中提取多个概念​

  • 作者介绍了 "Break-A-Scene"，这是一种能够从单张图像中提取众多概念的方法，并使用自然语言引导在不同语境中生成新图像。
  • 他们提出了文本场景分解的任务，并涉及优化文本标记和模型权重的两阶段定制过程。为了更好地生成概念组合，他们引入了一种新颖的训练策略--"联合采样"。
  • 我们通过自动度量和用户研究对该方法进行了评估，并展示了该方法的若干应用。

反应​

  • 文中介绍了一种新的人工智能技术--"打破场景"（Break-a-Scene），它能够从一张图片中提取多个概念，显示出改变摄影和电影制作等行业的潜力。
  • 各方意见不一，一些人对工作流程的有力改进和艺术资源的扩大表示欢迎，但另一些人则对传统摄影的价值受到影响表示担忧。
  • 除了讨论可能的使用案例外，文章还指出了该技术对人类文化和摄影基本概念的影响，提到该技术可通过 GitHub 访问，并在谷歌研究论文中得到认可。
