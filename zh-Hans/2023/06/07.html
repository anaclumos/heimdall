2023 年 6 月 7 日​

Reddit 杀死第三方应用程序的计划引发了广泛的抗议​

  • Reddit 对第三方应用征收 API 费用的计划引发了用户的抗议和反感，数百个子版块计划在 6 月 12 日进入黑暗期，持续 48 小时。- 第三方应用程序面临着高额的 API 定价，许多开发者说这远远高于其他网站的收费，可能会迫使他们关闭。- Reddit 的官方应用被普遍认为不如第三方选项，而且 API 条款还要求在第三方应用中屏蔽广告，并排除成人内容，这些都是该网站的主要吸引力。

行业反应​

  • Reddit 被指责人为地提高子版块的本地化版本的参与度，批评者认为这符合其战略，即引导用户使用官方应用程序，并在上市前抽出感知价值。- 用户建议实施类似于 Discord 和 Twitch 的资助模式，允许用户为子版块的升级付费，并将部分资金用于资助审核。- 帖子讨论了 Reddit 的移动应用和网站，用户对没有优先修复问题表示不满，并对公司的优先事项提出了批评。

GGML - AI at the Edge​

  • GGML 是一个用于机器学习的张量库，能够在普通硬件上实现大型模型和高性能，并针对苹果硅架构进行了优化。- 它支持 16 位浮点和整数量化，有内置的优化算法，并通过 WebAssembly 和 WASM SIMD 提供网络支持。- 它包括两个项目，用于语音到文本的 whisper.cpp 和用于语言建模推理的 llama.cpp，这两个项目都在苹果硅硬件上展示了高效的性能。

行业反应​

  • GGML 是一个在 CPU 上运行机器学习模型的库，已经得到了风险投资公司的大量资金支持，并允许在商品硬件上进行高效计算。- 人们对开放的核心商业模式和公司与社区之间潜在的利益不一致表示关切。- Willow 和 Home Assistant 是 GGML 的替代方案，用于本地命令检测和语音识别，需要进行基准测试以比较不同的选择。

美国 SEC 起诉 Coinbase，在起诉 Binance 一天后​

  • 美国证券交易委员会(SEC)对加密货币平台 Coinbase 提起诉讼，指责其在加密货币交易上充当中间人，逃避旨在保护投资者的披露要求。- 在这起诉讼之前，世界上最大的加密货币交易所 Binance 也遭到了类似的诉讼，指责他们和他们的首席执行官经营着一张 "欺骗之网"。- 如果美国证券交易委员会在这两起案件中获胜，它可以对加密货币行业主张其管辖权，该行业在很大程度上是在监管之外运作，并改变了市场。

行业反应​

  • 美国证券交易委员会已经对 Coinbase 提起诉讼，指控其交易未注册的证券，不符合法律标准。- 这个问题围绕着特定的加密货币是否符合证券或金融工具的定义。- 美国证券交易委员会没有提供关于什么是或不是证券的指导，使公司没有明确的合法合规途径。

为即将到来的电脑购物者海啸做准备​

  • 计算机历史专家杰森-斯科特(Jason Scott)获得了近 200 期《计算机购物者》，这是一本 20 世纪 80 年代和 90 年代的流行杂志，是硬件和软件的 "圣经"。- 斯科特正在对这些期刊进行扫描，这将导致至少 10 万页的扫描，并将它们送到 Gaming Alexandria 公司进行后期处理，以创建更可读的版本。- 研究人员旨在分析计算机历史，并从保存下来的杂志中找到有趣的信息和趋势，鼓励读者帮助传播关于捐赠缺失问题的消息。

行业反应​

  • 互联网档案馆的《计算机购物者》收藏品因保存了流行技术杂志的遗产而受到赞扬。- 评论者回忆起过去翻阅杂志挑选电脑零件和寻找本地公告板系统的日子。- 读者们讨论了数字化历史计算机杂志的价值，特别是《计算机购物者》，以获取关于历史上个人电脑定价和硬件可用性的宝贵信息。

OpenGL 3.1 on Asahi Linux​

  • Asahi Linux 已经将其图形驱动从 OpenGL 2.1 升级到 OpenGL 3.1，并将 OpenGL ES 2.0 的支持增加到 OpenGL ES 3.0。这意味着更好的渲染质量和更多的功能应用。- 然而，这些驱动程序是试验性的，还不符合 OpenGL 或 OpenGL ES 规范，因此用户可能会遇到错误。- 升级的亮点包括多个渲染目标、多采样、转换反馈和纹理缓冲器对象。具体来说，多重采样是一种有效的方法，可以减少由于在分辨率不足的情况下进行渲染而导致的对角线边缘锯齿状的混杂。它为每个像素创建多个样本，并对它们进行平均，以创建一个规则的图像。然而，苹果公司的 AGX GPU 需要一种独特的方法来进行采样着色，当混合和多采样被启用但采样着色没有被启用时，混合的性能会退步。

行业反应​

  • Asahi Linux 发布了一个具有各种功能的更新，包括对 M2 Pro/Max/Ultra SoC 的基本支持和一种新的基于固件的电池充电控制方法。- 苹果硬件的用户对在其上运行 Linux 的自由表示感谢，但有些人对 Asahi 的可持续性以及是否值得为运行它而购买一台 Mac 进行辩论。- Asahi Linux 已经取得了重大进展，但仍有一些限制和与 GPU 驱动的不兼容，会影响性能。

英国法律承认八爪鱼、螃蟹和龙虾为有生命的生物(2021)​

  • 根据英国法律，八爪鱼、螃蟹和龙虾已被承认为有生命的生物。- 这意味着政府已经承认这些动物能够感受到疼痛和痛苦，并且必须得到相应的对待。- 新法律还禁止销售和分销供人食用的活甲壳类动物，包括龙虾、螃蟹和小龙虾。

行业反应​

  • 根据新的环境措施，英国已经承认章鱼、螃蟹和龙虾是有生命的生物，该措施旨在改善动物福利，特别是无脊椎动物的福利。- 新的法律禁止某些做法，如不经绝育的活体水煮，向未经训练的处理者活体出售十足类甲壳动物，以及去爪。- 新的分类法最终可能导致减少所有动物的痛苦，尽管有些人对禁止活体甲壳类动物消费或改善肉类行业的做法持怀疑态度。

Reddit 永久禁止主张 Lemmy 迁移的用户的账户​

  • Reddit 已经永久封禁了一个用户的账户，因为他支持 Lemmy 并审查了他们的帖子。- 该用户正在主持几个子网站，花了无数时间改善社区，帮助 Reddit 繁荣发展，但他们所有的努力都被 Reddit 突然夺走。- 这一事件凸显了依赖 Reddit 这样的中心化平台的弊端，以及使用 Lemmy 这样的去中心化替代方案的好处，它允许个人主持自己的实例，或者在被审查时加入另一个实例。

行业反应​

  • Reddit 禁止了一个主张迁移到以隐私为中心的社交媒体平台 Lemmy 的用户，这引发了关于一个与 Reddit 等老牌网站竞争的联合和服务器维护的社交媒体平台的好处和缺点的讨论。- 一些用户建议将 Mastodon 作为 Reddit 的替代品，但批评其难以使用和缺乏节制。- 用户正在讨论 Lemmy 作为 Reddit 的联盟式开源替代品的局限性和可扩展性问题，并对其处理流量高峰的能力表示担忧。

苹果视觉​

  • 苹果公司宣布了一款名为 Apple Vision 的新混合现实头盔，将于 2024 年初发布，售价 3499 美元。- 该设备在体验上是一个 VR 设备，但使用其 12 个摄像头来实现 AR，以低时间延迟提供高质量的沉浸式体验。- 苹果 Vision Pro 在生产力和工作方面具有潜力，但可能面临制作内容和缺乏社交关系的挑战。

行业反应​

  • 苹果公司推出了一款名为 Apple Vision 的新 VR/AR 头盔，有 12 个摄像头，手持手势识别控制，专注于现场体验、游戏和生产力。- 该头盔可能在教育、流媒体、装饰和放松方面有潜在的用例，但一些批评者担心孤独感和 3500 美元的高成本。- 对该设备的意见不一，包括对娱乐和保健潜力的兴奋，对隐私的担忧，色情在推动技术创新方面的历史，以及人体工程学设计和晕动症等实际问题。

美国在声称拥有完整的外星飞行器后敦促其披露 UFO 证据​

  • 一位前美国情报官员 David Grusch 声称，美国政府拥有 "完整的和部分完整的 "外星飞行器，但却非法向国会隐瞒有关信息。- 格鲁什称，他在向国会提供这些车辆的机密信息后面临政府的报复，这导致他于 4 月退休。- 现任美国情报官员乔纳森-格雷证实了 "异形材料 "的存在，但没有说明这些车辆和材料的位置。

行业反应​

  • 前政府官员称美国已找到一艘坠毁的外星飞船并秘密研究其技术- 怀疑论、阴谋论和道听途说围绕着地外生命的可能性。- 军方最近发布的信息没有提供关于地外生命存在或访问的具体证据

Nvidia 发布新的 AI 芯片，拥有 480GB CPU 内存和 96GB GPU 内存​

  • Nvidia 发布了一款名为 "Grace Hopper Superchip "的新人工智能芯片，该芯片为大规模人工智能和高性能计算(HPC)应用而设计。- 该芯片拥有 480GB 的 CPU 内存和 96GB 的 GPU 内存，使其成为市场上用于人工智能和 HPC 任务的最快芯片之一。- 该芯片以美国计算机科学家格雷斯-霍普的名字命名，她在早期计算机和编程语言的发展中发挥了重要作用。

行业反应​

  • Nvidia 发布了一款新的人工智能芯片，拥有 480GB CPU 内存和 96GB GPU 内存，被赞誉为超级计算机。- 人们在讨论 ML 工作负载从 GPU 转向 ASIC 的可能性，但 ASIC 的局限性使 GPU 成为更安全的选择。- Nvidia 新的 Grace Hopper 超级芯片结合了 CPU 和 GPU，有 72 个 Neoverse V2 Armv9 核心，是为人工智能、HPC 和游戏应用而设计。
