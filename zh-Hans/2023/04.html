2023 年 4 月 4 日​

Mullvad 浏览器​

Mullvad VPN 和 Tor 项目合作创建了 Mullvad 浏览器，以对抗大规模监控；怀疑论者对使用 Mullvad VPN 绕过地理封锁提出了担忧；一个名为 Tor 浏览器的火狐分叉，支持 Mullvad VPN；Mullvad 因其对开源的承诺和无缝的按使用付费模式而受到称赞；Mullvad 浏览器采用了打击指纹识别的技术；目标是防止在线跟踪和数据收集；Mullvad 免费发布了注重隐私的浏览器，以打击指纹识别；Mullvad 的 VPN 可以绕过屏蔽 VPN 的网站；Mullvad 浏览器旨在与 Tor 网络一起使用或不使用。 Discussion Service, Article.

显示 Discussion Service：未知的快乐，一个使用 WebGL 的微小网络实验​

未知的快乐"，一个基于 WebGL 的网络实验，将音频数据可视化，在 Hacker News 上引起了热议。这个项目的灵感来自于 Joy Division 的专辑封面，创造者花了大约 10 天时间来开发。人们围绕着歌曲选择和 JS 生态系统展开讨论，创作者正在考虑将开发过程拍成视频。科技时报》报道了 IQ 制作的关于 webGL 中基于着色器的动画的视频教程，引发了关于 webGL 学习资源的讨论。用户赞扬了该视频的艺术性和复杂性，同时讨论了在网络浏览器中文本对齐的困难。此外，还有人评论说，"未知的快乐 "这个标题对工作用的笔记本电脑来说是合适的。一位网络开发者使用 WebGL、three.js 和 WebGPU 创建了一个名为 "未知的快乐 "的交互式 Javascript 演示，希望能够轻松地整合到复杂的工作中，尽管有报告称在某些浏览器中难以打开。 Discussion Service, Article.

向 GitHub 说再见​

一位软件开发者因 GitHub 对代码的人工智能训练和 Copilot 货币化的处理而反思离开 GitHub，引发了关于开源执行、道德、赔偿、法律改革和 OSS 许可的辩论。GitHub 的 ToS 必须保护用户在上传代码时的知识产权，而 Copilot 主要使用商定的用户代码。这种情况突出了普遍存在的版权问题，特别是对机器的改造性使用。模型生成的代码属于 GPL 的范畴，以后再写别的东西不属于复制，也不需要开放源代码。 Discussion Service, Article.

特斯拉移除停车传感器，结果可想而知，很糟糕​

特斯拉已将 Model 3 和 Model Y 中的前后停车传感器替换为摄像头。批评者认为，在关键的安全系统中，仅仅依靠计算机视觉而没有传感器融合是有风险的。有人担心，特斯拉的全包方式可能会造成更多的问题，而不是解决。黑客新闻的用户讨论了电动汽车的可用性和功能，包括具体型号和潜在的好处。尽管采取了削减成本的措施，但由于其卓越的驾驶体验和创新的超级充电网络，特斯拉仍然是全球电动车销售的领导者。 Discussion Service, Article.

中捷首席执行官压制了关于习近平的讽刺文章​

人工智能图像生成器 Midjourney 将中国国家主席习近平排除在其平台的政治讽刺作品之外，可能是为了保留对中国用户的访问，这引起了对全球审查规则执行情况的关注。批评者指责 Midjourney 默许了中国的专制政权，阻止了调侃性的提示，压制了关于习近平的讽刺，尽管它有 "创造一切 "的标语。其他评论认为，在各国法律范围内运作，尊重各国法规，是一个艰难的选择，人工智能可能加剧政治争端，限制言论自由。这场争论强调了对完全开源工具的需求，这些工具允许创造性的表达，不受政府或公司的要求约束。 Discussion Service, Article.

在 Mac 销量 "暴跌 "的情况下，苹果在 1 月份停止了 M2 芯片的生产​

据报道，由于 MacBook 销量暴跌，苹果停止了 M2 芯片的生产，导致全球产量下降。尽管 2023 年第一季度收入同比下降 5%，但苹果公司首席执行官认为，该公司在苹果芯片方面处于有利地位。通用汽车公司计划在其车辆中逐步淘汰苹果 CarPlay 和 Android Auto，转而采用与谷歌共同开发的内置信息娱乐系统。关于衡量仇外心理的讨论导致了关于多样性、种族主义和移民的影响的辩论。提出的观点包括在缺乏政治意愿的移民来源地提高生活水平的可能性，以及拜登关于解决中美洲移民根本原因的政策。美国的医疗保健与其他国家进行了比较，一些人指出了获取和官僚主义方面的问题，而另一些人则认为，实施经济适用房、免费教育和医疗保健等政策可以提高出生率。一位用户在 M2 MacBook Air 上启动 Docker 和运行服务时遇到了极度滞后的问题，促使他们改用自己的电脑。一些用户评论了 MacBooks 的高成本，并批评了苹果的定价策略，而另一些用户则赞扬了基于 M1 和 M1 ultra 的 MacBook Pros 的性能和响应速度，称其价格对于高质量的功能是合理的。 Discussion Service, Article.

推出 Discussion Service：OutSail(YC W23)--减少货船油耗的翼帆​

OutSail 航运公司正在为货船设计船帆，可减少高达 20%的燃料消耗，同时不干扰货物运行，而风力辅助船舶推进(WASP)装置可提高船舶的碳强度指标(CII)等级，而无需降低速度或改变航线。Outsail 设计了一种航运集装箱，可以转换为可拆卸的风力发电装置，用于远洋船舶，可以节省 30%的燃料成本，而且可以在大风浪中轻松地卷起和展开。一家名为 B9 航运公司的 Y Combinator 初创企业正在开发一种装有能够利用风能提高船只效率的翅膀的货船。Boundless Ocean Sailing Technologies 公司开发了 "智能风帆"，它使用传感器和算法，使船舶能够检测风速和风力，并相应地调整风帆。OutSail 公司正在为货船开发一种集装箱式的可伸缩风帆系统，以减少排放，该系统利用带状弹簧滚轮，预计需要进行改装才能将该系统安装到现有船队上；他们计划在集装箱船上安装自主风帆，风帆不需要对船舶进行永久性改动，也不需要桅杆，目前正在进行进一步测试。

阿里巴巴把自己拆成六块​

阿里巴巴分拆为六个独立的业务部门，每个部门都能通过 IPO 单独筹集资金，电子商务仍是最大的部门。此举刺激股价大涨 14%，并可能预先阻止监管机构的干预，或表明对科技镇压结束的信心。文章和评论讨论了中共对政府所有部门的控制以及马云失踪的可能原因。同时，对中国政府和未来的科技政策也有争论，因为最近的举动可能给投资者带来希望，但也有仔细审查的风险。讨论还涉及到美国和中国科技行业的垄断行为，以及拆分大型科技公司的潜在好处和弊端。归根结底，中国共产党决定解散阿里巴巴，可能是为了执行其权力，以保持对竞争对手权力基础的控制。 Discussion Service, Article.

Pandas 2.0​

Pandas 团队发布了 2.0.0 版本，包含新功能、错误修复和性能改进；现有代码应首先升级到 Pandas 1.5.3。虽然 Polars 的速度更快，但 Pandas 对于从事不断发展的模型的分析师和工程师来说仍然很有价值；Sklearn 提供了 Polars 和 DuckDB 对 Pandas 的铸造，具有无缝的互操作性。Pandas 的 2.0 版本引入了对箭头特定的 dtypes 的普遍支持；自动铸造和字符串作为对象，以及整数在引入 NaN 时变成浮点数，仍然是一些用户的重大挫折。Pandas 提供了生活质量的改进，并且明确地启用了写时复制。Pandas 从 R 的基础数据框架中汲取了灵感，但也受到了 plyr 和 data.table 的影响。Python 程序员有了一个新的开源库来代替昂贵的 Stata，甚至对于制药等领域也可以使用。 Discussion Service, Article.

Safari 版本是开发地狱​

由于压缩流 API 和服务工作者的问题，Safari 16.4 给 Construct 带来了问题，破坏了所有发布的内容。苹果公司在其发布过程中缺乏透明度和延迟更新，导致了开发者的挫败感。此外，Safari 浏览器增加了对 OffscreenCanvas 的支持，这导致预先存在的网络内容被破坏，因为它只支持 2D 上下文。开发人员正越来越多地将目光投向 Chrome 和 Firefox 作为替代品。同时，Chrome 的临时起源试验和硬件 API 的实施导致了 Safari 和 Firefox 开发者的反对。苹果公司在错误和未来产品方面缺乏透明度，以及它的应用商店指南也受到了批评。为 Safari 浏览器的错误和不稳定的性能进行开发是具有挑战性的，需要采取变通办法，并牺牲与其他浏览器的兼容性。如果他们的工作流程在 Safari 上无法运行，或者多个网站同时出现故障，用户可能会切换到其他浏览器。 Discussion Service, Article.

完全不给孩子自主权已经成为一种育儿规范​

在美国，对孩子的不断考勤导致了直升机式育儿，助长了父母的焦虑和抑郁，限制了孩子的自主权，导致父母的焦虑和抑郁。这种密集型育儿文化因大流行病而加速，向警方报告的误导造成了分裂，并增加了在非紧急情况下对警察的需求。对风险的恐惧导致了多管闲事的文化和个人主义的兴起，但建立信任和沟通对网络安全至关重要。一些国家的犯罪率和社会信任度较低，允许人们在不担心被盗的情况下留下自己的财物，但对儿童责任的期望值却下降了，不同的安全问题和原因会使某些做法在美国行不通。 Discussion Service, Article.

人工智能不会偷走你的工作，利用人工智能的人们会​

一位专家断言，人工智能将改变工作，而不是取代它们，预计将有多达 3 亿份工作受到影响。预计生成性人工智能将对白领工人产生最可观的影响，在未来十年内可能使世界 GDP 增加 7%。人工智能和自动化在财富分配和就业方面的应用是一个争论的话题--支持者提出了 UBI 和监管等解决方案。人工智能产生的产出也被讨论，专家预测编码和商业产品将发生重大变化，尽管存在依赖机器制造的结果的问题。人工智能的战略实施及其对劳动力的预期影响令人担忧，但一些人坚持认为，保持领先是保持竞争力的关键。人工智能在增强创造力方面具有潜力，但也有人担心由于能力的增加而出现公开的工作短缺。 Discussion Service, Article.

如何做困难的事情​

接受和承诺疗法有助于心理上的灵活性和保持对自己目标的导向。这涉及到化解，认识到消极思想是意识中的事件，以及澄清价值观。黑客新闻的文章和评论讨论了自律在完成艰难任务和培养习惯方面的重要性，但有些人在多动症或感到不堪重负方面挣扎。正念和小习惯的改变可以帮助使大问题更容易管理。不同的技巧对不同的人有效。 Discussion Service, 文章.

System76 开放固件​

System76 发布了开放固件，这是一个使用 coreboot、EDK2 和 System76 固件应用的开源固件，支持多种笔记本电脑型号，还有更多正在开发中。用于构建的固件可在 models 文件夹中找到，客户可以通过电子邮件索取电路板原理图。开放固件与 Linux 供应商固件服务兼容，简化了固态硬盘、扩展坞、笔记本电脑和鼠标狗的固件维护。System76 的笔记本电脑的质量在 Hacker News 上有争论，尽管没有专有的 blobs 的启动可能是不可行的。此外，System76 还提供了一个有 8 个 A100 单元的 2U 服务器供购买。 Discussion Service, Article.

显示 Discussion Service：Hocus - 使用 Firecracker 的 GitHub 代码空间的自我托管替代方案​

Hocus 是 Gitpod 和 GitHub Codespaces 的自我托管替代品，在个人服务器上提供自动提供的开发环境。Hocus 为每次提交预建环境，并与支持 SSH 的 Git 提供商集成。它目前只支持单节点部署，有已知的错误，但旨在提供简单、可扩展性和裸机性能。Hocus 用户可以指定在环境启动时运行的依赖关系和任务，并能够根据发布周期重复使用匹配的环境。这个基于虚拟机的平台优先考虑了部署和管理的便利性，未来还计划提供多节点支持和模板扩展。计划为大型团队提供基于座位的许可证，目前还没有提供托管服务。 Discussion Service, Article.

芬兰于 4 月 4 日星期二成为北约组织的成员​

芬兰将于 2023 年 4 月 4 日成为北约成员，这对该组织和该国来说都是一个重大事件。 评论者讨论了乌克兰和俄罗斯之间正在发生的冲突以及错综复杂的地缘政治格局。 谈话强调了了解局势的细微差别和通过商业而非战争建立关系的重要性。 芬兰加入北约的愿望归因于俄罗斯的威胁和它对北欧国家日益增长的侵略性。 加入北约提高了入侵的门槛，并可能使与俄罗斯发生冲突的可能性降低。 北溪河爆炸事件的真相仍不确定，瑞典不愿意与德国合作，可能是由于他们需要美国这个盟友。 Discussion Service, Article.

使用超快的 LZ 编解码器的近无损图像格式​

Richard Geldreich 提出了简单的超高速有损或接近无损图像编解码器的想法，它由新一代快速 LZ 编解码器构建，通过引入更多或更长的匹配，最大限度地减少可见的伪影。无损的帧缓冲区压缩对 MSAA 和 SSAA 很重要。计算能力的增长速度慢于高速带宽，而像 PNG 这样的图像编解码器在多线程或 GPU 解码时效果不佳。预处理图像可以用快速的 LZ 编解码器改善压缩，而不需要反转步骤。Zstd 结合了快速解码和高压缩率，可以作为 LZ4 预处理的一个替代方案。游戏下载与物理媒体所造成的二氧化碳排放仍在讨论之中。改进的想法包括渐进式 JPEGs 和小波，但它们可能以压缩率和内存效率为代价。 Discussion Service, Article.

最先进的开源聊天机器人 Vicuna-13B，刚刚发布了模型权重​

最近发布的开源聊天工具 Vicuna-13B 的模型权重，作为 delta 权重符合 LLaMA 模型许可。由于 llama-dl 上的 DMCA 撕毁请求认为 NN 权重不具有版权，有限的模型发布在未来可能会变得更加受限。与 Facebook 无关的研究人员被允许拥有和使用原始的 Vicuna-13B 模型权重。该模型包含一组调整，需要约 60GB 的 CPU 内存，但也可以在 64GB 内存的纯 CPU 模式下运行。该模型的大量搜索操作节省了时间和能量，导致了更好的结果。4 位量化模型的精确度低于原始模型。ML 模型的权重代表了模型 "学到 "的东西，对其正常运作至关重要。 Discussion Service, Article.

在荷兰空军基地发生了美国核武器事故？​

洛斯阿拉莫斯国家实验室出现了一张图片，显示排爆人员正在检查似乎是一枚弯曲的 B61 核弹，后来证实是来自一次训练演习。没有证实美国核武器在荷兰空军基地的事件，但 LANL 最近的照片表明，一架 C-17A 可以移动储存在沃尔克尔空军基地的所有炸弹。一张受损的 B61 炸弹照片在网上流传，但没有确认其真实性或含有物理包。一张在德克萨斯州的照片也在流传，引起了人们对事故发生可能性的质疑。所有人都在讨论政府执行信息安全协议的重要性。 Discussion Service, Article.
