2024-05-23

เอกสารที่รั่วไหลออกมาเปิดเผยกลยุทธ์เชิงรุกของ OpenAI ต่ออดีตพนักงาน​

  • เอกสารที่รั่วไหลออกมาแสดงให้เห็นว่า OpenAI นําโดย CEO Sam Altman ใช้กลยุทธ์เชิงรุกเพื่อป้องกันไม่ให้อดีตพนักงานวิพากษ์วิจารณ์บริษัทโดยขู่ว่าจะเพิกถอนส่วนของผู้ถือหุ้นที่ได้รับ เว้นแต่พวกเขาจะลงนามในข้อตกลงการออกที่เข้มงวด
  • แม้ว่า Altman จะขอโทษต่อสาธารณชนและอ้างว่าไม่รู้ แต่เอกสารภายในที่มีลายเซ็นของเขาและผู้บริหารคนอื่นๆ บ่งบอกว่าพวกเขาตระหนักถึงข้อกําหนดเหล่านี้ ทําให้เกิดความกังวลเกี่ยวกับความโปร่งใสและความน่าเชื่อถือของ OpenAI
  • ขณะนี้ OpenAI กําลังอัปเดตกระบวนการลาออกเพื่อให้แน่ใจว่าอดีตพนักงานจะได้รับความยุติธรรมและลบข้อที่ไม่ดูหมิ่น แม้ว่ายังมีงานอีกมากที่จะจัดการกับข้อกังวล

ปฏิกิริยา​

  • เอกสารที่รั่วไหลออกมาแสดงให้เห็นว่า OpenAI ใช้กลยุทธ์เชิงรุกเพื่อบังคับใช้ข้อตกลงที่ไม่ดูหมิ่นโดยคุกคามส่วนของอดีตพนักงาน ซึ่งนําไปสู่ฟันเฟืองและการรับรองจาก OpenAI ในภายหลัง
  • สถานการณ์ดังกล่าวได้จุดประกายการอภิปรายเกี่ยวกับการเจรจาสัญญา การชดเชยความเท่าเทียม และข้อที่ไม่แข่งขัน โดยเน้นย้ําถึงความซับซ้อนและความแตกต่างในระดับภูมิภาคในการบังคับใช้
  • นักวิจารณ์โต้แย้งว่าการกระทําของ OpenAI เผยให้เห็นประเด็นที่ลึกซึ้งยิ่งขึ้นเกี่ยวกับความไว้วางใจและความโปร่งใส โดยมีผลกระทบในวงกว้างสําหรับแนวโน้มของอุตสาหกรรม

OpenAI ไม่ได้โคลนเสียงของ Scarlett Johansson สําหรับ ChatGPT บันทึกยืนยัน​

  • Scarlett Johansson กล่าวหาว่า OpenAI เลียนแบบเสียงของเธอโดยไม่ได้รับความยินยอมหลังจากที่เธอปฏิเสธคําขออนุญาตของ CEO Sam Altman
  • OpenAI ได้ค้นหานักแสดงที่ไม่ใช่สหภาพแรงงานด้วยเสียงที่อบอุ่นและมีส่วนร่วมสําหรับโครงการลับเพื่อทําให้ ChatGPT มีมนุษยธรรม แต่ไม่ได้ตั้งเป้าอย่างชัดเจนที่จะโคลนเสียงของ Johansson ตามแหล่งที่มาและเอกสารที่ตรวจสอบโดย The Washington Post

ปฏิกิริยา​

  • OpenAI อยู่ภายใต้การตรวจสอบข้อเท็จจริงเนื่องจากถูกกล่าวหาว่าใช้นักพากย์ที่ฟังดูเหมือน Scarlett Johansson สําหรับ ChatGPT โดยไม่ได้รับความยินยอมจากเธอ ทําให้เกิดข้อกังวลทางกฎหมายและจริยธรรม
  • การอภิปรายเน้นย้ําถึงความซับซ้อนของกฎหมายเลียนแบบเสียง โดยอ้างอิงถึงกรณีต่างๆ เช่น Midler v. Ford และ Tom Waits vs. Frito-Lay และเน้นย้ําถึงความจําเป็นในการปรับปรุงกรอบกฎหมาย
  • การโต้เถียงนี้ให้ความสนใจกับผลกระทบที่กว้างขึ้นสําหรับ AI นักพากย์ และการพิจารณาด้านจริยธรรมของการใช้เสียงที่ฟังดูคล้ายกันโดยไม่ได้รับความยินยอมอย่างชัดแจ้ง

WinDirStat: Open-Source Disk Usage Viewer and Cleanup Tool สําหรับ Windows​

  • WinDirStat เป็นเครื่องมือโอเพ่นซอร์สสําหรับการดูและล้างการใช้งานดิสก์บน Microsoft Windows โดยนําเสนอรายการไดเร็กทอรี ทรีแมป และรายการส่วนขยาย
  • ทางเลือกสําหรับ Linux ได้แก่ KDirStat และ QDirStat ในขณะที่ผู้ใช้ MacOS X สามารถใช้ Disk Inventory X หรือ GrandPerspective
  • ซอฟต์แวร์นี้ได้รับอนุญาตภายใต้ GPLv2 เพื่อให้มั่นใจว่าซอฟต์แวร์ยังคงฟรีและโอเพ่นซอร์ส

ปฏิกิริยา​

  • การอภิปรายเปรียบเทียบเครื่องมือวิเคราะห์การใช้งานดิสก์ต่างๆ โดยเน้นที่คุณลักษณะ ประสิทธิภาพ และการใช้งานในระบบปฏิบัติการต่างๆ
  • WinDirStat เป็นที่นิยมและเป็นโอเพ่นซอร์ส แต่ถูกวิพากษ์วิจารณ์ว่าช้าในขณะที่ WizTree เร็วกว่า แต่มีข้อกังวลด้านความปลอดภัยและไม่ใช่โอเพ่นซอร์ส
  • ผู้ใช้เน้นการแลกเปลี่ยนระหว่างความเร็ว ความปลอดภัย และการใช้งาน และแสดงความต้องการคุณสมบัติการจัดการไฟล์ที่ดีขึ้นและวิธีการแสดงภาพที่ได้รับการปรับปรุง เช่น แผนผังต้นไม้และแสงตะวัน

การหยุดทํางานของ Microsoft ขัดขวางบริการ Bing, Copilot, ChatGPT และ DuckDuckGo​

  • การหยุดทํางานครั้งใหญ่ของ Microsoft เมื่อวันที่ 23 พฤษภาคม 2024 ทําให้บริการหลายอย่างหยุดชะงัก รวมถึง Bing, Copilot, การค้นหาทางอินเทอร์เน็ตของ ChatGPT และ DuckDuckGo ซึ่งส่วนใหญ่ส่งผลกระทบต่อผู้ใช้ในเอเชียและยุโรป
  • หน้าแรกและบริการ Copilot ของ Bing ประสบปัญหาสําคัญ ในขณะที่ DuckDuckGo แสดงข้อความแสดงข้อผิดพลาด แต่กลับมาทํางานตามปกติในภายหลัง
  • OpenAI และ Microsoft รับทราบปัญหา โดยมีความพยายามอย่างต่อเนื่องในการกู้คืนฟังก์ชันการทํางานเต็มรูปแบบให้กับ Bing และ Copilot

ปฏิกิริยา​

  • การหยุดทํางานของ Microsoft ส่งผลกระทบต่อบริการอินเทอร์เน็ตหลายรายการ เช่น Bing, Copilot, DuckDuckGo และ ChatGPT
  • เหตุการณ์ดังกล่าวเน้นย้ําถึงลักษณะการเชื่อมต่อระหว่างกันของบริการออนไลน์และการพึ่งพาโครงสร้างพื้นฐานของ Microsoft
  • สําหรับการสนทนาโดยละเอียดเพิ่มเติมผู้ใช้จะถูกนําไปยังเธรดเฉพาะใน Hacker News

ข้อผิดพลาดฟล็อปปี้ดิสก์ Space Quest II ของ Sierra เปิดเผยซอร์สโค้ด AGI​

  • ในปี 2024 พบว่า Space Quest II ของ Sierra On-Line บางเวอร์ชันมีซอร์สโค้ด C ที่เหลืออยู่บนฟล็อปปี้ดิสก์ขนาด 720KB เนื่องจากการจัดรูปแบบที่ไม่เหมาะสม
  • ข้อผิดพลาดนี้เปิดเผยซอร์สโค้ดล่าม AGI ของ Sierra ประมาณ 70% รวมถึงไฟล์ต้นฉบับ 75 C และไฟล์แอสเซมบลี 16 ไฟล์ ซึ่งไม่มีใครสังเกตเห็นจนถึงปี 2016
  • ซอร์สโค้ดพร้อมใช้งานแล้วบน GitHub โดยให้ข้อมูลเชิงลึกอันมีค่าเกี่ยวกับกระบวนการพัฒนาของ Sierra และช่วยเหลือโครงการต่างๆ เช่น ล่ามบนเว็บ AGILE

ปฏิกิริยา​

  • การอภิปรายเน้นย้ําถึงข้อผิดพลาดในอดีตในการจัดจําหน่ายซอฟต์แวร์ เช่น การรวมข้อมูลที่ละเอียดอ่อนหรือไม่ได้ตั้งใจไว้ในการเปิดตัวผลิตภัณฑ์ขั้นสุดท้าย ซึ่งยกตัวอย่างโดยเกม DOS ปี 1989 "Double Dragon II: The Revenge"
  • ตรวจสอบมาตรการป้องกันการละเมิดลิขสิทธิ์สําหรับฟล็อปปี้ดิสก์ข้อ จํากัด ของเครื่องถ่ายเอกสารดิสก์ระดับผู้บริโภคและเครื่องมือที่ทันสมัยเช่น Greaseweazle สําหรับการอ่านข้อมูลระดับแม่เหล็ก
  • ผู้เข้าร่วมแบ่งปันประสบการณ์ความคิดถึงกับเกมเก่า ๆ พูดคุยเกี่ยวกับผลกระทบของการรั่วไหลของซอร์สโค้ดและเน้นย้ําถึงความสําคัญของการถ่ายภาพระดับภาคส่วนสําหรับการเก็บถาวร

Master Drone Flying: บทช่วยสอนสําหรับผู้เริ่มต้นแบบโต้ตอบด้วย FPVSIM​

  • FPVSIM มีบทช่วยสอนการบินด้วยโดรนโดยละเอียดสําหรับผู้เริ่มต้น ซึ่งครอบคลุมแนวคิดหลัก เช่น การโฉบ การเลี้ยว การธนาคาร และการเลี้ยวที่ประสานกัน
  • บทช่วยสอนเน้นความแตกต่างระหว่างโดรนและระบบนําทางรถยนต์ โดยเน้นที่การเคลื่อนไหว 3 มิติผ่านการม้วน หันเห และขว้าง และนําเสนอบทเรียนเชิงปฏิบัติผ่านเครื่องจําลองบนเว็บ
  • ผู้ใช้สามารถเข้าถึงแหล่งข้อมูลเพิ่มเติม เช่น คู่มือ เคล็ดลับประสิทธิภาพ และการกําหนดค่าขั้นสูง และฝึกฝนต่อไปบนเว็บหรือเดสก์ท็อปของ FPVSIM เพื่อการเรียนรู้ที่ดีขึ้นและกราฟิกที่สมจริง

ปฏิกิริยา​

  • "Drone Flying 101 – บทช่วยสอนแบบโต้ตอบสําหรับผู้เริ่มต้น" ครอบคลุมพื้นฐานของโดรน FPV (มุมมองบุคคลที่หนึ่ง) และโดรนที่ไม่ใช่ FPV (ภาพยนตร์) โดยเน้นย้ําถึงความเป็นมิตรต่อผู้ใช้ของโดรนที่ไม่ใช่ FPV เช่น DJI Mavic เนื่องจากระบบป้องกันภาพสั่นไหวของ GPS
  • บทช่วยสอนเน้นความสําคัญของการเลือกเครื่องส่งสัญญาณที่เหมาะสมแนะนําซอฟต์แวร์ OpenTX หรือ EdgeTX และโปรโตคอล ExpressLRS เพื่อประสิทธิภาพที่ดีขึ้นด้วยเครื่องส่งสัญญาณยอดนิยมรวมถึง Radiomaster และ TBS Tango 2
  • การอภิปรายสํารวจการใช้โดรนที่พัฒนาขึ้นในสงครามสมัยใหม่ โดยเฉพาะอย่างยิ่งในยูเครน และสัมผัสกับอนาคตที่เป็นไปได้ของโดรนอัตโนมัติ การฝึกนักบิน และมาตรการรับมือ

Emacs Easy Draw: เครื่องมือวาดภาพที่ไร้รอยต่อที่รวมเข้ากับโหมดองค์กร​

  • Emacs Easy Draw เป็นเครื่องมือวาดภาพที่ทํางานภายใน Emacs ซึ่งต้องการ Emacs 27.2, รองรับรูปภาพและ SVG, gzip/gunzip และ libxml
  • ผสานรวมกับ Org-Mode ช่วยให้ผู้ใช้สามารถสร้างและแก้ไขภาพวาดได้โดยตรงในเอกสาร และรองรับการส่งออกเป็น HTML หรือ LaTeX
  • เครื่องมือนี้ใช้ชุดย่อยของข้อกําหนด SVG รวมถึงไลบรารีตัวเลือกสีสําหรับการแก้ไข CSS และ HTML และได้รับอนุญาตภายใต้ GPLv3 ซึ่งส่งเสริมการมีส่วนร่วมของชุมชน

ปฏิกิริยา​

  • Emacs Easydraw เป็นเครื่องมือวาดภาพที่พัฒนาขึ้นสําหรับ Emacs ซึ่งสร้างขึ้นโดยเฉพาะบน Windows แทนที่จะเป็นสภาพแวดล้อม Linux ทั่วไป
  • ผู้ใช้พบว่ามีประโยชน์สําหรับภาพวาดขนาดเล็กและการผสานรวมกับเวิร์กโฟลว์ เช่น org-roam แม้ว่าปัจจุบันจะขาดความสามารถในการเขียนด้วยลายมือและคุณสมบัติการทํางานร่วมกัน
  • ด้วยการปรับปรุงอัลกอริทึมบางคนเชื่อว่ามันสามารถแข่งขันกับ Inkscape และมีตัวเลือกสีที่มีประโยชน์ทําให้เหนือกว่าเครื่องมือออนไลน์มากมาย

Tom Waits ชนะคดี Frito-Lay มูลค่า 2.6 ล้านดอลลาร์ในข้อหายักยอกเสียง​

  • Tom Waits ฟ้อง Frito-Lay Inc. ในปี 1988 สําหรับการใช้การแอบอ้างเป็นเสียงเหมือนเพลง "Step Right Up" ของเขาในโฆษณา Doritos โดยอ้างว่าการรับรองที่เป็นเท็จและการยักยอกเสียง
  • คณะลูกขุนมอบรางวัล Waits 2.6 ล้านดอลลาร์ซึ่งเป็นคําตัดสินที่ยึดถือในการอุทธรณ์ โดยกําหนดแบบอย่างทางกฎหมายสําหรับการยักยอกเสียงภายใต้พระราชบัญญัติ Lanham และกฎหมายแคลิฟอร์เนีย
  • วิพากษ์วิจารณ์ศิลปินที่อนุญาตให้เพลงของพวกเขาในโฆษณา โดยโต้แย้งว่าเพลงนี้บ่อนทําลายความสมบูรณ์ของศิลปะ และกรณีของเขาเน้นย้ําถึงความสําคัญของการปกป้องชื่อเสียงทางศิลปะ

ปฏิกิริยา​

  • การอภิปรายสํารวจประเด็นทางกฎหมายและจริยธรรมของการใช้นักพากย์เสียงที่เหมือนกัน โดยอ้างอิงถึงการฟ้องร้องของ Tom Waits ต่อการโต้เถียงของ Frito-Lay และ Scarlett Johansson กับ OpenAI
  • แนวคิดเรื่อง "ขายหมด" และการรับรู้ที่พัฒนาขึ้นของศิลปินที่ออกใบอนุญาตงานของตน รวมถึงผลกระทบทางกฎหมายของการใช้เสียงที่คล้ายกับของ Johansson โดยไม่ได้รับความยินยอม
  • การสนทนาวิพากษ์วิจารณ์แนวทางปฏิบัติขององค์กร โดยเฉพาะอย่างยิ่งของ OpenAI และจัดการกับข้อกังวลในวงกว้างเกี่ยวกับเสียงที่สร้างโดย AI ซึ่งส่งผลกระทบต่อทรัพย์สินทางปัญญาและความสมบูรณ์ทางศิลปะ

Typing Animation UI Library: ส่วนประกอบที่ปรับแต่งได้ฟรีสําหรับวิศวกรออกแบบ​

  • ไลบรารี UI ของ Typing Animation สําหรับวิศวกรออกแบบมีส่วนประกอบภาพเคลื่อนไหวแบบโอเพ่นซอร์สฟรีมากกว่า 20 รายการที่สร้างขึ้นด้วย React, Typescript, Tailwind CSS และ Framer Motion
  • ไลบรารีมีคุณสมบัติต่างๆ เช่น การบันทึกไฟล์ การค้นหาข้อความแบบเต็ม การสนับสนุนหลายภาษา และการกรองปฏิทิน พร้อมการสาธิตส่วนประกอบจริง
  • ผู้ใช้ยกย่องไลบรารีบน Twitter สําหรับการออกแบบและการใช้งาน และ Magic UI Pro มีเทมเพลตขั้นสูงเพิ่มเติมสําหรับการปรับแต่งเพิ่มเติม

  • การวิพากษ์วิจารณ์ที่สําคัญ ได้แก่ ประสิทธิภาพที่ซบเซาการใช้ทรัพยากรสูงปัญหาการใช้งานบน Firefox และข้อกล่าวหาว่าเป็นการฉ้อฉล ShadCN / UI
  • การอภิปรายยังเน้นย้ําถึงการครอบงําของ React ในการพัฒนาเว็บ ยูทิลิตี้ในการบํารุงรักษาส่วนประกอบ Figma และปัญหาด้านประสิทธิภาพ เช่น การใช้งาน CPU ที่รุนแรงและเบราว์เซอร์ขัดข้องบนไซต์สาธิต

NVIDIA เปิดตัวแพลตฟอร์ม CUDA-Q เพื่อเพิ่มศูนย์คอมพิวเตอร์ควอนตัมทั่วโลก​

  • NVIDIA ได้เปิดตัวแพลตฟอร์ม CUDA-Q ที่มุ่งพัฒนาศูนย์คอมพิวเตอร์ควอนตัมทั่วโลก
  • การประกาศดังกล่าวมีขึ้นเมื่อวันที่ 12 พฤษภาคม พ.ศ. 2024 ซึ่งถือเป็นก้าวสําคัญในเทคโนโลยีคอมพิวเตอร์ควอนตัม
  • การเปิดตัวครั้งนี้คาดว่าจะเร่งการวิจัยและพัฒนาในด้านคอมพิวเตอร์ควอนตัม

ปฏิกิริยา​

  • ผลประกอบการไตรมาสที่ 1 ปีงบประมาณ 2025 ของ Nvidia แสดงยอดขาย GPU H100 ที่แข็งแกร่ง แต่ระมัดระวังเกี่ยวกับความเสี่ยงด้านซัพพลายเชนที่อาจเกิดขึ้น ซึ่งมีความคล้ายคลึงกับกรณีในอดีตเช่น Cisco
  • การอภิปรายเน้นย้ําถึงความสําคัญของกลยุทธ์การลงทุน เช่น การกระจายความเสี่ยง การปรับสมดุลความเสี่ยง และการทําความเข้าใจการเปลี่ยนแปลงของตลาด โดยเน้นย้ําถึงตําแหน่งผู้นําของ Nvidia ในด้าน AI เนื่องจากระบบนิเวศซอฟต์แวร์ที่เหนือกว่า
  • มีความกังวลเกี่ยวกับความยั่งยืนของการเติบโตของ Nvidia ท่ามกลางกระแส AI การแข่งขันที่อาจเกิดขึ้นจากลูกค้าเช่น Meta และ Microsoft/OpenAI ที่สร้างชิปของตนเอง และข้อจํากัดด้านการผลิตจาก TSMC และ Samsung

ผู้ผลิตรถยนต์ยอมรับว่าแบ่งปันข้อมูลผู้ขับขี่กับตํารวจโดยไม่มีหมายจับ วุฒิสมาชิกเตือน​

  • ผู้ผลิตรถยนต์แปดราย รวมถึงโตโยต้า ซูบารุ และบีเอ็มดับเบิลยู ยอมรับต่อสภาคองเกรสว่าพวกเขาจะให้ข้อมูลผู้ขับขี่แก่ตํารวจโดยไม่มีคําสั่งศาล ซึ่งขัดแย้งกับคําสัญญาก่อนหน้านี้ในการปกป้องความเป็นส่วนตัวของผู้บริโภค
  • วุฒิสมาชิก Ron Wyden และ Ed Markey วิพากษ์วิจารณ์ผู้ผลิตรถยนต์ที่ทําให้ผู้บริโภคเข้าใจผิดและทําให้เกิดความกังวลเกี่ยวกับการใช้ข้อมูลตําแหน่งในทางที่ผิดโดยระบบกฎหมาย
  • จุดยืนที่ไม่สอดคล้องกันของอุตสาหกรรมยานยนต์เกี่ยวกับความเป็นส่วนตัว เช่น การคัดค้านค่าซ่อมในขณะที่ประนีประนอมข้อมูลผู้บริโภค

ปฏิกิริยา​

  • สมาชิกวุฒิสภามีความกังวลเกี่ยวกับผู้ผลิตรถยนต์ที่ให้ข้อมูลตําแหน่งยานพาหนะแก่ตํารวจโดยไม่มีหมายจับ ทําให้เกิดปัญหาความเป็นส่วนตัวและการติดตามในรถยนต์สมัยใหม่
  • ผู้ใช้พูดคุยเกี่ยวกับความซับซ้อนของการปิดใช้งานบริการติดตาม เช่น OnStar ความถูกต้องตามกฎหมายของการกระทําดังกล่าว และผลกระทบต่อการทํางานและการรับประกันของรถ
  • การอภิปรายเน้นย้ําถึงความสมดุลระหว่างความปลอดภัยสาธารณะและความเป็นส่วนตัวบทบาทของ บริษัท ประกันภัยและความต้องการสิทธิผู้บริโภคที่แข็งแกร่งและกฎระเบียบความเป็นส่วนตัวของข้อมูล

ยานโวเอเจอร์ 1 กลับมาส่งข้อมูลวิทยาศาสตร์อีกครั้งหลังจากหายไปห้าเดือน​

  • ยานโวเอเจอร์ 1 ได้กลับมาส่งข้อมูลวิทยาศาสตร์จากเครื่องมือสองในสี่ชิ้นอีกครั้งหลังจากมีปัญหาคอมพิวเตอร์ในเดือนพฤศจิกายน พ.ศ. 2023
  • ทีมภารกิจกําลังปรับเทียบเครื่องมือที่เหลืออีกสองชิ้นใหม่ โดยขณะนี้ระบบย่อยคลื่นพลาสมาและแมกนีโตมิเตอร์ใช้งานได้
  • ปัญหาถูกติดตามไปยังหน่วยความจําที่เสียหายในระบบย่อยข้อมูลเที่ยวบิน ยานโวเอเจอร์ 1 เปิดตัวในปี 1977 อยู่ห่างจากโลกมากกว่า 15 พันล้านไมล์ และเป็นหนึ่งในยานอวกาศที่ปฏิบัติการยาวนานที่สุดของ NASA

ปฏิกิริยา​

  • การอภิปรายในบทความของ NASA เกี่ยวกับยานโวเอเจอร์ 1 ที่กลับมาส่งข้อมูลอีกครั้งมุ่งเน้นไปที่ว่าภารกิจของยานโวเอเจอร์เป็นความสําเร็จทางวิทยาศาสตร์ที่ยิ่งใหญ่ที่สุดของมนุษยชาติหรือไม่
  • ผู้เข้าร่วมเปรียบเทียบอายุขัยและการออกแบบที่เรียบง่ายของยานโวเอเจอร์กับโครงการที่ซับซ้อน เช่น Large Hadron Collider และการจัดลําดับจีโนม โดยเน้นย้ําถึงความสําคัญของตัวช่วยแรงโน้มถ่วงและการจัดตําแหน่งดาวเคราะห์ที่ไม่เหมือนใคร
  • การอภิปรายยังกล่าวถึงความสําเร็จที่ยิ่งใหญ่อื่น ๆ เช่นการกําจัดไข้ทรพิษและการพัฒนาแท่นพิมพ์โดยเน้นย้ําถึงความท้าทายในการจัดอันดับความสําเร็จเหล่านี้เนื่องจากผลกระทบที่สําคัญ

ความก้าวหน้าของเครื่องทัวริงใหม่คํานวณฟังก์ชันระดับ Ackermann​

  • Pavel Kropitz ค้นพบ Turing Machine (TM) 3 สถานะ 4 สัญลักษณ์ที่สามารถคํานวณฟังก์ชันระดับ Ackermann ได้ โดยหยุดด้วยสัญลักษณ์ที่ไม่ใช่ศูนย์ ( (2 \uparrow^15 5) + 14 ) บนเทปพอดี
  • TM นี้พบเมื่อวันที่ 25 เมษายน พ.ศ. 2024 เป็นครั้งแรกที่รู้จักในการจําลองฟังก์ชันที่ซับซ้อนดังกล่าว โดยพฤติกรรมของมันต้องการการเหนี่ยวนําสองครั้งเพื่อพิสูจน์
  • การค้นพบนี้ยังทําหน้าที่เป็นกรณีทดสอบสําหรับผู้ตรวจสอบความถูกต้อง "การพิสูจน์อุปนัย" โดยมุ่งเป้าไปที่การสร้างมาตรฐานและตรวจสอบหลักฐานดังกล่าว

ปฏิกิริยา​

  • ข้อความเจาะลึกความซับซ้อนของเครื่องจักรทัวริง โดยเน้นที่ปัญหา Busy Beaver และโปรแกรมเครื่องทัวริงใหม่ BB(3, 4) ซึ่งเกินฟังก์ชันของ Ackermann ในด้านความซับซ้อน
  • คุณสมบัติของเครื่องจักรทัวริงที่ทํางานมายาวนาน และผลกระทบของความซับซ้อนของ Kolmogorov โดยเน้นถึงความท้าทายในการวิเคราะห์เครื่องจักรเหล่านี้
  • การสนทนายังวิพากษ์วิจารณ์ระบบการตรวจสอบโดยเพื่อนความน่าเชื่อถือของแหล่งข้อมูลดิจิทัลและเน้นย้ําถึงความสําคัญของการเก็บถาวรและการอ้างอิงที่เหมาะสมในการวิจัยทางวิทยาศาสตร์

Computershare ทิ้ง VMware สําหรับ Nutanix AHV ท่ามกลางการปรับขึ้นราคาครั้งใหญ่​

  • Computershare ซึ่งเป็นผู้ให้บริการรีจิสทรีส่วนแบ่งตลาดหุ้นทั่วโลกกําลังละทิ้ง VMware เนื่องจากการปรับขึ้นราคาอย่างมีนัยสําคัญหลังจากการเข้าซื้อกิจการ VMware ของ Broadcom

  • การย้ายครั้งนี้เน้นย้ําถึงปัญหาที่อาจเกิดขึ้นสําหรับ Broadcom เนื่องจากลูกค้ารายใหญ่รายอื่นอาจมองหาทางเลือกอื่นเนื่องจากกลยุทธ์การกําหนดราคาที่มีรายได้สูงและมีอัตรากําไรสูง

  • การอภิปรายยังเน้นย้ําถึงความเสี่ยงของการล็อคอินของผู้ขาย และแนะนําแนวทางแบบไฮบริดหรือมัลติคลาวด์เพื่อลดการพึ่งพาผู้จําหน่ายไฮเปอร์ไวเซอร์รายเดียว
