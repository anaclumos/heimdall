2023-07-29

Cap'n Proto 1.0​

  • Cap'n Proto ซึ่งเป็นโปรโตคอลการส่งข้อความได้เปิดตัวเวอร์ชัน 1.0 ของการใช้งานอ้างอิง C ++
  • โปรโตคอลนี้ถูกใช้ในการผลิตเป็นเวลาหลายปีซึ่งบ่งบอกถึงความน่าเชื่อถือ
  • การเปิดตัวรวมถึงการเพิ่มประสิทธิภาพเพื่อประสิทธิภาพที่ดีขึ้น
  • มีการเปลี่ยนแปลงเพื่อให้สามารถยกเลิก RPC ได้
  • แผนสําหรับเวอร์ชัน 2.0 รวมถึงการแก้ไข C ++ API และไลบรารีชุดเครื่องมือ KJ C ++ เพื่อปรับปรุงประสบการณ์ของนักพัฒนา
  • การเปลี่ยนแปลงเหล่านี้จะต้องใช้คอมไพเลอร์ที่รองรับ C ++ 20 และอาจทําให้ KJ เป็นมิตรกับ coroutine มากขึ้น
  • การเปลี่ยนแปลงที่เข้ากันไม่ได้ย้อนหลังจะไม่เกิดขึ้นกับรูปแบบการออกหมายเลขกํากับหรือโปรโตคอล RPC
  • การเปิดตัว 2.0 อย่างเป็นทางการไม่คาดว่าจะเกิดขึ้นสองสามปี

ปฏิกิริยา​

  • Ian Denhardt ผู้สนับสนุนหลักในการดําเนินการ Go ของ Cap'n Proto ได้เสียชีวิตแล้ว ทําให้ชุมชน Cap'n Proto และ Sandstorm อยู่ในความโศกเศร้า
  • Cap'n Proto เป็นรูปแบบการออกหมายเลขกํากับข้อมูลประสิทธิภาพสูงที่ใช้ในแพลตฟอร์ม Workers ของ Cloudflare
  • มีการกล่าวถึงประโยชน์ของ Cap'n Proto รวมถึงการออกหมายเลขกํากับและ deserialization ที่มีประสิทธิภาพ
  • การอภิปรายยังรวมถึงการสนับสนุนภาษาสําหรับ Cap'n Proto พร้อมตัวอย่างของการใช้งานในภาษาต่างๆ
  • มีการสํารวจศักยภาพในการพัฒนาและปรับปรุง Cap'n Proto ต่อไป
  • การสนทนาสัมผัสกับหัวข้อต่างๆเช่นฟิลด์ที่จําเป็นและไม่จําเป็นในการพัฒนาซอฟต์แวร์การพิมพ์แบบคงที่และความท้าทายของการออกแบบโปรโตคอล
  • รูปแบบการออกหมายเลขกํากับอื่น ๆ เช่น Avro, protobuf และ flatbuffers จะถูกเปรียบเทียบกับ Cap'n Proto
  • คําแนะนําสําหรับไลบรารีและโปรโตคอลการออกหมายเลขกํากับไบนารีอื่น ๆ จะกล่าวถึงควบคู่ไปกับ Cap'n Proto

ดูทีวีจากยุค 90 และก่อนหน้า​

  • ข้อมูลสรุปจะอธิบายรายการช่องทีวีและหมวดหมู่
  • มันกล่าวถึงปุ่มที่จะเดินทางย้อนกลับไปในปี 1990
  • ข้อมูลได้รับการปรับปรุงล่าสุดเมื่อวันที่ 23 กรกฎาคม 2023
  • ผู้สร้างรายการจะได้รับเครดิต
  • มีการขอบริจาคเพื่อซื้อกาแฟ

ปฏิกิริยา​

  • กระทู้ความคิดเห็นกล่าวถึงการดูรายการทีวีจากทศวรรษที่แตกต่างกันโดยเฉพาะยุค 60, 70, 80 และ 90
  • ผู้ใช้แสดงความคิดถึงประสบการณ์การพลิกช่องและวิพากษ์วิจารณ์การขาดนวัตกรรมในบริการสตรีมมิ่งในปัจจุบัน
  • แนะนําแพลตฟอร์มทางเลือกและวิธีการเข้าถึงรายการทีวีรุ่นเก่า
  • มีการกล่าวถึงความท้าทายในการแปลงเทป VHS ให้เป็นดิจิทัลและข้อ จํากัด ของทีวีแอนะล็อก
  • ผู้ใช้แบ่งปันประสบการณ์และความทรงจําในการดูทีวีในอดีต
  • มีการหารือเกี่ยวกับช่องโฆษณาและรายการเฉพาะจากยุค 90
  • ปัญหาลิขสิทธิ์และใบอนุญาตถูกกล่าวถึงในบริบทของการดูรายการทีวีรุ่นเก่า

ผู้ก่อตั้ง Sci-Hub ได้รับรางวัล EFF สําหรับการให้การเข้าถึงความรู้ทางวิทยาศาสตร์​

  • Alexandra Elbakyan ผู้ก่อตั้ง Sci-Hub ได้รับการยอมรับจาก Electronic Frontier Foundation (EFF) สําหรับความพยายามของเธอในการให้การเข้าถึงความรู้ทางวิทยาศาสตร์ฟรี
  • Sci-Hub เป็นทรัพยากรที่มีค่าสําหรับนักเรียนและนักวิจัยซึ่งได้รับการยกย่องสําหรับบทบาทในการช่วยชีวิต
  • Elbakyan ยังคงปกป้องภารกิจของ Sci-Hub แม้จะมีความท้าทายทางกฎหมายและความเสียหายนับล้านที่เป็นหนี้กับสํานักพิมพ์รายใหญ่
  • EFF ยอมรับงานของ Elbakyan ในการท้าทายระบบการเผยแพร่ทางวิชาการในปัจจุบันและช่วยให้สามารถเข้าถึงข้อมูลทางวิทยาศาสตร์ได้หลายล้านคน
  • Elbakyan จะได้รับรางวัลโดยตรงในพิธีในเดือนกันยายน

ปฏิกิริยา​

  • Alexandra Elbakyan ผู้ก่อตั้ง Sci-Hub ได้รับรางวัลผู้บุกเบิก Electronic Frontier Foundation (EFF) จากความพยายามของเธอในการทําให้ความรู้ทางวิทยาศาสตร์สามารถเข้าถึงได้
  • Elbakyan แสดงความไม่พอใจในการยอมรับรางวัลในนามของ Sci-Hub มากกว่าเป็นการส่วนตัวโดยเปรียบเทียบกับ Linus Torvalds และ Linux
  • การอภิปรายเน้นย้ําถึงความสําคัญของ Sci-Hub ในการทําให้ความรู้เป็นประชาธิปไตยและความพร้อมของแพลตฟอร์มทางเลือกสําหรับการเข้าถึงเอกสารทางวิทยาศาสตร์
  • อย่างไรก็ตามมีความกังวลว่ารางวัลนี้อาจถูกใช้เพื่อบ่อนทําลาย EFF ในคดีทางกฎหมายที่เกี่ยวข้องกับการละเมิดลิขสิทธิ์

Worldcoin ไม่ได้แย่อย่างที่คิด: มันแย่กว่านั้น​

  • Worldcoin เป็นระบบการเงินใหม่ที่รวบรวมข้อมูลไบโอเมตริกซ์ที่ละเอียดอ่อนและสัญญาว่าจะให้ความเท่าเทียมกันและความเป็นธรรม
  • บทความนี้ทําให้เกิดความกังวลเกี่ยวกับวิธีการรวบรวมข้อมูลที่น่าสงสัยที่ใช้โดย Worldcoin และการสร้างตลาดมืดที่มีศักยภาพสําหรับข้อมูลประจําตัวที่ได้รับการยืนยัน
  • ประสิทธิภาพของมาตรการความเป็นส่วนตัวของ Worldcoin และผลที่ตามมาของการเชื่อมโยงลักษณะไบโอเมตริกซ์ที่ไม่เปลี่ยนแปลงกับเงินก็ถูกตั้งคําถามเช่นกัน
  • แผนการจัดจําหน่ายของ Worldcoin ซึ่งเกี่ยวข้องกับการจัดสรรโทเค็นจํานวนมากให้กับคนวงในถูกวิพากษ์วิจารณ์
  • บทความชี้ให้เห็นว่า Worldcoin อาจไม่ปฏิวัติหรือเท่าเทียมอย่างที่กล่าวอ้าง

ปฏิกิริยา​

  • การอภิปรายครอบคลุมหลายหัวข้อรวมถึงสกุลเงินดิจิทัลการยืนยันตัวตนและข้อ จํากัด ของเทคโนโลยีบล็อกเชน
  • การสนทนาส่วนใหญ่มุ่งเน้นไปที่โครงการ Worldcoin และข้อบกพร่องและผลกระทบที่อาจเกิดขึ้น
  • ผู้เข้าร่วมแสดงความสงสัยเกี่ยวกับความน่าเชื่อถือของโครงการ Worldcoin
  • มีความกังวลเกี่ยวกับการใช้ไบโอเมตริกซ์เพื่อระบุตัวตน
  • มีข้อสงสัยเกี่ยวกับการกระจายและความเป็นธรรมของสกุลเงิน Worldcoin
  • การอภิปรายยังสํารวจประเด็นต่างๆเช่นความไว้วางใจในสกุลเงินดิจิทัลบทบาทของทุนนิยมในความก้าวหน้าทางเทคโนโลยีและความท้าทายของตัวตนออนไลน์และความเป็นส่วนตัว

รัฐบาลสหราชอาณาจักรใกล้จะกัดกร่อนการเข้ารหัสทั่วโลก​

  • รัฐบาลสหราชอาณาจักรใกล้จะผ่านร่างกฎหมายความปลอดภัยออนไลน์ซึ่งอาจทําให้สามารถแทรกแบ็คดอร์ลงในบริการส่งข้อความและทําให้การเข้ารหัสแบบ end-to-end อ่อนแอลง
  • กลุ่มภาคประชาสังคม ผู้เชี่ยวชาญด้านเทคนิค องค์กรสิทธิมนุษยชน และผู้ให้บริการส่งข้อความได้คัดค้านร่างกฎหมายนี้ โดยอ้างถึงความกังวลเกี่ยวกับผลกระทบต่อระดับโลก ความเป็นส่วนตัว และประชาธิปไตย
  • การยืนยันของรัฐบาลว่าสามารถสแกนข้อความเพื่อหาเนื้อหาที่ผิดกฎหมายในขณะที่ปกป้องความเป็นส่วนตัวนั้นขัดแย้งกัน
  • ผู้สนับสนุนกําลังเรียกร้องให้ฝ่ายนิติบัญญัติของสหราชอาณาจักรปกป้องการเข้ารหัสและความเป็นส่วนตัวโดยการรวมการแก้ไขร่างกฎหมาย

ปฏิกิริยา​

  • ผู้เข้าร่วมจะหารือเกี่ยวกับการเข้ารหัส การเฝ้าระวังของรัฐบาล และความสัมพันธ์ของ Apple กับจีน
  • มีการวิพากษ์วิจารณ์ต่อความพยายามของรัฐบาลสหราชอาณาจักรที่จะบ่อนทําลายการเข้ารหัส
  • มีความกังวลเกี่ยวกับ Apple ที่ประนีประนอมหลักการ
  • ผลกระทบที่อาจเกิดขึ้นจากการควบคุมของรัฐบาลเป็นที่ถกเถียงกัน
  • การอภิปรายเกี่ยวกับพรมแดนอินเทอร์เน็ตและผลกระทบของกฎระเบียบต่อการใช้อินเทอร์เน็ต
  • มีการตั้งคําถามถึงความเป็นไปได้และประสิทธิผลของกฎหมายที่เสนอ
  • หัวข้อทั่วไป ได้แก่ การพังทลายของความเป็นส่วนตัวความกังวลเกี่ยวกับการเข้าถึงของรัฐบาลมากเกินไปและผลกระทบด้านลบที่อาจเกิดขึ้นจากการกระทําของรัฐบาล

การกีดกันการเล่นเป็นสาเหตุสําคัญของวิกฤตสุขภาพจิตของวัยรุ่น​

  • การเล่นที่ไม่ได้รับการดูแลในหมู่เด็กกําลังลดลงและมีผลเสียต่อสุขภาพจิตของพวกเขา
  • การเพิ่มการเล่นฟรีถูกมองว่าเป็นทางออกที่คุ้มค่าในการจัดการกับวิกฤตสุขภาพจิตในหมู่วัยรุ่น
  • ผู้เขียนยอมรับว่าการกีดกันการเล่นเป็นปัจจัยสนับสนุน แต่พวกเขามีความคิดเห็นที่แตกต่างกันเกี่ยวกับบทบาทของสมาร์ทโฟนและโซเชียลมีเดีย
  • การวิจัยแสดงให้เห็นว่าการเล่นและกิจกรรมอิสระตอบสนองความต้องการทางจิตวิทยาเพื่อความเป็นอิสระความสามารถและความเกี่ยวข้องซึ่งนําไปสู่สุขภาพจิตที่ดีขึ้น
  • บทความนี้เน้นถึงการเพิ่มขึ้นของความวิตกกังวลภาวะซึมเศร้าและอัตราการฆ่าตัวตายในคนหนุ่มสาวซึ่งเชื่อมโยงกับการลดลงของเสรีภาพและการเล่น
  • การจัดลําดับความสําคัญของการป้องกันผ่านการเปิดใช้งานการเล่นและการสํารวจอาจส่งผลให้ผลลัพธ์ด้านสุขภาพจิตดีขึ้น

ปฏิกิริยา​

  • การอภิปรายครอบคลุมหัวข้อต่าง ๆ ที่เกี่ยวข้องกับการเลี้ยงดูการพัฒนาเด็กการเล่นและการศึกษา
  • การเล่นที่ไม่มีโครงสร้างเป็นสิ่งสําคัญสําหรับสุขภาพจิตของวัยรุ่น
  • วิธีการเลี้ยงดูที่แตกต่างกันสามารถช่วยป้องกันพฤติกรรมเสี่ยงในเด็กได้
  • มีการหารือเกี่ยวกับผลกระทบของรถยนต์ต่อความปลอดภัยและเสรีภาพของเด็ก
  • การอนุญาตให้เด็กสํารวจและทดลองมีคุณค่า
  • การกําหนดเวลามากเกินไปและเวลาอยู่หน้าจอมากเกินไปมีผลเสียต่อเด็ก
  • ปฏิสัมพันธ์ทางสังคมและพลวัตทางการศึกษากําลังเปลี่ยนแปลง
  • ประสบการณ์การเรียนรู้แบบลงมือปฏิบัติความคิดสร้างสรรค์และความเป็นอิสระเป็นประโยชน์ต่อการพัฒนาเด็ก

แคลิฟอร์เนียเคลื่อนไหวเพื่อปิดปากนักวิจัยสแตนฟอร์ดที่ได้รับข้อมูลเพื่อศึกษาการศึกษา​

  • กระทรวงศึกษาธิการแคลิฟอร์เนียกําลังถูกวิพากษ์วิจารณ์ถึงข้อสัญญาในข้อตกลงความร่วมมือด้านข้อมูล
  • ข้อนี้ทําให้นักวิจัยไม่สามารถเป็นพยานต่อแผนกในคดีความได้
  • สหภาพเสรีภาพพลเมืองอเมริกันเชื่อว่านี่เป็นการละเมิดสิทธิการแก้ไขครั้งแรกของนักวิจัย
  • ข้อพิพาทไม่เกี่ยวข้องกับการเปิดเผยข้อมูลระดับนักเรียน
  • กรณีนี้มีความสําคัญเนื่องจากอาจจํากัดความสามารถของนักวิจัยในการจัดการกับความไม่เท่าเทียมกันทางการศึกษาในแคลิฟอร์เนีย
  • CDE ให้เหตุผลว่าบทบัญญัตินี้จําเป็นเพื่อปกป้องความเป็นส่วนตัวของนักเรียน

ปฏิกิริยา​

  • การสนทนากล่าวถึงข้อ จํากัด ในการมีส่วนร่วมของนักวิจัยในการดําเนินคดีที่กําหนดโดยกระทรวงศึกษาธิการแคลิฟอร์เนีย
  • บทบาทของการแข่งขันในการกําหนดความสามารถมีการสํารวจในการสนทนา
  • มีการหารือเกี่ยวกับความท้าทายที่เกี่ยวข้องกับข้อมูลที่ไม่ระบุตัวตน
  • มีการตรวจสอบความสมดุลระหว่างความโปร่งใสและความเป็นส่วนตัวในการวิจัยทางการศึกษา
  • การใช้พยานผู้เชี่ยวชาญในการฟ้องร้องและค่าธรรมเนียมของพวกเขาจะถูกกล่าวถึง
  • ปัญหาเกี่ยวกับโปรแกรมของรัฐบาลและความเป็นส่วนตัวของข้อมูลได้รับการแก้ไขแล้ว
  • การสนทนาเน้นความสําคัญของการปกป้องความเป็นส่วนตัวในขณะที่ตระหนักถึงความสําคัญของความโปร่งใสและความรับผิดชอบ

เหตุใด DNS จึงยังเรียนรู้ได้ยาก​

  • การเรียนรู้และการแก้ไขปัญหา DNS อาจเป็นเรื่องที่ท้าทายเนื่องจากลักษณะที่ซ่อนอยู่ของระบบ
  • แคชของตัวแก้ไขและการสนทนาระหว่างตัวแก้ไขและเนมเซิร์ฟเวอร์ที่เชื่อถือได้มักจะถูกซ่อนจากผู้ใช้
  • ผู้เขียนแนะนําให้สอนผู้คนเกี่ยวกับระบบที่ซ่อนอยู่เหล่านี้และให้การมองเห็นและการดีบักข้อมูลใน DNS มากขึ้น
  • เครื่องมือที่สับสนและผลลัพธ์ของพวกเขาก่อให้เกิดความท้าทายในการแก้ไขปัญหา DNS และผู้เขียนเสนอการปรับปรุงเอาต์พุตเครื่องมือและสร้างเครื่องมือบรรทัดคําสั่งที่ใช้งานง่ายยิ่งขึ้น
  • ความยากลําบากในการจัดทําเอกสารปัญหา DNS ทั่วไปเกิดขึ้นจากการเปลี่ยนแปลงของประสบการณ์ของแต่ละบุคคล
  • การสัมผัสไม่บ่อยนักและความกลัวในการทดลองกับ DNS มีส่วนทําให้เกิดความยากลําบากในการเรียนรู้เรื่องนี้

ปฏิกิริยา​

  • การเรียนรู้ DNS (Domain Name System) ก่อให้เกิดความท้าทายและความซับซ้อน
  • การดีบักปัญหา DNS เป็นปัญหาทั่วไป
  • อุปสรรคในการทําความเข้าใจ DNS จําเป็นต้องได้รับการแก้ไข
  • จําเป็นต้องมีเอกสารและเครื่องมือที่ดีขึ้นเพื่อปรับปรุงการเรียนรู้ DNS
  • มีการกล่าวถึงการปรับปรุงอินเทอร์เฟซผู้ใช้ของเครื่องมือหลัก FOSS (ซอฟต์แวร์ฟรีและโอเพ่นซอร์ส)
  • การใช้เครื่องหมายอัฒภาคในการสืบค้น DNS เป็นหัวข้อถกเถียงกัน
  • ความง่ายในการเรียนรู้ DNS ถูกตั้งคําถาม
  • การทําความเข้าใจโครงสร้างพื้นฐานถือว่ามีความสําคัญในการเรียนรู้ DNS
  • ทักษะทางเทคนิคที่ลดลงในหมู่นักพัฒนาที่อายุน้อยกว่าเป็นเรื่องที่น่ากังวล
  • มีการกล่าวถึงโปรโตคอล DNS และไฟล์โซน
  • มีการกล่าวถึงตัวเลือกซอฟต์แวร์ DNS ทางเลือก
  • ประสบการณ์เฉพาะเกี่ยวกับการแก้ไขปัญหา DNS จะถูกแชร์
  • DNS ใช้เพื่อวัตถุประสงค์ต่างๆ

"ความสมบูรณ์ของสภาพแวดล้อมเว็บ" คือการโจมตีบนอินเทอร์เน็ตฟรี​

  • นโยบาย "Web Environment Integrity" (WEI) ของ Google ถูกกล่าวถึงในบทความ
  • นโยบายนี้อนุญาตให้นักพัฒนาซอฟต์แวร์อนุมัติหรือปฏิเสธการกําหนดค่าเบราว์เซอร์บางอย่าง ซึ่งอาจจํากัดการเข้าถึงเว็บไซต์สําหรับผู้ใช้เบราว์เซอร์หรือระบบปฏิบัติการฟรี
  • บทความชี้ให้เห็นว่า WEI อาจถูกรัฐบาลและ บริษัท ต่างๆใช้ประโยชน์เพื่อควบคุมและ จํากัด การเข้าถึงอินเทอร์เน็ต
  • มูลนิธิซอฟต์แวร์เสรีกําลังเรียกร้องให้ Google ทบทวนนโยบายและเน้นย้ําถึงความสําคัญของอินเทอร์เน็ตที่เสรีและเปิดกว้าง

ปฏิกิริยา​

  • ข้อเสนอ "Web Environment Integrity" (WEI) ของ Google อยู่ระหว่างการตรวจสอบข้อเท็จจริงเกี่ยวกับผลกระทบที่อาจเกิดขึ้นต่อเสรีภาพทางอินเทอร์เน็ต
  • ผู้ใช้กังวลเกี่ยวกับการควบคุมความปลอดภัยของเบราว์เซอร์การบล็อกโฆษณาและการเข้าถึงเว็บไซต์ที่เพิ่มขึ้นของ Google
  • มีความกังวลเกี่ยวกับวัตถุประสงค์ของระบบ reCAPTCHA ของ Google และศักยภาพในการติดตามและการทําเหมืองข้อมูล
  • มีการเปรียบเทียบระหว่าง WEI และ Privacy Access Tokens (PAT) ของ Apple ซึ่งนําไปสู่ความสงสัยและการต่อต้านการกระทําของ Google
  • การอภิปรายรวมถึงโปรโตคอลทางเลือกอิทธิพลของ บริษัท เทคโนโลยีขนาดใหญ่และข้อ จํากัด ที่อาจเกิดขึ้นในการควบคุมผู้ใช้และการเข้าถึงอินเทอร์เน็ต

โหมด No-GIL กําลังมาสําหรับ Python​

  • สภากํากับดูแล Python กําลังพิจารณาข้อเสนอเพื่อให้ Global Interpreter Lock (GIL) เป็นตัวเลือกใน CPython
  • สิ่งนี้จะเปิดใช้งานโหมด GIL-less ใน Python ซึ่งอาจปรับปรุงกระบวนการทํางานพร้อมกัน
  • สภากําลังใช้ความระมัดระวังเพื่อให้แน่ใจว่ามีความเข้ากันได้แบบย้อนหลังและหลีกเลี่ยงสถานการณ์แยก Python 2 และ 3
  • พวกเขากําลังหารือเกี่ยวกับข้อกําหนดสําหรับความเข้ากันได้ของ ABI และจัดการกับผลกระทบต่อความเข้ากันได้แบบย้อนหลัง
  • ผู้วิจารณ์บางคนได้แสดงความกังวลเกี่ยวกับปัญหาความเข้ากันได้ที่อาจเกิดขึ้นและแนะนําแนวทางทางเลือกในการปรับปรุงกระบวนการทํางานพร้อมกันใน Python

ปฏิกิริยา​

  • Python กําลังแนะนําโหมด No-GIL (Global Interpreter Lock) ตามที่ยืนยันโดยโพสต์บน lwn.net
  • Global Interpreter Lock เป็นกลไกใน Python ที่อนุญาตให้รัน Python bytecode ได้ครั้งละหนึ่งเธรดเท่านั้น
  • โหมด No-GIL มีจุดมุ่งหมายเพื่อลบข้อ จํากัด นี้และอนุญาตให้หลายเธรดรัน Python bytecode พร้อมกัน
  • ข้อมูลเกี่ยวกับโหมด No-GIL ถูกแชร์ครั้งแรกบน ycombinator.com
